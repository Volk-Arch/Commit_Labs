# Сбой наклоняет конусы: задержка Шапиро из порядка

Дата: 11 октября 2026, вечер. Код: `code/tilt.py` (`EPS=0.8 python3
tilt.py 600 0.03 2`, ~6 мин). Продолжение `defect-doc.md`.

## Конструкция

1. Засев в слое (≈13 000 событий); в центре неподвижный сбой — трубка
   событий r < 0.15.
2. **Поле из порядка:** число связей от сбоя к событию (`defect-doc`: идёт
   как 1/R), сглаженное по соседям. Φ = −κ·поле, κ подобрано так, чтобы
   масса M = 0.03.
3. **«Раньше» только между близкими:** 0 < Δt < 0.8 и |Δx| < c·Δt,
   c = 1 + 2Φ. Это слабое поле ОТО: свет медленнее у массы. У Нордстрёма
   c = 1, и конусы не меняются.
4. **Дальнее «раньше» — цепочкой близких.**
5. **Прибор — только порядок:** часы-цепи слева и справа на высоте b;
   приход сигнала = первый тик приёмника в будущем тика испускателя.
   Задержка = приход с полем минус приход без поля, на тех же точках.
   Без поля свет доходит за 2.54–2.56 при D = 2.4 (дискретность).

Первая попытка (шаг 0.45, плотность 350) была непригодна: дискретность
давала +0.6 к времени света, задержки скакали. Вторая — с полем от сбоя
только до t < 2.2 — тоже: поздние участки пути шли без поля. Ниже
исправленная.

## Результат (2 засева, ~45 испускателей на каждое b)

| b | замер | ∫(1/c − 1)dx по фактическому полю | ОТО 2M·ln((r₁+r₂+D)/(r₁+r₂−D)) | Нордстрём |
|---|---|---|---|---|
| 0.25 | 0.257 ± 0.006 | 0.245 | 0.273 | 0 |
| 0.40 | 0.219 ± 0.006 | 0.214 | 0.218 | 0 |
| 0.60 | 0.192 ± 0.005 | 0.181 | 0.173 | 0 |
| 0.90 | 0.133 ± 0.005 | 0.127 | 0.132 | 0 |

Задержка, измеренная одним только порядком, совпадает с формулой Шапиро
ОТО в пределах 5–10 %, включая логарифмический спад с прицельным
расстоянием. Цепочка близких отношений точно переносит наклон местных
конусов в дальние (замер против интеграла по полю: +2…+6 %).

## Что это и чего это не значит

* Впервые в проекте свет **задерживается** массой — то, чего Нордстрём не
  даёт (и чего не давали дырки). Сбой меняет уже не «кто есть», а
  «кто раньше».
* Коэффициент 2 в c = 1 + 2Φ (то есть Φ + Ψ при Ψ = Φ) — **выбор ОТО,
  вставленный руками**. Из порядка выведены: поле 1/R (связи) и перенос
  местного наклона в дальние отношения (замыкание). Почему именно 2, а не
  0 (Нордстрём), — не выведено.
* Масса — свободный параметр (κ). Местные конусы считаются по
  координатам точек, как и в золотом мире по меткам.
* Слабое поле. При c → 0 конусы закрываются: там, где 2|Φ| → 1, сигнал
  не выходит за конечное время — подпись горизонта. Не проверено.
