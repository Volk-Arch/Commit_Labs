# Обе строки в одной петле: Λ — неподвижная точка, и она чинит ошибки

Дата: 11 октября 2026, вечер. Код: `code/fixgold.py`. Продолжение
`fixloop-doc.md`.

## Постановка

Мир — золотой квазикристалл Λ в ромбе (N = 1279). Часов извне **нет**: 12
мировых линий составлены из точек самого Λ (место с координатами из
{0, ±0.618}, у них малая тень; тики — все разрешённые тенью времена,
шаг 0.73–0.77ℓ, неравномерный). Линии знают свои метки (свои показания
часов и место).

Шаг петли: радар по порядку до линий (несмещённо, по показаниям часов) →
MDS, синхронизация, сферы → перевод в рамку Λ по линиям → **вторая
строка:** событие садится на ближайшую свободную точку Λ → конус.

Старт: события Λ сдвинуты шумом σ·ℓ, порядок испорчен. Мера — доля
отношений, отличающихся от Λ (с учётом того, какое событие где), и доля
событий, вернувшихся на своё место. 2 прогона на строку.

## Результат

| σ | только конус: ошибка по шагам 0→6 | конус + тень: ошибка 0→6 | на своём месте |
|---|---|---|---|
| 0 | 0 → 0.12 → 0.22 → … → **0.38** | 0 → 0.003 → … → **0.000** | **100 %** |
| 0.1ℓ | 0.12 → … → 0.42 | 0.12 → **0.017** → 0.020 | 93 % |
| 0.2ℓ | 0.25 → … → 0.45 | 0.25 → **0.14** | 76 % |
| 0.3ℓ | 0.38 → … → 0.50 | 0.38 → 0.35 | 50 % |
| 0.5ℓ | 0.62 → … → 0.64 | 0.62 → 0.64 | 20 % |

**Только конус, часы из самого мира:** даже из точного Λ петля уходит,
12 % отношений за первый шаг, 38 % за шесть. Часы с шагом 0.73ℓ слишком
грубы (`gpsrule-doc`: нужно ≲ 0.3ℓ), и ошибки копятся. С внешними
частыми часами (`fixloop-doc`) петля замерзала; со своими — нет.

**Конус + тень:** Λ — точная неподвижная точка при тех же грубых часах.
Ошибки радара меньше половины расстояния между точками Λ округляются
прочь. Сдвиг на 0.1ℓ петля исправляет за один шаг (12 % → 2 %, 93 %
событий дома), на 0.2ℓ — наполовину. Бассейн притяжения по меткам
~0.1–0.2ℓ.

## Честная оговорка

Как **набор точек** неподвижная точка единственна по построению: событий
столько же, сколько точек Λ в ромбе, и каждое садится на свою, так что
неразмеченный порядок после первого шага — всегда порядок Λ. Нетривиальны
два других факта: без тени мир со своими часами вообще не держится, а с
тенью держится точно и возвращает события на свои места.

## Простыми словами

Конус без тени — аналоговая запись: каждая перезапись добавляет шум, и
копия копии расплывается. Тень делает мир **цифровым**: всякое событие
может стоять только в разрешённой точке, и маленькая ошибка округляется
обратно, как при чтении цифрового сигнала. Поэтому мир, который сам себе
служит часами, держится только вместе со второй строкой.

## Что дальше

* Λ самоподобна (умножение на τ): её неподвижность при петле, вероятно,
  переносится на все масштабы τᵏ — не проверено.
* Бассейн ~0.1–0.2ℓ мерян при N=1279 и 12 линиях; зависимость от числа
  линий и от N не мерилась.

## Дополнение: самоподобие проверено (`code/selfsim_gold.py`)

Мир с тенью в τᵏ раз меньше, взятый в ромбе в τᵏ раз больше, **совпадает**
с исходным миром, увеличенным в τᵏ: при k = 1, 2, 3 все 1609 точек
совпали (расхождение ~1e−15), порядок совпал полностью. В том же ромбе
события с тенью ≤ 0.618r составляют 0.130 всех (ожидание τ⁻⁴ = 0.146,
отличие — край ромба). Значит неподвижная точка петли одна и та же на
всех масштабах τᵏ: огрубление (оставить события с малой тенью)
переводит мир в себя. Это точная, не статистическая, неподвижная точка
огрубления.
