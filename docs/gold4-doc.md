# Золотой квазикристалл 3+1: четырёхмерный мир из одной строки

Дата: 11 октября 2026, вечер. Код: `code/gold4.py` (построение),
`code/gold4test.py`, `code/gold4b.py` (бусты), `code/gold4stats.py`
(различители). Продолжение `lattice-doc.md`.

## Правило

Точка-кандидат — четвёрка чисел `cᵢ = aᵢ + bᵢτ` (aᵢ, bᵢ целые). У числа
есть «тень» `c' = a − b/τ`.

    событие существует  ⟺  0.618·t'² + x'² + y'² + z'² ≤ r²   (тень в шаре)
    A раньше B          ⟺  ΔT > |Δx|,   T = √τ·t

Форма `τt² − x² − y² − z²` лоренцева у нас и определённая у тени. Поэтому
её целочисленные (в `Z[τ]`) симметрии — дискретная группа Лоренца — в
тени действуют вращениями и шар не портят. Светоподобных векторов в
решётке нет вовсе: форма над `Q(√5)` анизотропна. Радиус `r` задаёт
плотность: `ρ = (π²/2)r⁴/25`. Случайности нет. Каждое событие решается
само по себе: правило локально в предельном смысле.

## 1. Бусты: число точек в ромбе объёма 30 (Пуассон: 30 ± 5.5 всегда)

| направление | η | квазикристалл | Z⁴ (решётка в покое) |
|---|---|---|---|
| ось x (рац. световое (1,1,0,0)) | 0 / 2 / 3 | 30.4±6.3 / 30.5±4.7 / 30.8±4.8 | 29.8±4.6 / 30.8±**32.5** / **11.1±30.4, 87 % пустых** |
| (1,2,2)/3 (рац. световое (3,1,2,2)) | 2 / 3 / 4 | 30.4±2.7 / 30.0±3.0 / 30.0±2.7 | 30.3±3.3 / **32.8±32.2, 48 % пустых** / — |
| (1,1,0)/√2 (иррац.) | 2 / 3 / 4 / 4.5 | 29.4±3.0 / 28.8±5.1 / 29.8±3.4 / 28.8±4.5 | 30.8±2.1 / 29.4±1.9 / — |
| случайное | 1 / 2 / 3 | 30.5±3.1 / 30.1±2.8 / 29.7±3.4 | 29.7±2.3 / 30.1±1.9 / 29.8±2.3 |

η = 4.5 — вытягивание в `e⁹ ≈ 8000` раз. Квазикристалл ни разу не дал
пустого ромба ни в одном направлении. Решётка Z⁴ ломается **ровно** по
рациональным световым направлениям (теория: каспы группы `O(3,1;Z)`) и
цела по остальным. У квазикристалла рациональных световых направлений
нет.

## 2. Различители в ромбе (3 положения ромба против 6 засевов)

| N | доля | разм. | высота | связей/соб. | спектр |
|---|---|---|---|---|---|
| 1000 кв. / засев | 0.095 / 0.100 | 4.07 / 4.00 | 10.7 / 9.7 | 18.3 / 18.0 | +0.010 / +0.018 |
| 2000 | 0.106 / 0.099 | 3.94 / 4.01 | 12.3 / 12.3 | 30.0 / 27.4 | +0.016 / +0.024 |
| 4000 | 0.103 / 0.101 | 3.97 / 3.99 | 15.0 / 15.3 | 44.2 / 42.5 | +0.022 / +0.030 |

**Сходится:** доля пар, размерность 4, высота, число связей и его рост
(в пределах 1–10 %). Спектр положителен и растёт с N, как у засева, но
ниже примерно на 0.008.

**Не сходится — отпечаток кристалла:** профиль малых интервалов.
`n1/n0` = 0.22–0.29 против 0.35–0.40, распределение размеров «комковатое»
(бугры на 4, 6, 11–12, 15). Запрещённых размеров, в отличие от 1+1, нет.

## Итог

> Однострочное бинарное правило без случайности даёт четырёхмерный
> порядок, у которого нет выделенной системы отсчёта (проверено до
> растяжения в 8000 раз по всем направлениям), размерность 4, верные доля
> пар, высота и рост числа связей. Отличается профилем малых интервалов и
> спектром.

## Оговорки

* Это картина, а не рост: мир задан сразу, динамики нет. Плоский.
* Малые N (до 4000); спектр и профиль — при трёх положениях ромба.
* Дискретная группа Лоренца кокомпактна по теории (анизотропная форма
  над вполне вещественным полем). Измерено до η = 4.5 в четырёх
  направлениях.
* Не новость по сути: модельные множества из арифметических групп;
  Boyle & Mygdalas (arXiv:2601.07769) строят пространственно-временные
  квазикристаллы из `II₉,₁`. Новое здесь — проверка различителями
  причинных множеств.
