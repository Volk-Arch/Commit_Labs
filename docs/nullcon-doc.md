# Светоподобная свёртка: скаляр фокусировки из счёта

6 октября 2026, ночь. Побочный, но важный результат при составлении
плана: нужная физике комбинация оказалась **лучше всего измеренной**.

Запуск: `python3 code/nullcon.py` (разбор набора `pencil.py`).

## Что это за величина и почему именно она

Для светоподобного `k ∝ (1, n̂)` в конформных координатах перекрёстных
членов нет по симметрии, поэтому

    R_μν k^μ k^ν = R_ηη + R_xx

то есть просто **сумма двух компонент, которые карандаш измеряет**
(`pencil-doc.md`: `α ∝ R_ηη`, `β ∝ R_xx`).

Три причины, по которым нужна именно она, и все три — физика:

1. **Вакуумное уравнение.** `R_μν k^μk^ν = 0` для ВСЕХ светоподобных
   `k` равносильно `R_μν = λ g_μν`, то есть вакууму с космологической
   постоянной. Это и есть левая часть вакуумного уравнения Эйнштейна.
2. **Условие энергии.** `R_μν k^μk^ν ≥ 0` есть условие энергии на
   светоподобном направлении — то, на чём стоят теорема фокусировки и
   теоремы о сингулярностях.
3. **Фокусировка.** Ровно эта величина входит в уравнение Райчаудхури
   для светоподобного пучка, то есть она и есть причина, по которой
   тяготение притягивает.

## Почему она измеряется лучше компонент

`α` и `β` в подгонке сильно **положительно** скоррелированы (около 0.9),
потому что столбцы плана почти коллинеарны. Значит их **разность**
определена плохо, а **сумма** — хорошо. Разность даёт скаляр `R`, сумма
даёт светоподобную свёртку:

| величина | из счёта | истина | точность |
|---|---|---|---|
| скаляр `R ℓ²` (разность) | +0.0183 ± 0.0087 | +0.0072 | **120 %** |
| свёртка `R_μν k^μk^ν ℓ²` (сумма) | см. ниже | | **17 %** |

**В семь раз лучше на тех же данных.** Физике нужна сумма — повезло.

Ошибка берётся складным ножом по самой **сумме**, а не квадратурой
слагаемых: при корреляции +0.9 квадратура завысила бы её вдвое.

## Результат

| | из счёта | истина | σ | точн. | условие энергии |
|---|---|---|---|---|---|
| линейное, `X₂` | **+0.00429 ± 0.00083** | +0.00490 | 0.7 | **17 %** | выполнено (5.2 σ) |
| линейное, `X₃` | **+0.00490 ± 0.00086** | +0.00490 | **0.0** | 18 % | выполнено (5.7 σ) |
| квадратичное, `X₂` | −0.00207 ± 0.00067 | −0.00240 | 0.5 | 28 % | НАРУШЕНО (3.1 σ) |
| квадратичное, `X₃` | −0.00117 ± 0.00078 | −0.00240 | 1.6 | 32 % | НАРУШЕНО (1.5 σ) |

**Знак различён во всех четырёх строках.** У линейного семейства
`4h² > 0` — условие энергии выполнено; у квадратичного `−2c < 0` —
нарушено, и верно: это семейство не отвечает никакой физической материи,
оно взято как математический контроль.

## Что это значит

**Величина, на которой стоят фокусировка и теоремы о сингулярностях,
в причинном множестве считается — и считается с 17 %.**

И левая часть **вакуумного** уравнения Эйнштейна, таким образом, уже
есть: условие `R_μν k^μk^ν = 0` для всех светоподобных направлений
проверяемо прямо, без материи и без интеграла по путям.

Это меняет порядок работ: доводить до точности надо не скаляр `R`
(`plan-step5.md`, пункт A3, низкий приоритет), а именно свёртку (пункт
A1). Вчетверо больше набора даёт 5 % вместо 17 %.

## Чего это НЕ даёт

- `R_μν k^μk^ν = 0` для всех `k` оставляет свободной космологическую
  постоянную: `R_μν = λ g_μν` ему удовлетворяет. Отличить вакуум от
  вакуума с `Λ` этой величиной нельзя.
- Вейля она не видит, как и всё остальное у нас: это свёртка Риччи.
  Снаружи звезды и в гравитационной волне она читает нуль.
- Направление `k` берётся из геометрии пучка (ориентации интервалов), а
  не из метрики. Но само семейство ориентаций — внешний объект, и
  вопрос, как его задать одним порядком, остаётся (в причинном множестве
  относительная скорость двух цепей измерима — `A = γ²`, — но строго это
  не замкнуто).
