# Три масштаба: почему вес бессилен, а ограничение достаточно

> **ОТОЗВАНО 11 октября, вечер — см. `retraction-doc.md`.** Вывод «вес
> бессилен» НЕВЕРЕН. Масштаб `N^{3/2}` относится к действию на ЗАСЕВАХ,
> а на слоистых множествах (которые и создают энтропию) действие растёт
> как `n²`: показатели 2.004, 1.998, 2.003 против 1.027 у засева.
> Подавление `e^{+βS}` бьёт энтропию при β > 0.96. Ряд
> `n ln n ≪ n^{3/2} ≪ n²` сам по себе верен, вывод из него — нет.

Дата: 11 октября 2026. Код: `weight.py`, `dimcount.py`.
Предшествует: `prostoe-doc.md` (профиль обилий — единственная
неимитируемая величина), `crit-geom-doc.md` (действие БД геометрию
подавляет).

## Замер: перебивает ли вес из профиля энтропию

Вес `S_prof(C)` = χ² профиля `N_m/N₀` до центра засева, в единицах
поконфигурационного разброса. Локален и безразмерен — то есть годной
формы. Вопрос «перебивает ли энтропию» есть сравнение показателей по
`N`: подавление `exp(−β·χ²)` при `χ² ~ N^p` против числа конкурентов
`2^{N²/4}`, то есть `p` против 2.

| ансамбль | `p` |
|---|---|
| контроль (засев) | −0.26 (стоит на ~8, как и должно при 8 условиях) |
| **Клейтман–Ротшильд `k`=3 `q`=0.5** | **+0.56** |
| `k`=6 `δ`=2 | +1.55 |
| `k`=13 `δ`=1 | +1.67 |
| энтропия | **2.00** |

Худшее — в выделенной строке: **чемпион по энтропии имеет и самый
медленный рост χ²**. Нужное `β` росло бы как `N^{1.44}` — не константа
связи, а подгонка под размер. (Оговорка: ряд КР шумный, 1381 / 294 /
1201 / 3167, показатель 0.56 ненадёжен; но даже наибольший из
измеренных, 1.67, меньше двух, и вывод от этого не зависит.)

**Обобщение.** Обилия интервалов растут как `N^{3/2}` (`nm-doc.md`),
значит ЛЮБОЙ вес, собранный из локальных величин — наш профиль,
действие БД, что угодно — имеет `p ≤ 3/2`. Разрыв в показателе не
закрывается выбором весов. Это объясняет все девять попыток одной
строкой, включая сегодняшнюю: различитель может быть неимитируемым и
при этом не быть правилом отбора.

## Следствие: менять надо пространство, а не вес

Порядок размерности ≤ `d` есть пересечение `d` линейных порядков, значит
таких не больше `(n!)^d`, то есть `ln ≤ d·n·ln n`. Тогда три масштаба
ложатся в ряд:

```
n·ln n          ≪        n^{3/2}        ≪        n²
энтропия                 локальный               полная
при dim ≤ d              вес                     энтропия
```

Локальный вес сидит **ровно между**: против полной энтропии бессилен,
против энтропии при ограниченной размерности достаточен.

## Коэффициенты, а не только показатели

`dimcount.py`, точное перечисление (счёт совпал с известным: 2, 5, 16,
63, 318, 2045):

| `n` | порядков | `dim ≤ 2` | доля | `ln(всего)/n²` | `ln(dim2)/(n ln n)` |
|---|---|---|---|---|---|
| 4 | 16 | 16 | 1.000 | 0.173 | 0.500 |
| 5 | 63 | 63 | 1.000 | 0.166 | 0.515 |
| 6 | 318 | 315 | 0.991 | 0.160 | 0.535 |
| 7 | 2045 | 1956 | 0.956 | 0.156 | 0.556 |

Полная энтропия уже насыщена к `ln2/4 ≈ 0.173`; столбец при `dim ≤ 2`
идёт 0.50 → 0.56 при границе 2. Подстановка `n` = 1000:

| масштаб | значение |
|---|---|
| энтропия при `dim ≤ 2` | ≈ 1.4 · 10⁴ |
| **локальный вес `n^{3/2}`** | ≈ 3.2 · 10⁴ |
| полная энтропия | ≈ 1.7 · 10⁵ |

Вес проигрывает полной энтропии в пять раз и выигрывает у ограниченной
вдвое.

Оговорка о силе счёта: при `n ≤ 7` ограничение почти не кусается (доля
0.956), потому что препятствия размерности 3 требуют не менее шести
элементов, а оценка `(n!)²` ещё не связывает. Коллапс доли показывает
не счёт, а оценка; счёт даёт коэффициенты и согласие с архивом (вне
`dim ≤ 2`: 3 при `n`=6 и 89 при `n`=7, при 3 и 21 МИНИМАЛЬНЫХ
препятствиях).

## Что это меняет в постановке

Задача об энтропии решается не лучшим действием, а **кинематическим
ограничением**: причинное множество обязано быть вложимым (ограниченная
порядковая размерность), и уже внутри этого пространства обычный
локальный вес работает. Это ровно ответ на вопрос «что во фрактале
запрещает другие конфигурации» — не вес, а правило построения.

Следующее: внутри `dim ≤ d` проверить, выбирает ли вес из профиля
засевы, — и оценить, при каких `n` ограничение начинает кусаться
по-настоящему.

## Поправка: ограничение — ВЛОЖИМОСТЬ, а не порядковая размерность

Дата: 11 октября, вечер. Код: `ordim.py`, `sk_build.py`. Формулировка
выше («кинематическое ограничение по порядковой размерности») проверена
на самом засеве и оказалась **неверной для 4d**. Вывод при этом выживает,
меняется только формулировка.

### 1+1: ограничение точное и чисто порядковое

Световые координаты `u = t+x`, `v = t−x` дают

    x ≺ y  ⟺  u_x < u_y  и  v_x < v_y

то есть причинный порядок в 1+1 **ровно двумерен** в порядковом смысле, а
засев в диамант есть буквально случайные точки в квадрате с
покоординатным порядком.

Замер (`ordim.py`, нижняя граница через индуцированный стандартный
пример `S_k`): у засева 1+1 наибольшее `k` равно **2** при `N` = 100,
200, 400, 800 и при любом усилии поиска. Предсказание до замера
подтверждено.

### 4d: размерность НЕ ограничена, и это построено, а не найдено

Жадный поиск оказался ограничен **усилием**: при `N`=800 он давал
2/2/3 при малом переборе и 3/4/4 при большом. По такому заключать
нельзя — поэтому построение.

Нужны пары, где `a_i` пространственноподобна своему `b_i` и причинна
всем остальным. Кладём `a_i = (0, r·u_i)`, `b_i = (T, −r·u_i)` при
`|u_i| = 1`:

    i = j:    |Δx| = 2r              нужно T < 2r        (несравнимы)
    i ≠ j:    |Δx| = r|u_i + u_j|    нужно T > r|u_i+u_j| (a_i ≺ b_j)

Окно существует, когда `|u_i + u_j| < 2` при `i ≠ j`, то есть когда
единичные векторы различны. В трёх пространственных измерениях их
сколько угодно, в одном `u = ±1` — ровно два.

Проверка (`sk_build.py`): в 4d `S_k` построен при `k` = 3, 5, 8, 12, 20,
все четыре условия выполнены. В 1+1 окна нет уже при `k`=3 (требуется
`2.0000 < T < 2.0000`) — контроль прошёл.

**Следствие:** порядковая размерность причинного порядка в 4d не
ограничена.

Попутно объяснилась и слабость поиска, количественно: окно сужается как
1.099 → 1.451 → 1.674 → 1.790 → 1.877 → 2, то есть относительная ширина
`~1/k`. Чтобы такая конфигурация случайно выпала в засеве, нужно `N`,
растущее степенью `k`. Поэтому при `N`=800 поиск упирался в 3–4 и рос с
усилием.

### Что это меняет, а что нет

Формулировка ограничения — **вложимость**, а не ограниченная порядковая
размерность. Оценка энтропии при этом выживает целиком: вложимое
причинное множество задано `n` точками в `d`-мерной области, значит таких
не больше `(объём/разрешение)^n = exp(O(d·n·ln n))`. Ряд
`n·ln n ≪ n^{3/2} ≪ n²` стоит, и вывод «решает ограничение, а не вес»
не меняется.

Но появляется различие, которое стоит назвать точно: **в 1+1 ограничение
чисто порядковое** (`dim ≤ 2` — утверждение о самом порядке, без всякой
геометрии), **а в 4d — нет**: там требуется вложение. Это и есть
precise-формулировка того, почему 1+1 в теории причинных множеств
«лёгкая», а 4d тяжёлая.

### Что из этого строить

В 1+1 кинематика теперь **решена**: засев есть равномерно случайная пара
перестановок, и пространство конфигураций перечислимо. Значит всю идею
«ограничение плюс локальный вес» можно проверить там до конца, без
проблемы выборки:
* энтропия внутри `dim ≤ 2` — действительно ли `exp(O(n ln n))`;
* равномерно случайный двумерный порядок — засев или нет (у порядков
  разное число реализаторов, и равномерная мера по порядкам не равна
  равномерной по парам перестановок);
* нужен ли вообще вес, если ограничение уже наложено.
