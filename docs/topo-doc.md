# Заряд как топологический инвариант

### Дополнение к `ORDER-final.md`

Идея: заряд — не метка, а свойство **формы** куска графа. Число независимых циклов вокруг
события, как число дырок в бублике.

Порядок ацикличен, но граф прямых связей **без направления** циклы иметь может.

---

## ⭐ Треугольников нет по построению

$$\text{проверено: } 0 \text{ треугольников из } 2000 \text{ связей}$$

**Причина строгая:** прямая связь — пустой интервал. Если $a$ раньше $b$ и $b$ раньше $c$,
то между $a$ и $c$ есть $b$, значит связь $a{-}c$ **не прямая**.

> Треугольник в графе связей невозможен. Это запрет из правила, а не свойство реализации.

---

## Циклы длиннее трёх есть

Интервалы 12–25 событий:

| | значение |
|---|---|
| интервалов с нулём циклов | 59 из 232 (**25%**) |
| распределение циклов | 59, 26, 20, 15, 16, 13, 12, 14 |

Три четверти интервалов циклы имеют.

### ⊗ Но число циклов определяется числом связей

| корреляция циклов с | значение |
|---|---|
| размером интервала | +0.831 |
| **числом связей** | **+0.969** |

Формула $E - V + C$: при фиксированных $V$ и $E$ число компонент почти не меняется
(разброс 0.00–0.50). **Ничего сверх подсчёта связей.**

## Четырёхугольники: остаётся ли что-то

| | значение |
|---|---|

Остаток после нормировки заметный — казалось, есть что мерить.

### ⊗ Но остаток ни с чем не связан

| признак | корреляция с остатком | **при фиксированной степени** |
|---|---|---|
| прошлое | −0.290 | **−0.059** |
| будущее | −0.210 | **−0.094** |

| время | −0.079 | −0.015 |
| перекос конусов | −0.072 | +0.020 |

**При фиксированной степени все связи падают почти до нуля.** Остаток — шум.

## Итог

⭐ **Найден строгий запрет:** треугольников в графе связей нет по построению
(0 из 2000 проверенных).

⊗ **Топологического заряда не нашлось.** Число циклов на 97% определяется числом связей;
остаток после нормировки ни с одной величиной не связан.

⚠ Проверены циклы длины 3 и 4. Более длинные и более тонкие инварианты (числа Бетти
высших порядков, гомологии) не проверялись.
