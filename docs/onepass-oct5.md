## 1. Тяготение в радарном кадре: закон по массе есть, по расстоянию нет

Наблюдатель — плотная цепь по оси через центр; разрежение — запретный для
ФОНА шар вокруг того же центра (цепь остаётся: она прибор, не вещество).
Тогда радарное расстояние события от наблюдателя ЕСТЬ его расстояние от
вещества, посчитанное счётом.

### ⊗ Пойманная ошибка: согласование по высоте

Сначала ход часов брался как `h / |прошлое|^(1/4)` и сравнивался при
СОВПАДАЮЩЕЙ ВЫСОТЕ. Но высота стоит в ЧИСЛИТЕЛЕ: зафиксировав `h`, я
приравнивал числитель и оставлял только знаменатель, который при удалении
событий обязан вырасти. Вышел положительный «сигнал» +0.367 (19.3σ) и
контроль «рассыпано» тоже дал профиль +0.084 — мерился артефакт.

Починка оказалась улучшением: **кадр даёт время сам**, значит
согласовывать не нужно. Ход часов есть

```
высота / радарное время  =  собственное время / координатное
```

то есть ровно гравитационное замедление, без посторонних величин.

### Знак верен, контроли чисты

| `r` от центра | в `ℓ` | дефицит | сигм | контроль рассыпано |
|---|---|---|---|---|
| 0.244 | 2.8 | **−0.02119** | **25.6** | 0.5σ |
| 0.332 | 3.8 | −0.00062 | 2.2 | 0.2σ |
| 0.420 | 4.8 | −0.00085 | 3.1 | 0.7σ |
| 0.507 | 5.8 | −0.00187 | 7.2 | ⊗ граница мира (радиус 0.5) |

Дефицит ОТРИЦАТЕЛЕН — часы у вещества идут медленнее, как велит ОТО.
Рассыпанное удаление того же числа событий не даёт профиля. Нулевая
глубина даёт ровно `0.00000` во всех полосах.

### Закон по массе: линейный

Радиус ФИКСИРОВАН (0.20 = 2.3 `ℓ`), меняется только доля оставленных
событий, то есть только масса:

| масса `M` | дефицит у края | сигм |
|---|---|---|
| 100 | −0.00657 | 4.7 |
| 200 | −0.01137 | 6.2 |
| 294 | −0.01625 | 8.1 |
| 395 | −0.02369 | 12.7 |

```
дефицит ~ M^+0.918
```

**Это слабое поле ОТО** (`замедление ~ GM/r` — линейно по массе), и это
первый количественный закон проекта.

### Поле, а не поверхность

При изменении радиуса дальнобойность РАСТЁТ с массой: отношение
«дальнее поле к ближнему» идёт 0.011 → 0.008 → 0.018 → 0.030 при радиусе
0.08 → 0.26. То есть эффект не прилипает к поверхности.

⚠ Но в том замере менялись радиус И масса вместе. При фиксированной
геометрии дальнее поле не обнаруживается: 1.1…1.5σ. Это поправка к
прочтению предыдущего прогона.

### Закона спадания нет, и цена его теперь известна

Профиль немонотонен: резкий поверхностный член, затем хвост на уровне 3 %
от края при 2–3σ, затем подъём, который есть граница мира. Подогнанный
`r^-3.27` бессмыслен.

Причина считается: радиус мира 5.7 `ℓ`, дырка 2.3 `ℓ`, чистого места под
профиль — полторы ячейки. Для подгонки показателя нужно ≥ 10 `ℓ` снаружи
объекта, то есть радиус ≥ 13 `ℓ`:

```
радиус/ell = 0.5 * (7.64 N)^(1/4) = 13   =>   N ≈ 60000
```

План говорил 32000 — порядок тот же, число уточнено.

## 2. Лоренц без координат: исполнено

В §16 продольная координата бралась как радиальное радарное расстояние со

Заменено своим же инструментом проекта (`signed.py`): разность радарных
расстояний до ДВУХ опорных цепей на `±0.16` по оси движения.

| быстрота | `A` | `γ²` | промах | качество |
|---|---|---|---|---|
| 0.3 | 1.0904 | 1.0927 | **−0.21 %** | 0.9978 |

## 3. Сглаженное действие: окно по `ħ` ОТКРЫВАЕТСЯ

### Формула из источника, проверенная пределом

[Dowker & Glaser, arXiv:1305.2588](https://arxiv.org/pdf/1305.2588).
Смысл сглаживания: событие оставляется с вероятностью `ε`, местный
оператор применяется к прореженному множеству, результат усредняется. У
пары с `n` событиями между ними остаётся `m ~ Binomial(n, ε)`:

```
f(n, ε) = Σ_m C_{m+1} · C(n,m) · ε^m · (1−ε)^(n−m),    C = (1, −9, 16, −8)
```

При `ε = 1` даёт ровно `C_{n+1}` и нули дальше — **предел проходит, и это
проверяется в коде до всякого замера**. Выловленная из PDF запись при
`ε = 1` давала нули при `n ≥ 1`, то есть либо огрех вычитки, либо иная
индексация; взята форма, которая проверяется.

### Цель поставлена точнее, чем «σ/⟨⟩ < 1»

Отношение к среднему можно сделать любым постоянным сдвигом (`α` входит
аддитивно). Физический критерий: **разброс против разницы между
геометриями**. Окно существует, если `ΔS` (плоское против дырки)
превышает `σ(S)`.

| `ε` | `⟨S⟩` | `σ(S)` | `ΔS` дырка | `ΔS/σ` | окно |
|---|---|---|---|---|---|
| 1.00 | −596.1 | 2352.2 | 483.8 | 0.206 | нет |
| 0.60 | 648.3 | 765.5 | 212.3 | 0.277 | нет |
| 0.35 | 2234.3 | 571.8 | 140.2 | 0.245 | нет |
| 0.20 | 5065.3 | 745.4 | 714.7 | 0.959 | нет |
| 0.10 | 10741.1 | 813.2 | 2013.2 | **2.476** | **ДА** |
| 0.05 | 19722.8 | 752.6 | 4460.1 | **5.926** | **ДА** |

### Решающий контроль: не вырождение

Я опасался, что при малом `ε` разложение `f ≈ 1 − 9nε` сводит действие к
СЧЁТУ ОТНОШЕНИЙ, и тогда окно тривиально. Проверено:

| `ε` | корр. `S` со счётом отношений | `Δ`остатка / `σ`остатка |
|---|---|---|
| 1.00 | 0.107 | 0.928 |
| 0.35 | 0.047 | 0.008 |
| 0.10 | −0.220 | **5.370** |
| 0.05 | −0.187 | **9.112** |

Корреляция НИЗКА при всех `ε` — вырождения нет, опасение неверно.
Разложение годится лишь при `nε ≪ 1`, а при `ε = 0.05` и `n` до сотен
сглаживание отбирает пары с `n ≲ 60`, то есть работает промежуточным
масштабом, как и задумано. После вычитания линейной зависимости от счёта
отношений отклик держится: **5.4 и 9.1**.

> ⊗ **ПОПРАВКА К §19.** Там сказано: «годного `ħ` не существует ни при
> каком размере мира». Это верно для **несглаженного** действия (при
> `ε = 1` отношение 0.21…0.93, то есть окна действительно нет). Со
> сглаживанием окно открывается и растёт: **0.21 → 2.48 → 5.93**.
> Квантовый слой НЕ закрыт — ему нужен был сглаженный оператор, ровно
> тот, за которым его и вводили.
