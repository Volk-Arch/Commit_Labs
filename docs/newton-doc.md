Воспроизведение: `python3 code/bigfall.py --n 8000 --seeds 24 --scatter`

## Результат

> **Гравитационное замедление времени `∝ M/r`, выведенное из одного
> отношения «раньше».** Оба показателя измерены и согласуются с
> предсказанием слабого поля общей теории относительности в пределах
> одной сигмы.

```
показатель по РАССТОЯНИЮ:  r^(-1.067 ± 0.069)     ОТО: -1
показатель по МАССЕ:       M^(+0.890 ± 0.139)     ОТО: +1

ЗАКОН:  дефицит хода часов ~ M^0.89 / r^1.07
```

Погрешности — складным ножом по 24 засевам.

## Как мерится

Ни координат, ни расстояний на входе. Три порядковые величины:

| величина | как получена |
|---|---|
| **вещество** | разрежение: внутри шара радиуса `rad` фону запрещено (цепь остаётся — она прибор, не вещество) |
| **расстояние** | радарное: для события `x` последнее событие цепи в прошлом `p`, первое в будущем `f`, тогда `ρ = (f − p)/2` по НОМЕРАМ вдоль цепи |
| **ход часов** | `высота / радарное время`, то есть собственное время на координатное — ровно гравитационное замедление |

Радарный метод Эйнштейна, выполненный счётом: `W = 2λr` проекта и есть
радарное расстояние (`radar-doc.md`).

## ⊗ Ошибка, которая и была настоящей стеной

Сначала высота считалась по ВСЕМ событиям, включая цепь наблюдателя. Но
плотная цепь из 300 событий сама есть цепь длины 300, тогда как
естественная самая длинная цепь сприклинга идёт как `N^0.25` — десяток-два.
Значит высота события оказывалась почти равна его НОМЕРУ ВДОЛЬ ЦЕПИ, и
отношение `h/τ` вырождалось по построению. Признак был прямо в выводе:
при `N = 8000` и цепи 300 «высота мира» печаталась ровно **300**, и ни
одна полоса не давала двух сигм.

Починка разделяет роли: **прибор даёт координаты, система даёт собственное
время.** Высота считается ТОЛЬКО ПО ФОНУ. После неё «высота мира» стала
16–17 при `N = 8000` и 28–29 при `N = 60000`, то есть естественной.

**И это меняет вывод о цене.** Я оценивал, что для закона спадания нужно
`N ≈ 60000`, потому что при `N = 2200` «чистого места под профиль
оставалось полторы ячейки». Оценка считалась по испорченному замеру:
мешала не теснота мира, а вырожденная высота. Закон виден уже при
`N = 8000`.

⚠ Этой же ошибкой затронут закон по массе `M^+0.918` из §21 — он
перемерен: `M^(+0.890 ± 0.139)`. Числа близки, но прежнее значение было
получено неверно и совпало случайно.

## Контроли

1. **Нулевая масса** — ровно `0.000000` во всех полосах, при всех `N`.
2. **Рассыпанное удаление** того же числа событий по всему ромбу: в
   **47–56 раз** меньше сигнала и спадает как `r^-0.37` вместо `r^-1.03`.
   То есть профиль не объясняется тем, что «событий стало меньше».
3. **Парно по засеву**: мир и цепь те же, разница только в дырке.
4. **Высота естественная** (16–17 при `N = 8000`, 28–29 при 60000) —
   печатается каждым прогоном как защита от возврата пойманной ошибки.
5. **Покрытие кадра** 0.78 — у события должны быть и прошлое, и будущее
   на цепи.

## Как это считается при N = 60000

Полная матрица отношений (3.6·10⁹ записей) не строится, и мощности
интервалов не нужны вовсе:

- **высота** — просмотр по времени блоками: вклад прошлых блоков берётся
  матрично, внутри блока последовательно. `O(N²)` сравнений без хранения;
- **радарные координаты** — `O(N · длина цепи)` = 1.8·10⁷, даром.

Один мир при `N = 60000` считается 21 секунду, засев (три мира) — 62
секунды, весь прогон из восьми засевов — 511 секунд.

## Что это значит

Проект получил **количественный закон**, которого ему не хватало всё
время. До этого было сходство: вещество замедляет часы и выгибает цепи с
верными знаками. Теперь есть число: замедление равно `M/r`.

И это ровно та планка, которая была названа в `plan-oct5.md` как
достижимая:

> **Классическая теория пространства-времени из чистого порядка.** Время
> выходит само; пространство выходит относительно полной истории; переход
> между историями есть Лоренц; вещество есть разрежение; и замедление
> времени у вещества идёт как `M/r`.

Остаётся вторая половина тяготения — **отклонение самих цепей** (не их
хода, а их пути). Выгиб измерен качественно (+0.0223, 5.0σ), и теперь его
можно мерить тем же кадром и тем же способом, ожидая показателя `M/r`
для угла отклонения.
