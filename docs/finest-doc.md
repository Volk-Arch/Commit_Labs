# Самый мелкий буст: золото выделяется однозначно

Дата: 12 октября 2026. Код: `code/finest.py`; поиск целых бустов — в журнале сессии
и `code/anisolat.py`.

## Утверждение

У кристалла-тени точный буст g сохраняет интервал Q и в каждой тени обязан быть
вращением определённой формы, иначе шар тени испортится. Поэтому
**cosh η = g₀₀ = a** — целое алгебраическое число a > 1, у которого все сопряжённые
лежат в [−1, 1].

* Если a < 2, все сопряжённые лежат в [−2, 2], и по теореме Кронекера a = 2cos(2π/n).
  Перебор n ≤ 5000 даёт ровно одно n = 10: a = 2cos 36° = **τ**. Других чисел нет
  ни в одной степени поля.
* Иначе a ≥ 2, то есть η ≥ 1.317.
* Обычные решётки (поле Q) дают целое a ≥ 2.

**Буст с cosh η < 2 бывает только у золотого кристалла: cosh η = τ, η = 1.0613.**
Он существует: [[τ,1],[τ,τ]] в (t, x) (проверено в `gold4-doc`).

## Конкуренты из `robust-doc` и новый: анизотропные целые решётки

Целая решётка Z⁴ с формой 7t² − x² − y² − z² не имеет световых векторов вовсе:
7t² не сумма трёх квадратов. Её группа Лоренца кокомпактна, как у золота.

| мир | надёжность min\|интервал\|·√ρ | самый мелкий буст η | самоподобие |
|---|---|---|---|
| золото √5 | 0.146 | **1.061** | есть (×τ) |
| серебро √2 | 0.172 | ≥ 1.53 | есть (×(1+√2)) |
| решётка 7t² − \|x\|² | **0.615** | 2.48 (g₀₀ = 6, найден) | нет |
| решётка 15t² − \|x\|² | 0.508 | 2.06 (g₀₀ = 4) | нет |
| Z⁴, посыпка | 0 | — | — |

По надёжности порядка целые анизотропные решётки лучше золота. Значит, один
критерий золото не выделяет, и в `robust-doc` этот конкурент был пропущен.

## Три требования — один ответ

1. **Надёжный порядок** (нет почти светоподобных пар) оставляет анизотропные
   решётки и кристаллы-тени.
2. **Точное самоподобие** (x → εx переводит мир в мир; это де Ситтер и фрактал из
   `desitter-doc`) отсекает решётки: sL = L только при s = ±1. Остаются тени.
3. **Самый мелкий буст** (лучшее приближение непрерывной относительности) по
   Кронекеру даёт только τ.

Каждое требование физически мотивировано, но выбрано нами. Ни одно по
отдельности золото не выделяет: по первому выигрывает решётка, по первому и
второму — серебро. Золото — единственный мир, который проходит все три.
В 1+1 первое и третье требования уже совпадают на золоте (`robust-doc`).
