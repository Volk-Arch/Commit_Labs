# Словарь «Вселенная как Git» ↔ причинный порядок (по эссе пользователя `universe-as-git.md`, 15 окт.)

Эссе пользователя — метафоры. Часть из них у нас **буквально верна** (причинное множество и есть граф коммитов), часть —
аналогия, часть подсказывает следующий шаг. Статусы: [точно] — совпадение определений; [замер] — проверено у нас;
[аналогия] — образ, не утверждение; [гипотеза] — стоит проверить.

| Git | Причинный порядок / кристалл | Статус |
|---|---|---|
| коммит | событие | [точно] |
| родители коммита | связи в прошлое (у золотого 1+1 ≈ 7 на событие — каждый коммит — «слияние» многих веток) | [точно] / [замер] |
| `git merge-base --is-ancestor A B` | A раньше B (порядок, `core.precedes`) | [точно] |
| `git log B` (все предки) | прошлый световой конус B | [точно] |
| длина самой длинной цепочки коммитов от A до B | собственное время между A и B (длина самой длинной цепи ∝ τ) | [точно] (теорема Бритвелл–Грегори) |
| две ветки, ни одна не предок другой | несравнимые события (пространственно разделены) | [точно] |
| нет ветки `main` | нет выделенной системы отсчёта: «сейчас» — выбор нарезки, не свойство графа | [точно]; урок 15 окт.: слои кристалла — рваное «сейчас», мера «по слою» подвела (`maxwell-doc` §26) |
| сколько коммитов «видят» друг друга | взаимодействие пары из одного порядка: (F/2)·[события несравнимы] (`maxwell-doc` §26, `cov.py`) | [гипотеза], в работе |
| merge conflict: две правки одной строки | принцип Паули: два одинаковых фермиона не могут быть в одном состоянии | [аналогия], см. ниже |
| `a == b`, но `a is not b` | одинаковые частицы: у квантовых **нет** отдельной «личности» — обмен местами меняет амплитуду лишь на знак ± | [точно] (это и есть статистика) |
| коммит необратим после push | стрела времени: порядок сам по себе направлен (нет «раньше» назад) | [точно] для порядка; термодинамика — отдельно |
| для света нет времени | у пары событий на световом луче самая длинная цепь между ними — без промежуточных событий (связь), τ = 0 | [точно] в пределе |
| `push --force`, чёрная дыра | горизонт: события, из прошлого которых нельзя попасть в наше будущее | [аналогия] |

## Паули: что из этого следует для нас

* **Знак при обмене.** Амплитуда пары у нас — матрица Ψ[k₁, k₂] по парам событий (`cov.py`). Одинаковые бозоны: Ψᵀ = Ψ;
  фермионы: Ψᵀ = −Ψ, и тогда Ψ[k, k] = 0 — две частицы не могут «закоммитить» одно событие (тот самый merge conflict).
* **Но навязать знак руками нельзя.** У скалярных квантов кристалла спектр iΔ симметричен (±) — они бозоны строго
  (`maxwell-doc` §23); антисимметризовать скаляры = нарушить связь спина и статистики, это было бы «читерство». Честный путь —
  спинорное ядро (фермионы сами по себе), пункт роадмапа уровня 2.
* **Подсказка для 1+1 [гипотеза].** В одном пространственном измерении «два фермиона» и «два бозона, которые не могут
  пройти друг сквозь друга» дают одинаковые энергии (отображение Жирардо). На причинном множестве «не пройти друг сквозь
  друга» — это «мировые линии не пересекаются», условие чистого порядка. Это может быть первым честным Паули в 1+1 — до спиноров;
  в 3+1 такой обход не работает, там нужны спиноры.

## Первый опыт «правила пересечений» (15 окт., `code/goldlab_checks/pauli1.py`) [замер, отрицательный]

Две одинаковые частицы (Джонстон, сумма по цепочкам). H₀ — сумма по парам цепочек **без общих событий** (запрет встречи,
λ = 0), D — определитель (фермионы). Миры 12 и 16, m = 1 и 0.5: H₀ ≠ D (остаток подгонки H₀ ≈ r·D — 0.77…0.996).
**Запрет встречиться в одном событии — ещё не Паули:** цепочки кристалла прыгают и меняются местами слева–справа, не имея общего
события. Нужен запрет именно на **смену порядка слева–справа** (геометрическое пересечение мировых линий, в 1+1 определимое
порядком) — следующий опыт; для него нужен другой алгоритм (состояние пары с текущими отрезками обеих линий).

## Второй опыт: зигзаг-частица и «не пересекаться» (15 окт., `code/goldlab_checks/zigzag.py`, `checker*.py`) [замер]

* **Сеть шагов.** «Самые световые» связи кристалла длинные и пересекаются массово (123 346 пересечений на 2 284 рёбрах при L = 12);
  кратчайшие связи вправо/влево — 2 744 пересечения на 2 174 рёбрах; жадно собрать плоскую сеть, покрывающую все события, не
  удаётся (шаг вправо есть лишь у 56 %, влево у 35 %). Плоской «шахматки» на золотом 1+1 нет — пути меняются местами между событиями.
* **Зигзаг-частица** (шахматка Фейнмана на кратчайших связях: прямо ×1, поворот ×(−i·m·Δt)) — двухкомпонентная (вправо/влево),
  то есть 1+1-Дирак. Две такие частицы: сумма по историям, которые **не пересекаются и не встречаются** (H), против определителя
  (F, фермионы). Счёт проверен: без правила H = K₁⊗K₂ до 4·10⁻¹⁶. Итог: H ≈ (0.62…0.87)·F, остаток 0.36…0.55 (L = 8…12, m = 0, 1).
  **Не совпадает — и не должно:** у релятивистских двухкомпонентных частиц правый и левый «бегуны» проходят друг сквозь друга
  и будучи фермионами; «жёсткие стенки = фермионы» (Жирардо) — для медленных частиц без внутренней степени свободы.
* **Что такое правило пересечения на самом деле.** В 1+1 статистика — это **фаза при обмене = фаза за каждое пересечение историй**:
  θ = 0 — бозоны, θ = π — фермионы, промежуточные — эниони (в 1+1 возможны). С θ = π сумма по всем парам историй даёт ровно
  определитель, и амплитуда двух частиц в одном состоянии (событие + направление) обращается в ноль — **Паули**. Но само θ = π
  пока выбрано, а не выведено.
* **Решающий следующий опыт.** Что выбирает θ: связь спина и статистики. Для скалярных квантов мы показали — спектр iΔ симметричен
  ⇒ возможен только коммутатор ⇒ бозоны (`maxwell-doc` §23). Для зигзаг-частицы — построить её поле и проверить, допускает ли оно
  коммутатор или только **антикоммутатор** (положительность). Если зигзаг ⇒ только фермионы — Паули выведен из порядка + зигзага.
* **Разведка спин–статистики зигзага (`spinstat.py`) [замер, нерешающий].** Для запаздывающего пропагатора зигзага по состояниям
  «событие + направление» спектр i(K − K†) тоже **строго симметричен** (± до 10⁻¹⁵), как у скаляра. Причина — та же структура:
  смена знака левых состояний превращает −i·m·Δt в +i·m·Δt (комплексное сопряжение). Значит, этот тест сам по себе зигзаг от
  скаляра не отличает: для Дирака решает положительность ядра **с вставкой γ⁰** (скалярное произведение Дирака, у нас — спаривание
  правого и левого состояний одного события), его ещё надо корректно определить на кристалле. Заметка: амплитуды шахматки растут
  (наибольшее собственное ~10³ при L = 10) — нормировка зигзага не унитарна, её тоже нужно поправить.

## Одно правило на разных уровнях? (вопрос пользователя 15 окт.)
* **Факт:** почти всё полученное — подсчёт в одном порядке двух фигур: **цепочек** (время = длина цепочки, движение частицы =
  взвешенное число цепочек) и **несравнимых пар** (пространство, взаимодействие пары по несравнимости); размерность — доля
  упорядоченных пар, поле заряда — число связей с его линией. Цепочки — «конвергенция», несравнимость — «дивергенция».
* **Факт:** правило самоподобно — кристалл переходит в себя при растяжении в τ; тот же τ — в бусте (η₀ = arcch τ) и в «тиканье»
  слоёв времени (1 : τ : τ², слово Фибоначчи). Это неподвижная точка «ренормгруппы» для геометрии.
* **Уровни** (атом, ядро) возникают из того, что ломает самоподобие, — из массы (свой масштаб длины).
* **Гипотеза [проверяемо]:** «руками» взятое (масса, закон движения, монета, нити) — то же правило на другом уровне. Первый
  опыт: растянуть кристалл в τ раз — частица массы m должна стать в точности частицей массы m·τ.
* Предостережение: узоры легко увидеть там, где их нет; мерило — сокращение списка «взято руками» и сошедшиеся предсказания.
* **Опыт (вечер 15 окт., `code/goldlab_checks/onerule.py`) [замер].** Подкристалл «тень в шаре r/τ» — это в точности тот же
  кристалл, растянутый в τ раз (377 из 377 внутренних событий), и он лежит внутри мелкого (1153 → 443, отношение 2.603 ≈ τ²).
  Вопрос: амплитуды частицы мелкого уровня между событиями крупного — снова ли правило Джонстона на крупном?
  * **без массы — да, точно** (остаток 9·10⁻¹⁵): безмассовое правило — «½ за каждое отношение порядка» — одно и то же на любом
    уровне (впрочем, и на любом подмножестве: это свойство самого порядка);
  * **с массой — нет:** m = 0.5 — подгонка даёт m′ = 0.49 (масса в физических единицах сохраняется, в единицах зерна растёт в τ),
    но остаток 0.25 (у случайного прореживания 0.48); m = 1 — 0.82 (0.89): на крупном зерне масса уже не разрешается.
  * **Вывод:** «одно правило» точно для причинной части (порядок, свет) — она одинакова на всех уровнях; **масса — именно то, что
    не повторяется**: она вводит масштаб и ломает самоподобие, как и ожидалось. Гипотеза «m → m·τ точно» не подтвердилась (в единицах
    зерна это лишь размерность); золотое укрупнение лучше случайного, но не точное. Открыто: существует ли массовое правило,
    которое золотое укрупнение воспроизводит точно (неподвижная точка с массой)?
