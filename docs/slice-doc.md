# Уравнения среза: гравитация, которую тела создают сами

14 октября 2026, вечер (автономный час). Код: `rt_spherical.py`, `rt_normals.py`. Роадмап, уровень 3, главный пункт.

## 1. Мысль [вывод]

У нас гравитация — изгиб среза золотого кристалла в «тень»: мир — это 4-мерная поверхность y^A(x) в плоском объемлющем
пространстве с формой следа (R^{1,7} для 3+1, одно время), индуцированная метрика g_μν = ∂_μ y^A ∂_ν y^B η_AB
(`bentcut-doc`). Это **ровно постановка гравитации вложения** (Редже–Тейтельбойм, 1975): переменная — не метрика, а
форма поверхности.

Отсюда развилка — какой закон у среза:
* **(А) правило вакуума** («малые ромбы любой ориентации плоские вне вещества», `golden-doc`) — это уравнения
  Эйнштейна G = 8πT. Срез обязан давать эйнштейновскую метрику.
* **(Б) экстремум действия по форме среза.** Наше действие — счёт событий / действие Бенинкасы–Доукера (на изогнутом
  срезе = Эйнштейн–Гильберт индуцированной метрики). Вариация по форме y^A даёт **уравнения Редже–Тейтельбойма**:
  ∂_μ(√−g (G^{μν} − 8πT^{μν}) ∂_ν y^A) = 0 ⇔ (G^{μν} − 8πT^{μν}) b^a_{μν} = 0 (b — вторая фундаментальная форма).
  Они слабее Эйнштейна: G = 8π(T + τ), где τ — «материя вложения», τ^{μν} b^a_{μν} = 0. Группа Пастона (СПбГУ)
  предлагает τ как тёмную материю и сообщает согласие с гало галактик (в 10-мерном объемлющем пространстве):
  [Kuptsov, Ioffe, Manida, Paston, arXiv:2210.13272](https://arxiv.org/abs/2210.13272); обзор подхода —
  [Paston, Sheykin, arXiv:1402.1121](https://arxiv.org/abs/1402.1121).

## 2. Замер на нашем «винтовом» срезе [замер]

Срез чёрной дыры из `bentcut-doc`: T = t, x⃗ = r n⃗, y₅ + i y₆ = A(r) e^{iωt}, y₇ = B(r) (время — поворот в тени).
Метрика g_tt = 1 − ω²A², g_rr = −(1 + A'² + B'²) — при ω²A² = 2M/r это ровно Шварцшильд.

1. Символьно выведены уравнения Р–Т для этого класса (`rt_spherical.py`): для y⁰ = t — тождество; для остальных —
   нетривиальные ОДУ на A, B.
2. Матрица условий τ^{μν} b^a_{μν} = 0 (3 нормали × 3 компоненты τ = diag(ε, p_r, p_t)) на шварцшильдовом срезе
   **вырождена** (ранг 2, одно сингулярное число ровно 0) при всех проверенных r = 4…40 и ω = 0.3…4. Значит, **срез с
   законом (Б) допускает одну свободную функцию материи вложения** — он не обязан быть шварцшильдовым.
3. Допустимое направление: **ε : p_r : p_t = 1 : −K : −K/4**, отношение p_r/p_t → 4.00 (4.016 → 4.001 при росте r),
   K ≈ 2.3·ω²r² (K ∝ ω² точно: 88.6 / 356 / 1428 / 5714 при ω = 0.5 / 1 / 2 / 4). То есть материя вложения здесь —
   **почти чистое напряжение**: давление огромное, плотность энергии ничтожная (ε ≈ −p_r/K).

## 3. Что это даёт для вращения галактик [оценка, слабое поле]

Сохранение τ для статической анизотропной «жидкости» в слабом поле: p_r' + 2(p_r − p_t)/r = 0, при p_t = p_r/4 ⇒
**p_r ∝ r^{−3/2}**. Активная гравитирующая плотность ε + p_r + 2p_t ≈ 1.5·p_r ∝ r^{−3/2} ⇒ масса M(r) ∝ r^{3/2} ⇒
скорость на орбите **v ∝ r^{1/4}** — растущая кривая вращения (у плоских кривых нужно ρ ∝ r^{−2}). Это грубая оценка:
фон шварцшильдовский, A и B не пересчитаны, ω — свободный параметр вложения.

## 4. Статус и что дальше

* [вывод] Наш изогнутый срез = гравитация вложения; правило вакуума (А) даёт Эйнштейна, экстремум действия по форме (Б)
  даёт Редже–Тейтельбойма с «материей вложения».
* [замер] В сферическом винтовом классе (Б) допускает одну функцию τ — почти чистое напряжение, p_r : p_t = 4 : 1.
* [оценка] Её притяжение растёт наружу (v ∝ r^{1/4}) — кандидат на «тёмную материю», но не плоские кривые.
* **Решающий опыт дальше:** на самом кристалле — меняется ли счёт событий (действие БД) при деформации среза вдоль
  допустимого направления? Если действие стационарно — закон среза (Б), и тёмная материя у нас «бесплатная»; если нет —
  (А), чистый Эйнштейн. Второе: полная система ОДУ на A, B с материей вложения (без опоры на Шварцшильд).

*Простыми словами:* если гравитация — это изгиб «листа» мира в скрытые направления, то естественный закон для листа —
изгибаться так, чтобы «счёт событий» был наилучшим. Такой закон почти совпадает с Эйнштейном, но разрешает листу
лишнюю «упругость» — невидимое напряжение, которое тоже притягивает. Это готовый кандидат на тёмную материю, и в
нашем сферическом случае он даёт притяжение, растущее с расстоянием. Проверить, какой закон верен, можно прямо на
кристалле.

## 5. Полная (нелинейная) система уравнений среза — решена (`rt_ode.py`, `rt_far.py`)

Состояние (A, A′, B′); на каждом r вторые производные (A″, B″) находятся из трёх условий τ^{μν} b^a_{μν} = 0, где τ = G/8π
индуцированной метрики; интегрирование наружу (РК4). Невязка условий 10⁻¹⁷…10⁻⁴.
* **Проверка:** шварцшильдовы начальные данные остаются Шварцшильдом — v² = r f′/(2f) совпадает с M/(r − 2M) до
  трёх знаков (0.1241 / 0.0554 / 0.0357 / 0.0263 / 0.0172 против 0.1250 / 0.0556 / 0.0357 / 0.0263 / 0.0173).
* **Малое отклонение от Шварцшильда (δA/A = +2 %)** — решение уравнений среза с материей вложения: v² при r = 60
  0.0242 против кеплеровых 0.0173 (+40 %); масса «по пространству» m_eff = r(1 − 1/h)/2 остаётся 1.000 — добавочное
  притяжение идёт **от давления** (ε ≈ 0, p_r > 0, p_r/p_t = 4.0), а не от плотности. δA/A = −2 % — притяжение слабее.
* **Добавочная «масса» по кривой вращения** M_доп(r) = v²r − M: при δA = 0.5 % и 1 % — 0.011 / 0.053 / 0.155 / 0.436 и
  0.033 / 0.111 / 0.313 / 0.872 при r = 20 / 40 / 80 / 160; **наклон log M_доп / log r = 1.50–1.51** — ровно оценка §3:
  M_доп ∝ r^{3/2}, v ∝ r^{1/4}. Дальше r ≈ 250–290 винтовое вложение перестаёт существовать (решение рвётся).
* **Поправка 15 окт. (при сборке каркаса goldlab) [замер].** В `rt_far.py` строка выхода писалась со сдвигом на шаг:
  радиус — старый, состояние — новое; это занижало M_доп на малых r. Правильные числа: δA = 1 % — **0.045 / 0.116 /
  0.316 / 0.873**, δA = 0.5 % — 0.022 / 0.058 / 0.158 / 0.437 при r = 20 / 40 / 80 / 160 (на больших r старые верны).
  Наклон log M_доп / log r на r = 30…160 — **1.45** (не 1.50); локальный наклон растёт: 1.43 (40→80), 1.47 (80→160) —
  к асимптоте 3/2. Радиус, где решение «рвётся», **зависит от шага интегрирования** (161, 203, 236, 300+ при разных
  сетках) — это не физический результат, утверждение «r ≈ 250–290» снято. Вывод раздела не меняется: добавка растёт
  асимптотически как r^{3/2}, плоских кривых в этом классе нет. Опыт `slice_rt` в goldlab считает по-новому.

**Итог [замер].** Если закон среза — экстремум действия по форме (Р–Т), у сферического тела появляется семейство
решений с «невидимым» добавочным притяжением, растущим наружу как r^{3/2} по массе. Это настоящее решение полных
уравнений, а не только оценка. Для галактик (плоские кривые ⇔ M ∝ r) оно растёт быстрее, чем нужно, — сам по себе
этот класс срезов тёмную материю не воспроизводит; нужен более широкий класс (ещё нормали, неоднородное ω) или
закон (А). Решающий опыт на кристалле (стационарно ли действие вдоль этого направления) остаётся следующим шагом.

## 6. Уравнение состояния точно, и роль четвёртого направления тени (`rt_eos.py`, `rt_scan.py`, `rt_y8.py`)

**Точная формула [вывод + замер].** В винтовом классе вторые производные ∂tt (центростремительная в плоскости поворота),
∂rr и ∂θθ (радиальная в мире) вместе с касательной e_r лежат в одном 3-мерном пространстве (n, e^{iωt}, ê_B). После
проекции на нормали — в 2-мерном, поэтому свободная τ есть всегда (ранг 2 — не случайность, а геометрия). Из условия
c₁∂tt + c₂∂rr + c₃∂θθ ∝ e_r:

  **p_t / p_r = −r B″ / (2 h B′)**  (проверка на решении: 0.24930 по уравнениям = 0.24930 по формуле).

С сохранением τ: при p_t/p_r = q давление p_r ∝ r^{−2(1−q)}, добавочная масса M_доп ∝ r^{1+2q}. **Плоские кривые ⇔ q → 0
⇔ B″ → 0.**

**Скан начальных данных [замер].** Девять вариантов (A, A′, B′ при r₀ = 10, отклонения до 100 %), интегрирование до
r = 3000: везде, где решение живёт, **q = 0.250 ± 0.001** на r = 20…2000, B′ ∝ r^{−1/2}. Значение 1/4 — притягивающее:
уравнения среза сами возвращают B′ к шварцшильдовскому спаду. M_доп бывает обоих знаков (притяжение сильнее или слабее
Кеплера), но растёт всегда как r^{3/2}. **В этом классе плоских кривых нет — устойчиво, а не по выбору данных.**

**Четвёртое направление тени [замер].** В R^{1,7} у тени 4 направления, винтовой класс использует 3 (плоскость поворота
+ B). Если взять и четвёртое: радиальная кривая (B(r), D(r)) в тени. Пока кривая прямая (D ∝ B) — свободная τ есть (одна).
**Стоит кривой изогнуться (φ′ = 0.01 или 0.1) — третье сингулярное число становится 5·10⁻⁴…5·10⁻³ вместо 0, свободных τ
нет: материя вложения обязана быть нулём, уравнения Р–Т совпадают с Эйнштейном.**

**Итог [замер + вывод].** В статическом сферическом секторе нашего объемлющего пространства R^{1,7}:
* общий (изогнутый во все 4 направления тени) срез даёт ровно Эйнштейна — тёмной материи вложения нет;
* в вырожденном (плоском по тени) подклассе она есть, но всегда с p_t/p_r = 1/4 и M_доп ∝ r^{3/2} — не плоские кривые.

Значит, развилка (А)/(Б) для статических тел почти снята: оба закона дают Шварцшильда, кроме меры-нуль-подкласса.
Механизм Пастона (тёмная материя от вложения) у них работает в **10-мерном** объемлющем пространстве (6 нормалей);
у золотого кристалла 3+1 — только 4 нормали. **Гипотеза:** если тень богаче (6 и больше направлений — другое числовое
кольцо или решётка большего ранга), материя вложения возвращается — и одновременно растёт группа «закрутки»: SO(6) ≅ SU(4)
⊃ SU(3) (цвет). Вместе с уже найденным SO(4) = SU(2)×SU(2) это SO(6)×SO(4) — ровно группа Пати–Салама. То есть тёмная
материя и сильное взаимодействие могут оказаться одним вопросом: «сколько направлений у тени».

*Простыми словами:* лист мира можно гнуть в четыре скрытых направления. Если гнуть только в три, у листа остаётся
«лишняя упругость» — но она даёт притяжение, растущее с расстоянием слишком быстро (не как в галактиках), и это не
исправить никакими начальными условиями. Если лист гнётся во все четыре, упругость исчезает совсем, и остаётся чистый
Эйнштейн. Чтобы получилась тёмная материя «как у галактик», нужно больше скрытых направлений — и, возможно, те же
лишние направления дадут цвет кварков.

## 7. Можно ли расширить тень до 6 направлений? (`cubic_crystal.py`) [замер + вывод]

**Рецепт золотого кристалла даёт тень только «четвёрками».** Тень — это сопряжённые копии мира (замена τ → τ′), каждая
копия той же размерности, что мир (4 в 3+1). Чтобы мир был лоренцевым, а тень — компактной («шар»), форма должна быть
лоренцевой у нас и определённой у всех сопряжённых. Число направлений тени = 4·(степень поля − 1): **4** (золотое, √5),
**8** (кубическое), 12 (четвёртой степени)… **Ровно 6 этим рецептом не получить.**

**Кристалл с 8 направлениями существует — проверено.** Поле θ = 2cos(2π/7) (корни 1.247, −0.445, −1.802), форма θt² − x²
(лоренцева у нас, определённая у обоих сопряжений). Найден точный буст с коэффициентами из Z[θ]: p = 1 + θ,
q = −1 + θ + θ², p² − θq² = 1 точно; в мире — быстрота 1.449 (скорость 0.896), в тени — повороты 56.3° и 143.3° в двух
плоскостях. Кристалл 1+1 (тень — 4-мерный шар): буст переводит точки кристалла в точки кристалла **83 из 83**, в ромбе
площади 18 — по 15 точек в трёх системах отсчёта. Значит, это такой же лоренц-инвариантный кристалл, как золотой, только
с вдвое большей тенью.

**Что даёт 8 направлений для групп «закрутки»** (по `gauge-doc`: группа = вращения нормалей; это само по себе гипотеза):
шар в 8 измерениях → SO(8) ⊃ SO(6)×SO(2) ≅ SU(4)×U(1) ⊃ SU(3) — **цвет помещается**; также SO(8) ⊃ SO(4)×SO(4). Полной
группы Пати–Салама SO(6)×SO(4) в SO(8) нет (не хватает ранга): она требует 10 направлений и появляется в SO(12)
(поле четвёртой степени), там же и SO(10) великого объединения.

**Поправка к §6 [вывод].** Гипотеза «тёмная материя вернётся при ≥ 6 направлениях» поспешна: для статического
сферического тела свобода τ есть, только если проекции ∂tt, ∂rr, ∂θθ на нормали лежат в плоскости. Две плоскости
поворота + B дают 4-мерное пространство минус касательная = 3 ⇒ в общем случае ранг 3 и τ = 0, как и в R^{1,7}. Число
направлений само по себе не решает — решает, насколько симметрично гнётся лист. Связка «тёмная материя = цвет» —
снята до открытого вопроса; связка «больше тени ⇒ есть место для SU(3)» — остаётся.

*Простыми словами:* у золотого числа одна «тень-двойник», поэтому скрытых направлений 4. Можно взять число с двумя
двойниками (из уравнения третьей степени) — проверили, что кристалл из него так же честно симметричен ко всем скоростям,
а скрытых направлений становится 8. В восьми направлениях группа цвета кварков помещается. Шести не бывает: двойники
приходят только целыми четвёрками.
