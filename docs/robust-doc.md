# Выводится ли золото? Надёжный порядок и лестница Маркова

Дата: 12 октября 2026. Код: `code/markov.py`, `markov2.py`, `markov3.py` (1+1), `robust4.py` (3+1).
Журнал: `data/markov3.log`.

## Критерий без τ на входе

Порядок надёжен, если ни одна пара событий не почти светоподобна: малый сбой
не должен переворачивать «раньше/позже/несвязаны». Мера — min |интервал| по всем
парам, умноженный на √плотности (не зависит от масштаба).

## 1+1: петля «почини самую светоподобную пару»

Мир — решётка; горизонт растёт (видит соседей до 6, 12, 25, 50 шагов). 600
случайных стартов, проверка на окне 150.

| куда пришли | доля | точный буст | теория (Марков) |
|---|---|---|---|
| 0.4472 | 1.2 % | λ = τ² (след 3, быстрота 0.962) | 1/√5 — **золото, максимум** |
| 0.3536 | 2.7 % | λ = (1+√2)² (след 6) | 1/√8 — серебро |
| 0.3363 | 7.0 % | след 15 | 5/√221 |
| 0.3338 | 3.5 % | (поиск не нашёл, ожидается след 39) | 13/√1517 |
| ниже 0.33 | 83 % | — | застревание |

* **Петля сама находит лестницу Маркова**: дискретные значения 1/√5, 1/√8,
  5/√221, 13/√1517 → 1/3. Это теорема Маркова–Гурвица, воспроизведённая без
  подсказки.
* **Каждая найденная ступень имеет точный цифровой буст.** Требование «нет почти
  светоподобных пар» само порождает точную дискретную симметрию Лоренца.
  Решётки общего вида дают min = 0.
* **Золото — вершина**: лучшая надёжность, и оно же даёт самый мелкий целый
  буст (след 3). Оба критерия совпадают, потому что у √5 наименьший
  дискриминант.
* **Но петля золото не предпочитает**: к нему приходит 1 % стартов, к серебру
  2.7 %, к 5/√221 — 7 %. Золото — лучший ответ, но не самый вероятный исход
  локальной починки.

## 3+1: почему окно тени — шар

Окно нашего кристалла 0.618t'² + |x'|² ≤ r² — это **ровно сопряжённая форма
интервала**, взятая со знаком минус: Q' = τ't'² − |x'|². Поэтому интервал любой
пары Q — целое число поля с |Q·Q'| ≥ 1, а |Q'| ≤ 4r². Отсюда:

    |ΔT² − Δx²| ≥ 1/(4r²)   для ЛЮБОЙ пары событий.

Вторая строка формулы («тень в шаре») — это и есть гарантия надёжного порядка.

min|интервал|·√ρ в ящиках растущего размера (ρ = 1):

| мир | L = 2.5 | 3.2 | 4.0 | гарантия |
|---|---|---|---|---|
| золото √5 | 0.146 | 0.146 | 0.146 | ≥ 0.111 |
| серебро √2 (θ = 1+√2) | 0.172 | 0.172 | 0.172 | ≥ 0.069 |
| √3 | 0.072 | 0.072 | 0.072 | ≥ 0.033 |
| √13 | 0.092 | 0.092 | 0.092 | ≥ 0.025 |
| посыпка Пуассона | 2e−5 | 1e−5 | 9e−6 | → 0 |
| Z⁴ | 0 | 0 | 0 | есть световые пары |
| Z⁴ с T = (π/2)t | 0.13 (векторы до 5) | 0.086 (до 10) | 0.009 (до 20) | → 0 (Маргулис) |

* Кристаллы-тени держат порядок при любом размере; посыпка и иррациональные
  решётки — нет.
* Гарантия ∝ 1/(D·√|N(θ)|): у золота она лучшая (D = 5 — наименьший
  дискриминант), **но фактический минимум у серебра больше** (0.172 против
  0.146). В 3+1 надёжность выделяет класс «тени над квадратичными полями», но
  не одно золото.
* Плотность в ящиках колеблется ±30 % от формулы (ящики выровнены по осям
  кристалла); нормировка по формуле.

## Итог

* Выведено: «тень в шаре» = сопряжённый световой конус = надёжный порядок;
  в 1+1 надёжность ⇒ точный цифровой буст ⇒ лестница Маркова, золото на вершине.
* Не выведено: локальная петля золото не выбирает (1 %), и в 3+1 по
  фактическому минимуму серебро не хуже. Чтобы золото выделилось однозначно,
  нужен второй критерий — например, самый мелкий буст (в 1+1 это снова золото,
  в 3+1 не проверено).

> **Поправка (`finest-doc`):** в таблице 3+1 пропущены целые анизотропные решётки
> (например, 7t² − |x|²). У них световых векторов нет, а надёжность 0.615, выше
> золота и серебра. Однозначный выбор золота даёт только сочетание трёх
> требований: надёжность, самоподобие и самый мелкий буст.
