## Опыт 0. Пространственного расстояния в порядке нет

**Что делается.** Буст применяется к ТЕМ ЖЕ событиям сприклинга;
причинное отношение пересчитывается из новых координат. Буст причинность
сохраняет, значит все порядковые величины обязаны совпасть тождественно,
а пространственный поперечник интервалов — разъехаться.

**Выход** (N=900, 2 засева, быстроты 0 / 1 / 2):

```
 быстрота  отношений   связей  высота  доля сравн.  ПОПЕРЕЧНИК
     0.00      39471    14744     9.0      0.09757     0.32272
     1.00      39471    14744     9.0      0.09757     0.56844
     2.00      39471    14744     9.0      0.09757     1.62633
  расхождение порядковых величин не более 0.000 %
  поперечник вырос в 5.04 раза
```

**Вывод.** Поперечник не есть функция порядка. Отсюда: никакая порядковая
конструкция не может знать, кто к кому близко.

## Опыты 1–2. Цепь даёт координаты, две цепи дают Лоренца

**Радарный метод, выполненный счётом.** Для события `x` и цепи `C`:
последнее событие цепи в прошлом `x` — это `p`, первое в будущем — `f`,
тогда

```
расстояние = (f − p)/2        время = (p + f)/2
```

Индексы `p`, `f` — номера вдоль цепи. Координаты в построении НЕ
участвуют; они используются только для сверки результата.

Это архивная формула проекта `W = 2λr`: `(f − p) ≈ 2λr`. Проект проверял
систему отсчёта, думая, что проверяет линейку.

**Опыт 1.** Корреляция радарных координат с собственными минковскими
координатами наблюдателя.

**Опыт 2.** Подгонка перехода между двумя наблюдателями:
`τ₂ = A·τ₁ + B·x₁ + C`, где `x₁` — положение по оси движения из радара
первого.

**Выход** (N фона 2000, по 90 событий на наблюдателя, 2 засева,
отбор у оси `|cosθ| > 0.97`):

| случай | время | простр. | `A` | `γ²` | промах | `v` | ожид. | промах | качество |
|---|---|---|---|---|---|---|---|---|---|
| буст 0.3 | 0.9998 | 0.9997 | 1.0923 | 1.0927 | **−0.04 %** | 0.2781 | 0.2913 | −4.55 % | 0.9995 |
| буст 0.6 | 0.9998 | 0.9996 | 1.4067 | 1.4053 | **+0.10 %** | 0.5095 | 0.5370 | −5.13 % | 0.9991 |
| буст 0.9 | 0.9998 | 0.9995 | 2.0577 | 2.0537 | **+0.19 %** | 0.6789 | 0.7163 | −5.22 % | 0.9971 |
| КОНТРОЛЬ сдвиг | 0.9998 | 0.9997 | 1.0003 | 1.0000 | +0.03 % | 0.0004 | 0.0000 | — | 0.9997 |

**Почему `γ²`, а не `γ`.** Радарное время мерится в ДЕЛЕНИЯХ ЦЕПИ, а у
движущегося наблюдателя деление есть его СОБСТВЕННОЕ время, короче в `γ`
раз. С ожиданием `γ` промах был 19 %; с `γ²` стал полпроцента, причём
`γ²` по таблице меняется почти вдвое — значит это не подгонка под одно
число.

**Остаточные −5 % по `v`** постоянны при всех быстротах (0.957 / 0.951 /
0.948), то есть калибровочный множитель: угловой отбор
(`⟨1/cosθ⟩ = 1.015` при `|cosθ| > 0.97`) плюс дискретность счёта по
цепи. Форма воспроизведена, масштаб смещён.

### Пойманная ошибка, оставлена в коде нарочно

Сначала в подгонку шло `x₁ = ±r₁`, то есть РАДИАЛЬНОЕ радарное
расстояние со знаком. Буст идёт по одной оси, и нужна составляющая
`r·cosθ`; по сфере `⟨|cosθ|⟩ = 1/2`, и `v` выходило вдвое малым: **0.2269
против 0.5370, то есть в 2.37 раза.** Исправлено отбором у оси.

## Опыт 3. Протечки нет: зависимость от скорости краевая

**Как поставлен вопрос.** «Безопорная величина не зависит от опоры» —
тавтология. Цепь-наблюдатель есть ФИЗИЧЕСКИЙ объект, его вставка меняет
множество, значит спрашивать надо: зависит ли вклад от СКОРОСТИ?

Наблюдатель строится по СОБСТВЕННОМУ времени (`observer_proper`): от
центра вдоль `(cosh ρ, sinh ρ)` на проперное время `tau`, `dens` событий
через равные промежутки. При любой быстроте это ОДИН объект — та же
мощность, та же собственная длительность.

Считаются только отношения наблюдатель-фон, за `O(dens·N)` без матриц
`N×N` — это позволяет дойти до `N = 33000`.

**Выход** (`ell = 0.107` фиксировано, наблюдатель 20 событий,
`tau = 0.22`, 10 засевов):

| `T` | `N` | радиус/`tau` | отн. `ρ=0` | отн. `ρ=0.9` | рост % | сигм |
|---|---|---|---|---|---|---|
| 1.0 | 999 | 2.3 | 2815 | 3006 | **6.80** | 2.6 |
| 1.4 | 3836 | 3.2 | 10209 | 10569 | 3.53 | 2.0 |
| 1.8 | 10483 | 4.1 | 27108 | 27718 | 2.25 | 1.8 |
| 2.4 | 33132 | 5.5 | 83775 | 84940 | **1.39** | 2.3 |

```
зависимость ~ T^-1.815   (ожидание около -2: площадь границы на объём)
```

**Вывод.** Зависимость краевая и в пределе бесконечного объёма исчезает.
Протечки нет: наблюдатель даёт координаты и не возмущает безопорную
структуру.

**И отсюда же:** вопрос корректен ТОЛЬКО в пределе бесконечной области. В
конечном мире скорость наблюдателя различима всегда, ибо никакая конечная
область не инвариантна к бусту. **Система отсчёта — понятие глобальное.**

### Пойманная ошибка в контроле

Сначала я проверял «граница или физика» наращиванием `N` при `T = 1` —
то есть ИЗМЕЛЬЧАЛ мир, а не увеличивал. Расстояние наблюдателя до
границы при этом не меняется, и краевой эффект обязан остаться
постоянным. Он и остался: `N^+0.000` (6.70 / 6.20 / 6.95 / 6.46 % при
`N` = 500…4000). Контроль был пустой. Растить надо ОБЛАСТЬ при постоянной
плотности.

⚠ Оговорка: проверено на СЧЁТНОЙ величине (число отношений). Для
действия замер силы не имеет: `ΔS` вышло 143±80, −80±95, −27±129,
13±130, то есть 0.1…1.8σ от нуля (`leak.py`).

## Опыт 4. Сколько мира накрывает цепь

`scratchpad/two.py`. Радарные координаты есть у события, если у него есть
И прошлое, И будущее на цепи.

| длина цепи (доля `T`) | событий цепи | покрытие |
|---|---|---|
| 0.25 | 30 | 0.0029 |
| 0.50 | 60 | 0.0456 |
| 0.75 | 90 | 0.2597 |
| 0.95 | 114 | 0.6933 |
| 1.00 | 120 | **0.8517** |

Даже цепь во весь мир накрывает 85 %: события у углов светового конуса не
имеют на ней ни прошлого, ни будущего.

> **Наблюдатель — НЕ мир.** Система отсчёта накрывает причинный ромб
> СВОЕЙ цепи. Точный кадр требует НЕПРОДОЛЖАЕМОЙ цепи — полной истории с
> бесконечным собственным временем; тогда её ромб есть весь Минковский и
> покрытие идёт к единице. Именно так устроена инерциальная система в
> теории относительности: бесконечная мировая линия плюс соглашение о
> синхронизации. Здесь это ВЫВЕДЕНО, а не заложено.
>
> У конечного наблюдателя кадр конечен дважды: по покрытию (85 % и ниже)
> и по точности (краевой член `T^-1.8`).

## Опыт 5. Действие по модулю 8 — щель в амплитудный слой

`scratchpad/two.py`. `B = N − n₀ + 9n₁ − 16n₂ + 8n₃`, и по модулю 8
`9 ≡ 1`, `16 ≡ 0`, `8 ≡ 0`, значит

```
B ≡ N − n₀ + n₁   (mod 8)
```

Сверено численно на 40 мирах разной мощности: **расхождений 0**.
Распределение остатка при 40 мирах: хи-квадрат 10.4 при 7 степенях
(порог 5 % = 14.1), то есть неотличимо от равномерного на такой выборке —
нужна бо́льшая.

### ⊗ Поправка к моему же утверждению

Утром я сказал, что амплитудный слой закрыт стеной `bdwall-doc.md`. Это
НЕВЕРНО. Стена стоит на ИЗВЛЕЧЕНИИ кривизны из действия: там надо вынуть
малый сигнал `ℓ²R` (~0.002) из числа с разбросом 70 на событие. Амплитуде
извлекать нечего: `B` есть ТОЧНОЕ ЦЕЛОЕ, посчитанное счётом, значит
`exp(iB)` вычисляется без погрешности вовсе.

Я спутал «нельзя измерить кривизну действием» с «нельзя посчитать
действие».
