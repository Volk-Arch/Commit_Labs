# Квадратичное правило против монотонного: одни и те же пять чисел

Дата: 11 октября 2026, вечер. Код: `code/gpsrule.py`, `code/gpspois.py`,
`code/gpsmany.py`. Проверка вывода `cone21-doc` («конечный набор чисел
даёт 4d только при немонотонном правиле»).

## Постановка

Засев 4d, ромб. Пять «спутников» — часы на неподвижных мировых линиях
вне области. Каждому событию из порядка достаются пять чисел: номер
**последнего тика каждого спутника в его прошлом** (координаты
излучения, «GPS observables»; только прошлое — пригодно для роста).
Из одних и тех же чисел два правила:

* **ЯЩИК** (монотонное): раньше по всем пяти. Берутся **точные** времена —
  самый выгодный для ящика случай.
* **GPS** (квадратичное): восстановить точку из пяти времён, сравнить
  знак интервала.

Контроли: точные времена → GPS совпадает с истиной (0 различий, ошибка
положения 1e−15); истина ⊂ ящик (0 нарушений).

## Результат (3 засева на строку; ℓ = ρ^{−1/4})

N = 2000:

| правило | лишних/R | пропущ./R | доля | разм. | высота | связей/соб. | спектр |
|---|---|---|---|---|---|---|---|
| истина | 0 | 0 | 0.0990 | 4.01 | 12.3 | 27.2 | +0.0225 |
| **ящик**, точные τ | **0.86** | 0 | 0.184 | **3.26** | 16.3 | 27.0 | **−0.0007** |
| GPS, ровные тики Δ=ℓ | 0.10 | 0.13 | 0.0962 | 4.05 | 10.7 | 33.0 | +0.0268 |
| GPS, Δ=ℓ, эфемериды ±Δ/2 | 0.12 | 0.15 | 0.0958 | 4.05 | 10.3 | 33.0 | +0.0225 |
| GPS, Δ=0.3ℓ | 0.035 | 0.037 | 0.0988 | 4.02 | 12.0 | 28.0 | +0.0243 |
| GPS, Δ=0.1ℓ | 0.012 | 0.012 | 0.0990 | 4.01 | 13.0 | 27.3 | +0.0242 |

Ящик на пяти числах — это орта: лишних пар 86 %, размерность 3.26,
спектр нулевой; ошибок на событие 42 → 85 → 174 при N = 1000/2000/4000
(растёт как N). GPS на тех же пяти числах даёт статистику Минковского;
доля ошибочных пар падает как `N^{−1/4}` (0.12 → 0.10 → 0.086 при Δ=ℓ).
Для сравнения с `cone21-doc`: E/R ≈ 0.1 требует ~25 граней, E/R ≈ 0.01 —
~300; GPS даёт то же пятью числами.

## Где граница: шум часов

Если тики случайные (пуассоновские), оценка времени втрое шумнее:

| тики, шаг | лишних/R | разм. | высота | связей | спектр |
|---|---|---|---|---|---|
| ℓ | 0.16 | 4.25 | 7.7 | 40.7 | **+0.0002** ✗ |
| 0.5ℓ | 0.11 | 4.05 | 9.7 | 34.7 | +0.0125 |
| 0.3ℓ | 0.07 | 3.99 | 11.0 | 31.3 | +0.0232 ✓ |
| 0.1ℓ | 0.026 | 3.98 | 12.3 | 28.6 | +0.0245 ✓ |
| истина | | 3.98 | 12.3 | 28.3 | +0.0232 |

Шум лечится и числом опор (`gpsmany.py`, случайная расстановка, тики
0.5ℓ): 5 → 8 → 16 → 32 опор дают лишних 0.26 → 0.14 → 0.074 → 0.048,
при 16 опорах статистика совпадает с истиной (связей 27.8 против 26.7,
спектр +0.0205 против +0.0238).

Шаг самой длинной цепи в засеве — `ℓ/m₄`, при `m₄` ≈ 1.8–2.4 это
0.4–0.55ℓ. **Ровно на границе:** часы, сделанные из самого порядка,
пограничны при пяти опорах и достаточны при ~16.

## Вывод

> Пять чисел на событие: монотонное правило даёт орту (86 % лишних пар,
> размерность 3.26), квадратичное — Минковского. Число чисел не зависит
> от N. Монотонному для того же нужно ~N граней (`cone21-doc`).

## Чего здесь нет

* Спутники идеализированы: неподвижные, вне области, положения известны
  (погрешность эфемерид ±Δ/2 проверена и терпима). Не цепи порядка.
* Роста нет: точки засеяны, правило лишь пересчитывает порядок.
* Попарного совпадения нет и не будет: ошибок на событие растёт как
  `N^{3/4}` (у пар у самого светового конуса); совпадает **статистика**.

Следующий шаг: спутники — длиннейшие цепи самого засева, их положения из
взаимной локации по порядку; затем рост, в котором новое событие
выбирает свои пять времён, а прошлое получает по квадратичному правилу.
