# Горизонт по порядку, и откуда двойка

Дата: 12 октября 2026, утро. Код: `code/horizon.py`, `code/vacuum.py`.
Повод — разбор мнения другой ИИ: «двойка — это симметрия времени и
пространства» (неверно: симметрия даёт Нордстрёма) и «при c → 0 будет
горизонт» (верно; нужна точная метрика, а не линейная формула).

## 1. Горизонт возникает сам

Радиальная плоскость Шварцшильда в координатах Эддингтона–Финкельштейна
(v, r): ds² = −f dv² + 2 dv dr, f = 1 − 2M/r.

* √−g = 1: густота событий одна и та же везде. Масса у Эйнштейна не
  меняет «кто существует» (g_tt·g_rr = −1), только «кто раньше».
* Местное «раньше»: Δv > 0 и Δr < f(r)·Δv/2. Внутри r < 2M f < 0, и все
  будущие направления ведут внутрь. Горизонт никто не вписывал.
* Дальнее «раньше» — цепочкой близких.

Прибор: часы на радиусе r_e и на R = 4.5M; задержка прихода по часам v.
Точная: Δv = 2(r*(R) − r*(r_e)), r* = r + 2M ln(r/2M − 1) — расходится
при r_e → 2M. Избыток над плоским (порядок / точно):

| r_e/M | ρ = 300 | ρ = 700 | ρ = 1600 | точно |
|---|---|---|---|---|
| 1.8 (внутри) | не дошло | не дошло | не дошло | никогда |
| 2.1 | не дошло | не дошло | **15.4** | 12.9 |
| 2.2 | не дошло | 13.7 | **11.3** | 10.1 |
| 2.4 | 14.0 | 9.0 | **8.0** | 7.3 |
| 2.7 | 8.3 | 6.0 | **5.5** | 5.1 |
| 3.2 | 4.2 | 3.4 | **3.1** | 2.9 |

Изнутри не выходит ничего при любой плотности. Снаружи порядок даёт
логарифмически растущую задержку и с ростом плотности сходится к точной
(отношение при r_e = 2.4: 1.91 → 1.23 → 1.09). Дискретность раздувает
горизонт: «дискретный горизонт» лежит выше 2M и опускается к нему с
ростом плотности (выше 2.2 при ρ=300, между 2.1 и 2.2 при 700, ниже 2.1
при 1600). Это 1+1; тень (фотонная сфера 3√3 M) требует 2+1 и
здесь не мерилась.

## 2. Двойка: правило вакуума

Семейство слабых полей ds² = −(1+2Φ)dt² + (1−2γΦ)dx², Φ = −M/r. Свет
чувствует 1 + γ: ОТО γ = 1 (двойка), Нордстрём γ = −1 (ноль). Мир строится
обеими строками: густота ∝ √−g = 1 + Φ − 3γΦ, «раньше» — по времени света
первого порядка (перенос проверен в `tilt-doc`).

**Правило вакуума:** вне вещества малый причинный ромб любой ориентации
содержит столько событий, сколько плоский той же собственной высоты. По
Гиббонсу–Солодухину отклонение δ = −Rτ²/180 + R_uu τ²/30; снаружи R = 0, а
R_uu = (γ − 1)·γ²v²·∂ₙ²Φ — разной величины вдоль радиуса и поперёк.

Замер: r = 10M, Φ = −0.01, ромбы высоты 6 с бустом v = 0.8 в местной
ортонормированной рамке, 2000 ромбов на строку, ~5000 событий в ромбе.
Мера — анизотропия δ(вдоль r) − δ(поперёк), общий сдвиг сокращается.

| γ | анизотропия | теория |
|---|---|---|
| −1 (Нордстрём) | +0.00237 ± 0.00044 (5.3σ) | +0.00128 |
| 0 | +0.00115 ± 0.00045 | +0.00064 |
| **+1 (ОТО)** | **−0.00007 ± 0.00044** | 0 |
| +2 | −0.00033 ± 0.00044 | −0.00064 |

Прямая по γ обращается в нуль при **γ* = 1.34 ± 0.30**. Это ОТО (в 1.1σ),
а Нордстрём отвергнут (7.8σ). Ромбы в покое — нуль при обоих γ (контроль:
у них R₀₀ = ∇²Φ = 0).

Наклон в 1.45 раза круче теории: ромбы большие (τ/r = 0.6), в них
вклады высших порядков. Отдельные δ у ромбов с бустом несут общий сдвиг
около +0.002 при γ ≥ 0 — он одинаков вдоль и поперёк и в анизотропии
сокращается.

## Что это значит

* Двойка — не симметрия, а **вакуум**: требование, чтобы вне вещества
  малые ромбы во всех ориентациях выглядели плоскими, выбирает γ = 1.
  Это уравнение Эйнштейна в пустоте, сказанное на языке счёта событий:
  правило в одну строку.
* Оговорка: мир строился из семейства метрик; правило **выбирает** из
  семейства, но не порождает само семейство. Вывода «из ничего» нет.
* У Эйнштейна масса меняет только «кто раньше» (густота в координатах
  Шварцшильда постоянна), у Нордстрёма — только «кто есть».
