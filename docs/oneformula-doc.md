# Одна формула: наклон, гравитация, вакуум и Λ

Дата: 12 октября 2026, утро. Код: `code/oneformula.py`. Повод — его
мысль «а что если наклон, гравитация, вакуум — одна формула».

## Формула

По Гиббонсу–Солодухину число событий в малом причинном ромбе
собственной высоты τ, ориентированном по u, отличается от плоского на

    δ = −R·τ²/180 + R_uu·τ²/30.

Подставив уравнение Эйнштейна (с Λ), получаем одну строку на языке счёта:

    δ(ромб, u) = −Λτ²/18 + 8π·τ²·(T_uu/30 + T/45)

* **пустота** (T = 0, Λ = 0): δ = 0 для любого ромба в любой ориентации;
* **вещество** (пыль в покое, плотность ρ): δ = 8πτ²ρ/90 у ромба в покое;
* **Λ**: δ = −Λτ²/18 (проверка: для де Ситтера с R = 12 выходит −τ²/6, как
  у Гиббонса–Солодухина).

Наклон конусов (Ψ), закон спадания (Φ ~ 1/r), вакуум, вещество и тёмная
энергия здесь — одно правило о счёте событий в малых ромбах.

## Проверка на точках: пустота выбирает и двойку, и 1/r

Семейство Φ = −A·(r₀/r)^p, Ψ = γΦ. Мир строится обеими строками
(густота ∝ √−g, «раньше» — по времени света первого порядка).

**Двойка** (`horizon-two-doc`, Φ = −0.01): анизотропия «вдоль радиуса минус
поперёк» обращается в нуль при γ* = 1.34 ± 0.30 (ОТО: 1).

**Закон 1/r** (новое): γ = 1, Φ(r₀=12) = −0.01, ромбы в покое высоты 8,
6000 ромбов по ~6400 событий. Теория: δ_покой = τ²∇²Φ/45,
∇²Φ = p(p−1)·Φ/r²; ноль только при p = 0 (постоянный потенциал) и p = 1
(поле Лапласа).

| p | p(p−1) | δ_покой | минус δ при p = 0 | теория |
|---|---|---|---|---|
| 0 | 0 | +0.00086 ± 0.00016 | 0 | 0 |
| **1** | 0 | +0.00112 ± 0.00016 | **+0.00026 ± 0.00023** | 0 |
| 2 | 2 | +0.00049 ± 0.00016 | −0.00037 ± 0.00023 | −0.00020 |
| 3 | 6 | +0.00023 ± 0.00016 | −0.00063 ± 0.00023 | −0.00059 |

Наклон по p(p−1): **−1.27·10⁻⁴ ± 0.33·10⁻⁴** (3.9σ от нуля) против
теоретических −0.99·10⁻⁴ (0.9σ). Поле 1/r даёт нуль (1.1σ).

Общий сдвиг +0.0009 у всех строк — погрешность второго порядка моего
построения («раньше» и густота заданы в первом порядке по Φ). При
Φ = −0.03 он вырастает до ~0.007 и заглушает всё (первый прогон —
непригоден, оставлен в коде как предупреждение).

## Что это значит и чего не значит

* Одно правило о счёте выбирает из двухпараметрического семейства и
  закон Ньютона (p = 1), и двойку Эйнштейна (γ = 1). Это уравнение
  Эйнштейна в пустоте, сказанное языком порядка; с веществом и Λ — та же
  строка (вывод, на точках не проверялся).
* Это по-прежнему **выбор из семейства**, а не рост поля из ничего: мир
  строился из готовых метрик. Порождение (поле само подстраивается, пока
  ромбы не станут плоскими) — следующий шаг, и он дорогой: сигнал 10⁻⁴
  требует тысяч ромбов на каждую итерацию.
* Эта идея известна: Джейкобсон (1995, 2016) выводил уравнение Эйнштейна
  из свойств малых причинных ромбов. Новое здесь — проверка счётом
  событий на дискретной модели.

## Дополнение: точное построение убрало сдвиг (`code/exactform.py`)

Мир построен точно для ds² = −e^{2Φ}dt² + e^{−2γΦ}dx²: густота e^{(1−3γ)Φ},
время света ∫e^{−(1+γ)Φ}dl, рамка и собственное время через экспоненты.
Остаётся лишь прямой путь света вместо геодезической. Φ(r₀=12) = −0.03 —
втрое сильнее, чем раньше, — ромбы в покое высоты 8, γ = 1:

| p | p(p−1) | δ_покой | теория τ²∇²Φ/45 |
|---|---|---|---|
| 0 | 0 | −0.00033 ± 0.00023 | 0 |
| 0.5 | −0.25 | −0.00003 ± 0.00016 | +0.00007 |
| **1** | 0 | **+0.00026 ± 0.00023** | 0 |
| 2 | 2 | −0.00044 ± 0.00016 | −0.00059 |
| 3 | 6 | −0.00130 ± 0.00016 | −0.00178 |

Подгонка δ = a + b·p(p−1): **сдвиг a = −0.00005 ± 0.00010** (был +0.0009 у
построения первого порядка при втрое слабом поле), **наклон
b = −2.07·10⁻⁴ ± 0.32·10⁻⁴** (6.4σ), теория −2.96·10⁻⁴ — 70 % от неё,
2.8σ. χ² = 3.4 на 3 степени. Нуль правила — у полей Лапласа (p = 0, 1).

Коэффициент по двум построениям: 128 % (первый порядок, Φ = 0.01) и 70 %
(точное, Φ = 0.03); ромбы велики (τ/r ≈ 0.67), поправки высших порядков
по τ/r не учтены. **Знак, форма p(p−1) и нуль при p = 1 — твёрдо;
коэффициент — ±30 %.**

Ромбы с бустом в точном построении при Φ = 0.03 несут свои сдвиги
(+0.0016 вдоль, +0.0006 поперёк при γ = 1): длинные ромбы заходят в
сильное поле, где прямой путь света уже плох. Проверка двойки остаётся
за прогоном при Φ = 0.01 (`horizon-two-doc`).

### Строка с веществом

Внутри вещества та же величина: δ_покой = τ²∇²Φ/45, а по Пуассону
∇²Φ = 4πρ, откуда δ = 8πτ²ρ/90 — это и есть строка формулы для пыли.
Отдельного прогона не нужно: измерен тот же отклик на ∇²Φ (6.4σ), с
коэффициентом в пределах ±30 % от теории.

### Порождение вместо выбора

Подстройка поля по правилу (итерации) упирается в шум: 6000 ромбов дают
±1.6·10⁻⁴, то есть p около 1 определяется лишь с точностью ±0.5 за шаг.
Пять точек скана выше и есть такая подстройка «за один проход»: нуль
правила стоит при p(p−1) = −0.25 ± 0.5, то есть у p = 1. Настоящее
порождение произвольного профиля потребует на порядок больше событий.
