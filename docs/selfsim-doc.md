# Условие самоподобия: третий класс правила тоже закрыт

Проверялось единственное незакрытое: условие на САМО прошлое нового
события целиком — неограниченное по размеру, но локальное в порядке.
Фаркаш его не касается (это не вес), порог `n ≈ 108` не касается (это
не запрет ограниченного размера).

**Условие:** доля отношений внутри прошлого каждого события обязана
совпадать с долей отношений целого. Проверяется при рождении, значит
локально по построению.

## Контроли, которые прошли

| контроль | результат |
|---|---|
| цепь: всякое прошлое — цепь, отклонение обязано быть нулём | **0.0000** ровно |
| засев `d`=2 ≡ доминирование `k`=2 (светоконусные координаты `u=t+x`, `v=t−x` делают причинность 1+1 в точности доминированием по двум шкалам) | `r` = 0.4973 против 0.4820; отклонения 0.0275/0.0956 против 0.0331/0.1040 |
| доля отношений доминирования обязана равняться `2^{1−k}` | 0.5207, 0.2551, 0.1233, 0.0648, 0.0358 против 0.5, 0.25, 0.125, 0.0625, 0.03125 |

Третий контроль подтверждает единственную верную формулу из вчерашнего
файла другой ИИ: `log₂(доля связанных) = −(k−1)` **выводится точно**,
потому что `P(A ≺ B) = 2^{−k}`, а связанных пар вдвое больше.

Там же видна честная шероховатость: `k`=4 даёт `r` = 0.1233…0.1348, а
Мирхейм–Мейер для `d`=4 хочет 0.1, и засев `d`=4 даёт 0.0729…0.0989.
Шкалы при `k`=4 не воспроизводят четырёхмерную причинность по доле
отношений.

## Сырое условие ВЫВЕРНУТО

| сектор | медиана `\|r(x)−r\|/r` при `nmin`=150 |
|---|---|
| иерархический слоистый `b`=3, `q`=0.6 | **0.0024** |
| слоистый `k`=50, `q`=0.7 | 0.0191 |
| засев `d`=2 | 0.0383 |
| **засев `d`=4** | **0.1583** |
| перколяция | 0.5100 |

Иерархический слоистый сектор самоподобен **в шестьдесят раз лучше**
четырёхмерного засева. Причина видна сразу: при `r` = 0.996 всякое
прошлое тоже почти полное, и совпадение даётся **жёсткостью**, а не
похожестью на мир.

## Починка и её провал

Правильная форма «часть похожа на целое» — сравнивать наблюдённый
разброс с ОЖИДАЕМЫМ (биномиальным по размеру прошлого). Первый замер
обнадёжил: засевы и доминирование 1.8…7.7, слоистые и перколяция
12…96. И на сетке из 109 секторов при `N` = 600 из 58 с энтропией выше
мировой не прошёл ни один — но ближайший стоял на 3.90 против порога
3.69, то есть в шести процентах.

Тонкий скан по `q` у единицы эти шесть процентов съел:

| `N` | порог по засевам | энтропия мира | лазеек найдено | макс. энтропия лазейки | её отношение |
|---|---|---|---|---|---|
| 300 | 2.50 | 6845 | **7** | 15995 (2.3×) | 2.24 |
| 600 | 4.89 | 15353 | **11** | 79203 (5.2×) | 3.06 |
| 1000 | 5.25 | 27631 | **12** | 132605 (4.8×) | 4.51 |

> **Условие самоподобия отбора не даёт.** Лазейки есть при каждом
> размере, их число и энтропия растут с `N`.

## Механизм провала, названный точно

1. **Жёсткость проходит самоподобие даром.** Почти полный порядок
   (`r` = 0.9999) совпадает с любой своей частью, потому что у него нет
   места для отклонения. Это верно для ЛЮБОЙ экстенсивной статистики, а
   не только для доли отношений: у экстремума её дисперсия обнуляется.
   Значит лазейка не лечится ни выбором другой статистики, ни
   конъюнкцией нескольких — почти полный порядок экстремален сразу по
   всем (`R`, `N₀`, цепи, высота).
2. **И при этом жёсткость не мешает энтропии.** Почти полный порядок
   достигается при `q` = 0.8…0.98 между блоками, то есть ~`N²`
   свободных бит остаются. Отсюда `S` до 255863 при мировых 27631.
3. **Порог дрейфует.** Отношение самого засева скачет с `N` (у `d`=2:
   5.99, 3.88, 4.14; у `d`=4: 2.26, 1.91, 2.47), потому что биномиальная
   нормировка не учитывает корреляции транзитивности. Фиксированный
   порог по такой статистике асимптотического смысла не имеет.

## Что получилось у доминирования

Побочно, но стоит записать: **порядок доминирования по `k` шкалам —
самый самоподобный из всех нежёстких структур** (отношение 1.84…3.02,
не хуже засевов). Это и ожидалось: прошлое точки в `k`-кубе есть снова
равномерный `k`-куб, то есть тот же процесс. Собственный примитив
проекта масштабно-инвариантен по построению.

## Пойманные ошибки

1. **Сравнение при неравных `N`.** Иерархические секторы строились с
   `N = b^глубина` (243…256), а сравнивались с засевом на 600, тогда
   как отношение от размера зависит. Построение переписано на
   рекурсивное деление ровно на `N` элементов.
2. **Неверный вопрос.** Я спрашивал «есть ли зазор между засевом и
   соперниками», а надо было «проходит ли условие сектор с ЭНТРОПИЕЙ
   ВЫШЕ мировой» — потому что жёсткие порядки отсекаются энтропией и без
   всякого условия (у цепи `ln N!` против `4N lnN` у мира). С неверным
   вопросом вердикт выходил «зазора нет» на почти-цепях, которые делу
   безразличны.
3. **Пропущенный контроль на `nmin`.** В первом прогоне у засева `d`=4
   отклонение вышло 0.47, и часть этого — просто шум малых прошлых
   (`1/√(r·C(m,2))` даёт 25 % при `m`=20). При `nmin`=150 остаётся
   0.158. Вывод не изменился, но цифра была завышена.

## Общая картина: три класса, одна причина

| класс правила | чем закрыт |
|---|---|
| **вес** (действие, мера) | сертификат Фаркаша: счёты мира — выпуклая смесь счётов соперников, линейный вес смеси не видит |
| **запрет ограниченного размера** | запрещать нечего: всё до 7 элементов реализуемо в 2+1, а счёт Уоррена–Милнора–Тома отодвигает первый запрет к `n ≈ 108` |
| **условие на прошлое целиком** | жёсткая лазейка: почти полный порядок самоподобен даром и при этом богат энтропией |

И причина во всех трёх одна: **у семейства соперников свободные
параметры (число слоёв, плотность, ветвление), поэтому оно
подстраивается под любой конечный набор условий.** Вес настраивает
пропорции, но не видит смеси; запрет убирает из существования, но
убирать нечего; условие на прошлое ловится экстремумом статистики.
Против семейства с континуумом параметров конечное правило каждый раз
оказывается недостаточно тонким.
