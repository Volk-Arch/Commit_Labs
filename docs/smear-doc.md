# Размазанное действие: укрощает флуктуации, но не отбирает

11 октября. Последний названный класс, и пришли к нему не по списку, а
по причине: замер того же дня (`horizon.py`) показал, что связи в
каузальном множестве **длинные** — через срединный срез проходит 70…80 %
всех связей. Эта нелокальность и держит все наши закрытия: разброс
действия растёт как `N` (`sigma-doc.md`), локальное действие бессильно,
слоистый сектор не гаснет. А размазанное действие у Соркина вводится
ровно для её укрощения.

## Построение — из принципа, а не по памяти о коэффициентах

Размазка есть усреднение резкого действия по случайному
**прореживанию** множества с плотностью `ε`: пара выживает с
вероятностью `ε²`, а размер её интервала становится биномиальным
`Bin(m, ε)`. Отсюда эффективный вес

    W_m(ε) = ε² · Σ_{j=0..3} w_j · C(m,j) ε^j (1−ε)^{m−j}

отличный от нуля при **всех** `m`, с затуханием `(1−ε)^m` — это и есть
нелокальность, с промежуточным масштабом `ε^{−1/4}` в длинах
дискретности.

## Контроли

| | |
|---|---|
| **A.** при `ε` = 1 обязаны вернуться веса БД | `W₀..W₅` = −1, +9, −16, +8, 0, 0 — **совпало** |
| **B.** геометрическое тождество `Σ W_m Γ(m+½)/m!` | машинный ноль при всех `ε` (10⁻¹⁶…10⁻¹⁷); **размазка сохраняет его точно** — прореживание переводит тождество в себя |
| **C.** полная сумма по `t` | прежний код обрывал на `t` = 3, что для размазанных весов неверно; исправлено |
| **D.** якорь `ε` = 1 против архива | 0.1155 против 0.1083…0.1167 — **сошёлся** |

Поймано по дороге: минимум по `θ` прилипал к краю диапазона при всех
`ε ≤ 0.7`, потому что веса сжимаются как `ε²` и для той же фазы нужно
`θ` в `1/ε²` раз больше. Первая версия сканировала не ту область, и её
вердикт был бессмыслен. Исправлено масштабированием диапазона `θ`.

## Результат

| `ε` | 1.0 | 0.7 | 0.5 | 0.3 | 0.2 | 0.1 | 0.05 | 0.03 |
|---|---|---|---|---|---|---|---|---|
| `c` по окну | 0.1155 | 0.1243 | 0.1358 | 0.1394 | 0.1341 | 0.1170 | 0.1159 | **0.1145** |

**Ни одной точки с гашением: 0 из 14.** И `c` почти не зависит от
промежуточного масштаба: при сильнейшей размазке 0.1145 против 0.1155
у резкого действия.

> **Вывод, и он разделяет две задачи, которые мы путали.** Размазка
> делает ровно то, для чего введена: укрощает ФЛУКТУАЦИИ действия. Но
> вердикт отбора зависит от КОГЕРЕНТНОЙ СУММЫ по сектору, а не от
> размера флуктуаций, и её размазка не трогает. Проблема
> `σ(S) ∝ N` и проблема отбора — разные проблемы, и размазка решает
> первую, не вторую.

## Оговорки

1. Прореживание — **моя реконструкция** принципа размазки, не
   воспроизведение опубликованных коэффициентов. Контроли (возврат к
   БД при `ε`=1, сохранение тождества) её поддерживают, но нормировка
   или ядро у Соркина могут отличаться.
2. Вердикт `c(m,d)` относится к блочной форме слоистого сектора, как
   выведено в `cancel5-doc.md`.
3. Одна точка (`ε` = 0.4) осталась с `θ` у края диапазона.
4. Сканировано `m, d` до 30.
