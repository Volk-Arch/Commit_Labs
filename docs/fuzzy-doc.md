# Размытый край тени: случайность там, где она нужна

Дата: 12 октября 2026, утро. Код: `code/fuzzy.py`. Продолжение
`lambda-why-doc.md`. Мысль о том, что миру нужна небрежность или шум,
высказана им в прошлой сессии (`noise-doc`); здесь она получает числовую роль.

## Правило

    событие x существует с вероятностью P(s), s — радиус тени:
    P = 1 при s < r(1−w), линейно падает до 0 при s = r(1+w)

При w = 0 — чистый кристалл. Радиус r подобран так, чтобы средняя
плотность не менялась. Доля «монеточной» дрожи ν = E[P(1−P)]/E[P].

## Результат (ромбы, n — ожидаемое число событий)

| w | ν | √ν | система | n = 3 000 | 30 000 | 100 000 |
|---|---|---|---|---|---|---|
| 0 | 0 | 0 | покой | 0.98 | 1.10 | 0.72 |
| 0 | | | буст 1.5 | 0.35 | 0.27 | **0.24** |
| 0.1 | 0.13 | 0.36 | покой | 1.00 | 1.23 | 0.84 |
| 0.1 | | | буст 1.5 | 0.39 | 0.33 | **0.42** |
| 0.3 | 0.36 | 0.60 | покой | 0.86 | 0.89 | 1.16 |
| 0.3 | | | буст 1.5 | 0.62 | 0.54 | **0.60** |

(значения — σ/√n; у случайного засева 1; ошибка ±13–16 %)

* В общей системе дрожь перестаёт падать и держится на √ν: рост как √N,
  **в любой системе отсчёта**. У чистого кристалла она падает (0.35 → 0.24).
* Средние без смещения: среднее/n = 1.000 ± 0.002 во всех строках.
* В системе кристалла дрожь остаётся ~1 (резонанс плюс монетка).

Остальные свойства (размерность, связи, петля, чинящая ошибки) здесь
не перемеривались: прореживание независимое и, по смыслу, их не трогает.
Петля `fixgold` с размытым краем — отдельная проверка.

## Λ(t): что даёт размытый край (вывод, без отдельного прогона)

Случайная часть независима для каждого события. Значит отклонение
числа событий в прошлом конусе — пуассоновское с дисперсией ν·N, то есть
ровно статистика «вечно присутствующей Λ» Соркина, только с амплитудой,
умноженной на √ν. Детерминированная часть кристалла растёт как N^0.32 и
на космологических N пренебрежима.

* **Что выходит:** Λ ~ √ν/√V. Четырёхобъём прошлого V ~ (возраст)⁴ в
  планковских единицах, поэтому Λ ~ 1/возраст² ~ H²: плотность тёмной
  энергии **сама порядка критической в любую эпоху**. Это и величина
  ~10⁻¹²², и ответ на вопрос «почему именно сейчас».
* **Что не выходит:** форма истории та же, что у модели Соркина, — Λ
  дрожит по величине и знаку, и типичные истории плохо ладят с
  реликтовым излучением (arXiv:2307.13743). Размытый край этого не
  исправляет. Коэффициент (√ν × неизвестный множитель Соркина) не выведен.

Самоисправление не страдает (даже чуть лучше). Мир — одна реализация

## Дополнение: можно ли успокоить историю Λ (`code/lambdahist.py`)

Модель: Λ(t) = ΔN(t)/V(t), V ∝ t⁴, 200 историй, время от 10 до 10⁶.

| примесь | |Λ|·t² в начале → в конце | смен знака на e-кратный рост времени |
|---|---|---|
| независимые монетки (Соркин) | 0.70 → 0.70 (следит за H²) | 3.9 |
| связанные блоками по 10⁴ | 66 → 69 (следит, амплитуда ×100) | 3.7 |
| анти-связанные (гипероднородно) | 0.064 → 0.001 (не следит, падает) | 3.4 |

Местное устройство случайности меняет **только амплитуду**: связь блоками
её усиливает, анти-связь убивает слежение за H² (как у чистого
кристалла). Форма — частые смены знака — от того, что ΔN складывается из
вклада всего прошлого. Успокоить историю можно только сменой самой связи
«дрожь → Λ» (например, отклик Λ, сглаженный по времени), а не устройством
монеток. (Число смен знака зависит от шага сетки; сравнение между строками
честное, абсолютное — нет.)
