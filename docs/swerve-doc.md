# «Виляние» частиц: кристалл против посыпки

Дата: 12 октября 2026. Код: `code/swerve.py`, `swerve2.py`, `swerve3.py`.

## Правило

Частица идёт «как можно прямее»: из текущего события выбирает следующее в будущем на
собственном времени τ ∈ [2, 3] ячейки, направление которого ближе всего к её скорости
u. Новая скорость — направление последних K шагов (K = 1 без памяти, K = 8 с памятью).
Меряем уход скорости ⟨η²⟩ — быстроту относительно начальной. Плотность ρ = 1.

## Результат

| мир | K | ⟨η²⟩ при 10 / 50 / 150 шагах | рост |
|---|---|---|---|
| Пуассон | 1 | 0.44 / 1.97 / 4.41 | ∝ n^0.91 (диффузия) |
| кристалл, общая скорость | 1 | 0.34 / 0.69 / 0.94 | ∝ n^0.35 |
| Пуассон | 8 | 0.088 / 0.139 / 0.371 | ∝ n^0.67 |
| кристалл, общая скорость | 8 | 0.078 / 0.096 / 0.129 | ∝ n^0.23 |
| кристалл, покой | 8 | 0.048 / 0.071 / 0.073 | ∝ n^0.19 |

Кристалл дольше, K = 8, 24 частицы, 600 шагов: ⟨η²⟩ при 50 / 200 / 600 шагах =
0.085 / 0.131 / 0.129 (η₀ = 0.5); 0.120 / 0.154 / 0.142 (η₀ = 1.5); 0.22 / 0.29 / 0.31 (η₀ = 2.5).
**Уход насыщается:** скорость дрожит в ограниченных пределах и не уходит.

Снос средней быстроты (K = 8, 150 шагов): кристалл 0.5 → 0.62, 2.5 → 2.33; Пуассон
0.5 → 0.80, 2.5 → 1.86. Снос к середине — свойство правила выбора, не кристалла: у
посыпки он сильнее. Признаков «залипания» на выделенных скоростях кристалла
(нарушения Лоренца) нет.

## Смысл

* В посыпке скорость частицы совершает случайное блуждание, и импульс со временем
  уходит. Это «виляние» Доуэра–Хенсона–Соркина; наблюдения ограничивают его очень
  сильно.
* В золотом кристалле отклонения ограничены и сами себя гасят (как привязка к тени в
  `fixgold`). Скорость, усреднённая по многим шагам, сохраняется: дрожь ~0.3 по
  быстроте, делённая на число шагов, уходит в ноль.
* Это качественное предсказание: в золотом мире виляния нет, а у случайной посыпки
  оно есть.
* Оговорки: правило движения выбрано нами (модель Доуэра–Хенсона–Соркина устроена
  иначе); шаг порядка ячейки; статистика — десятки частиц.
