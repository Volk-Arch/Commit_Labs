# Свобода весов в фазовой сумме: последнее неосмотренное место

10 октября, вечер. После закрытия классического роста тождеством
`L − H = 1` (`csg-doc.md`) оставалось одно место: амплитуды есть, а
действие другое. Проверено.

## Что именно было неосмотрено

Фаркаш закрыл разделение по ЗНАЧЕНИЮ: никакая линейная комбинация
счётов не разводит секторы неравенством (`actionexist-doc.md`). Скан
`cancel5` закрыл гашение по ФАЗЕ — но он варьировал только `ℏ`, `m`,
`d` при **фиксированных** весах Бенинказы–Доукера. Свободу самих весов
в фазовой сумме не трогали ни разу.

А чтобы её тронуть, нужно было знать, какие веса оставляют действие
**геометрическим**. Это дал сегодняшний двухточечный интеграл
(`nm-doc.md`): ведущий член плоского пространства гасится тождеством

    Σ_m w_m Γ(m+½)/m! = 0

В явном виде для весов до `w₃`: `w₀ + w₁/2 + 3w₂/8 + 5w₃/16 = 0`
(для БД: −1 + 9/2 − 6 + 5/2 = 0).

## Постановка

Вердикт сектора: `ln|Z| ~ c N²`, где `c(m,d) = ln|g_d(m)|/(4(m+d))`,
и сектор **гибнет** если `max` по `(m,d)` от `c` не больше нуля.
Обобщение на произвольные веса — подстановкой: `u = e^{iθw₀}`,
`φ(t) = e^{iθw_t}`, и

    g = (1+u)^m + Σ_{t≥1} C(m,t) u^t (φ(t)^d − 1)

Резонансы отсеяны без старого правила: решение обязано держаться на
ОКНЕ по `θ`, а резонанс есть одиночный шип. Поэтому `c` берётся как
минимум по `θ` от скользящего максимума.

## Результат

| свобода весов | лучшее `c` | пусков с гибелью |
|---|---|---|
| до `w₃` | **0.0557** | 0 / 10 |
| до `w₄` | 0.0735 | 0 / 10 |
| до `w₆` | 0.0731 | 0 / 10 |
| веса БД (якорь) | 0.1083 | — |

Плюс сетка: **0 из 1734** точек гиперплоскости дали гибель; минимум по
сетке 0.0661.

Расширение свободы НЕ помогает: при `w₄` и `w₆` лучшие точки сами
сводятся к решению по `w₃` — лишние веса выходят в ноль.

> **Пол положителен и равен ≈ 0.056** — вдвое ниже, чем у БД (0.108…
> 0.117), но знака не меняет. Гашение фаз закрыто не только для весов
> Бенинказы–Доукера, а для всего класса геометрических действий этого
> вида.

## Пойманный баг, и чем он пойман

Вынуждая `w₀` условием, я забыл поделить на `Γ(½) = √π`: брал
`w₀ = −Σ_{m≥1} w_m Γ/m!` вместо деления на `Γ(0.5)`. Первые два скана
считали **не ту поверхность** — точки не лежали на гиперплоскости
вовсе.

Поймано диагностическим столбцом «геом. условие», который печатал
−1e+01 и +5e+00 вместо нуля. Проверка исправления:
`9·0.886227 − 16·0.664670 + 8·0.553892 = 1.77246`, делённое на
`√π = 1.772454`, даёт ровно `1.00000`, то есть на весах БД правильная
формула возвращает `w₀ = −1`.

**Урок:** якорь обязан идти ЧЕРЕЗ ТОТ ЖЕ КОД. Мой первый якорь
передавал веса БД напрямую, минуя функцию, которая и была сломана, —
и потому прошёл. Контроль, обходящий проверяемый участок, не контроль.
(Это тот же урок, что `bdcontrol.py` дал 8 октября, в другом обличье.)

## Оговорки

1. Нелдер–Мид из десяти начал — не доказательство глобального пола.
   Согласие между началами и между размерностями свободы есть довод,
   но не теорема.
2. Класс — действия, линейные по счётам `N_m` с `w_m = 0` при `m > 6`
   и с одним геометрическим тождеством. Шире остаются: нелинейные
   действия и размазанные (нелокальные) с промежуточным масштабом,
   которые у Соркина и вводятся именно для укрощения флуктуаций.
3. Вердикт `c(m,d)` относится к блочной форме слоистого сектора, как
   она выведена в `cancel5-doc.md`.
