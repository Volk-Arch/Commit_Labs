# Что должно быть на входе: два числа, и теперь известно какие

**Драйвер:** `code/inputmem.py` · **Уточняет** ORDER-final часть VI,
`input-doc.md`

---

## Что было известно

ORDER-final, часть VI: порядок помнит о своём входе **ровно два числа**.
Восстановление из признаков порядка на независимых шкалах:

```
  отдельная шкала (контроль)   R² = 0.121, 0.045
  произведение                 0.986
  сумма                        0.948
  дисперсия                    0.909
  медиана                      0.714
```

Среди восстановимых ровно две независимые (первая компонента 0.637, две
первые 0.937; дисперсия ортогональна сумме, корреляция −0.01). Третьей
нет — восемь кандидатов, лучший остаток 0.344 и он на 0.97 коррелирует с
дисперсией.

Толкование там же: **сумма шкал — время, разброс шкал — заряд.**

И отдельно было измерено, что вход не обязан быть геометрическим: фазы
плоских волн, сферических волн и координаты дают один и тот же мир
(0.1289 / 3.70, 0.1213 / 3.77, 0.1226 / 3.76), причём координаты из фаз
не восстанавливаются (`R²` отрицательный по всем трём).

## Что меняется на связанных шкалах

Всё перечисленное мерилось на **независимых** шкалах. На связанных
(`correlated-scales-doc.md`) вход другой: точка в `m` измерениях, а
шкала направления `u` есть `t − u·x`. Тогда симметричные функции шкал
имеют прямой геометрический смысл:

```
    среднее по направлениям  = t        (средний u·x равен нулю)
    разброс по направлениям  ~ |x|²     (дисперсия проекций)
```

Проверка той же процедурой — признаки считаются **только** из порядка
(прошлое, будущее, их разность и сумма, прямые связи в обе стороны,
глубина):

```
    величина входа    ящик (независимые шкалы)      конус (проекции точки)
        сумма шкал          R² = 0.965 ± 0.003          R² = 0.952 ± 0.022
      разброс шкал          R² = 0.904 ± 0.011          R² = 0.921 ± 0.029
        одна шкала          R² = 0.285 ± 0.051          R² = 0.343 ± 0.016
      вторая шкала          R² = 0.273 ± 0.019          R² = 0.350 ± 0.016
      координата t          R² = 0.965 ± 0.003          R² = 0.997 ± 0.000
        радиус |x|          R² = 0.904 ± 0.011          R² = 0.975 ± 0.004
```

Ящик воспроизводит архив. А на конусе те же две величины оказываются
**настоящей геометрией**: время восстанавливается с `R² = 0.997`,
расстояние от начала — с `0.975`.

> **«Заряд» архива в связанной картине — это радиус.** Величина, найденная
> эмпирически как метка, из которой строилось взаимодействие, оказывается
> расстоянием от начала координат.

## Два числа — свойство правила, а не симметрии области

Естественное возражение: в сферически симметричной области направление
`x` неразличимо по симметрии, поэтому и остаётся только `|x|`. Проверено
сжатием области — симметрия сломана:

```
                   область        t      |x|       x1       x2       x3
       ромб (симметричный)    0.997    0.975    0.013    0.013    0.022
       ромб, сжат вдоль x1    0.997    0.962    0.012    0.031    0.077
         ромб, сжат сильно    0.997    0.975    0.005    0.047    0.121
```

Даже при восьмикратном сжатии отдельные координаты дают 0.005–0.121,
тогда как время держится на 0.997 и радиус на 0.962–0.975. Сигнал о
направлении слабо растёт с анизотропией (`x3`: 0.022 → 0.077 → 0.121), но
остаётся на порядок ниже.

> Ограничение «два числа» принадлежит **правилу**, а не области. Третий
> канал открывается при анизотропии, но слаб.

## Ответ на вопрос «что должно быть на входе»

Вход почти целиком выбрасывается. Что бы ты ни подал — координаты, фазы
плоских волн, фазы сферических волн — правило оставляет **два числа на
событие**, и именно поэтому все три входа дают один и тот же мир.
Различаются они лишь тем, что отбрасывается.

Отсюда обращение задачи, которое и было вопросом:

- **на независимых шкалах** два выживших числа геометрического смысла не
  имеют. Их приходится толковать задним числом (время и заряд), и `k`
  при этом не размерность, а просто число шкал;
- **на связанных шкалах** два выживших числа — это `t` и `|x|`, то есть
  **конформная информация** о событии. А размерность берётся из
  размерности поверхности, на которой живут шкалы.

Это и есть точная форма девиза проекта «порядок плюс число = геометрия».
Порядок даёт конформную часть (`t` и `|x|` с `R²` 0.997 и 0.975), а
**счёт событий** восстанавливает масштаб, которого конформной части не
хватает. В непрерывной теории это теорема Маламента–Хокинга–Кинга–Маккарти:
причинная структура определяет метрику с точностью до конформного
множителя. Здесь она же, в дискретном виде и измеренная.

## Чем эти два числа могут быть

Две гипотезы, обе проверены.

**Гипотеза 1: это объём прошлого и объём будущего.** Самые основные
порядковые инварианты события; тогда остальные признаки — их функции.

```
     набор признаков         t       |x|        x1
             прошлое     0.589     0.218     0.000
                 два     0.918     0.604     0.000
              полный     0.997     0.975     0.013
```

**Неверно.** Прошлое и будущее вдвоём дают `t = 0.918` и `|x| = 0.604`,
а полный набор — 0.997 и 0.975. Прямые связи и глубина добавляют
настоящую информацию, особенно про радиус (0.604 → 0.975), значит
функциями двух объёмов они не являются.

**Гипотеза 2: это положение события в пространстве орбит симметрии.**
Признаки события — скаляры, значит они инвариантны к симметрии всей
расстановки и могут определить положение лишь с точностью до её группы.
У ромба в четырёх измерениях симметрия `SO(3)`, пространство орбит
двумерно — `(t, r)`, отсюда ровно два числа.

Проверка: ломаем симметрию метками (плотные сгустки событий в заданных
местах).

```
                           область        t      |x|       x1       x2       x3
        ромб, симметрия SO(3) цела    0.997    0.975    0.013    0.013    0.022
       одна метка: симметрия SO(2)    0.992    0.950    0.103    0.010    0.015
     три метки: непрерывной нет       0.977    0.899    0.037    0.065    0.097
```

**Верно по механизму.** Метка стояла вдоль `x1` — и восстановимость
именно `x1` подскочила в восемь раз (0.013 → 0.103), пока `x2` и `x3`
остались на 0.01. С тремя метками сигнал появляется у всех трёх, а `t` и
`r` слегка проседают.

> **«Два» — не закон правила. Это размерность пространства орбит того,
> что подано на вход.** В симметричном мире событие и можно определить
> только парой `(t, r)`. Вносишь асимметрию — появляются новые числа.

Добавочные каналы слабы (0.10 против 0.99), потому что несколько меток —
слабое нарушение симметрии. Но направление однозначно.

### Важная оговорка о масштабе утверждения

«Два числа» — это то, что восстанавливают **скалярные признаки
отдельного события**. Сам порядок содержит несравнимо больше: по теореме
Маламента–Хокинга–Кинга–Маккарти причинная структура определяет всю
конформную геометрию. Это разные утверждения, и формулировка архива
«порядок помнит ровно два числа» — слабейшее из них.

Правильнее так: **из одного события порядок выдаёт его место в орбите
симметрии; из всего порядка — всю геометрию до конформного множителя.**

## Следствие для постановки задачи

Подавать на вход больше двух чисел на событие бессмысленно — правило их
не сохранит. Значит выбор входа сводится к одному: **связаны шкалы или
нет**.

- не связаны → мир есть порядок доминирования, размерность задаётся
  числом шкал, `t` и «заряд» без геометрии;
- связаны как проекции точки → мир есть причинная структура Минковского,
  размерность задаётся размерностью точки, два числа становятся `t` и
  `|x|`.

Третьего варианта правило не предлагает, и искать «что ещё положить на
вход» не нужно — надо выбирать, как связать то, что уже кладём.
