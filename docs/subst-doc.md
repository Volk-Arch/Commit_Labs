# Без монетки: правило подстановки

Дата: 12 октября 2026. Код: `code/substit.py` (показатель шума), `code/substcosmo.py` (против сверхновых).

## Ход

Вместо монетки — детерминированное разворачивание: каждое событие порождает
детей по фиксированному правилу (подстановка, как a→ab, b→a у Фибоначчи).
Отклонение счёта растёт как D(L) ~ L^h, h = ln|λ2|/ln λ1 (λ — собственные
числа матрицы подстановки; Oğuz–Socolar–Steinhardt–Torquato про (анти)гиперуниформность).

* |λ2| < 1 — отклонение ограничено (кристалл). Фибоначчи: λ2 = −1/τ — тень
  сжимается; это и есть причина «Λ на 30 порядков мала».
* |λ2| = √λ1 — h = 1/2 ровно, как у монетки Соркина: Λ ~ 1/√V без случайности.
* |λ2| > √λ1 — h > 1/2, Λ растёт относительно H².

Порог монеток по родословной q = 1/τ² — это то же условие: qλ1 = √λ1 при
λ1 = τ⁴. Детерминированное правило живёт ровно в точке порога.

**Золотое правило:** a→acd, b→cd, c→abc, d→ab. Характеристический многочлен
(x²−3x+1)(x²+x−1), собственные числа τ², −τ, 1/τ, 1/τ²: второе — ровно корень
из первого. Найдено перебором 0/1-матриц 4×4 (12 штук).

| правило | h теория | h замер |
|---|---|---|
| Фибоначчи | 0 (ограничено) | −0.00 |
| a→aabbbb, b→aa (4, −2) | 0.50 | 0.51 |
| a→abbbb, b→baaaa (5, −3) | 0.68 | 0.69 |
| золотое (τ², −τ) | 0.50 | 0.49 |
| монетка | 0.50 | 0.46 (оценка по максимуму занижена) |

## Против сверхновых

Самоподобие делает историю Λ лог-периодической: ΛV = 8πα√V·g(ln V), профиль g
повторяется каждый период ln λ1 (у золотого — со сменой знака каждые 0.96 по
ln V, т. е. каждые ~16 % роста a). 200 фаз × сетка α, Ω_m, условия H0 = 60…80,
0.2 < Ω_m < 0.45:

* золотое: допустимых миров 0 — отрицательные фазы Λ роняют H² < 0;
* a→aaab, b→abbb (4, +2, без смены знака): все 200 допустимы, лучший Δχ² = +314.

Монетка иногда «везёт» (спокойная история у 0.07–0.3 % миров); у правила везения
нет — оно повторяет один и тот же узор, и узор слишком частый.

## Итог

Изящно для величины (h = 1/2 точно, порог = второе собственное число = √первого,
золото даёт его точно), плохо для истории: строгая периодичность по ln V
отвергнута сверхновыми. Это 1D-игрушка; в 3+1 нужна инфляция с объёмным
множителем λ1 и отклонением √λ1 — не построена.

Следующая мысль: детерминированный хаос по родословной (скрытая фаза события
на торе, дети получают её образ под золотой «кошкой Арнольда» [[2,1],[1,1]],
собственные числа τ², 1/τ²) — даёт монетко-подобную, но не периодическую
последовательность. Не проверено.
