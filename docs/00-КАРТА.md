# Карта проекта: что готово и что нет (16 октября 2026)

Это сводная карта: всё, что получено за проект, от первых опытов с порядком и киральностью до обмена в паре электронов,
плюс всё незакрытое из роадмапа. На каждый пункт по 1–2 строки и ссылка на документ, где лежат подробности и числа.
Хронология — в `00-ИНВЕНТАРЬ.md` (новые записи сверху), дорога — в `00-РОАДМАП.md`, код — в архиве `goldlab`
(начинать с `goldlab/СТАРТ.md`, `python -m goldlab.selftest`).

**Значки.** ✓ — стоит (замер или вывод); ◐ — частично; ✗ — честный отрицательный результат (тоже результат: дверь
закрыта и известно чем); ↺ — отозвано (было, оказалось неверным); ☐ — открыто. В скобках — где читать.

**Одной строкой.** Из одного отношения «раньше» выводятся время, относительность и (на золотом кристалле) гравитация и
поле; пространство и квантовость требуют наблюдателя и «тени»; с ними выходят амплитуды, Белл, масса, свет, атом,
спин, Паули и обмен. Руками пока: масса, величина заряда, закон движения Джонстона, форма среза, нормировка вершины пары.

## Часть 0. Метод — правила, которые держат проект

- ✓ **Критерий физичности:** утверждение физично, только если не меняется при смене произвольной части — нумерации,
  шкал, нормировки, единиц (`00-ИНВЕНТАРЬ` §9, `ARTICLE` §10).
- ✓ **Проверять там, где ответ — точный ноль:** нуль нельзя подогнать; этот контроль поймал опровержение всей
  компонентной серии (промах 9.5σ, `design-doc`).
- ✓ **Всё твёрдое — тождества, нули, проверки теорем и отношения; всё отозванное — величины** (абсолютный масштаб
  втекал руками через плотность ρ) (`00-ИНВЕНТАРЬ` §9).
- ✓ **Не подавать величину отношением, если можно тремя числами:** отношение выбрасывало 97 % информации
  (`carrier-doc`). Фиксировать истину и мерить разброс ОЦЕНКИ, а не ширину корзины.
- ✓ **«Если исправление не изменило ни одной цифры, оно ничего не исправило»;** якорь проверки обязан идти через тот же
  код (`crit-doc`, `wscan-doc`).
- ✓ **Не открывать закрытый маршрут тем оценщиком, которым его закрывали** (`sigma-doc`).
- ✓ **Число протокола ≠ число физики:** четыре случая за неделю, когда показатель оказался свойством окна/процедуры
  (`census-doc`, `sigma-doc`, `exponent-doc`).
- ✓ **Принцип пользователя (14 окт.):** физика, а не симулятор ради фич; частицу и античастицу не выбрасывать;
  каждое упрощение помечать «приближение»; у каждого опыта — список «взято руками» (`00-РОАДМАП`, goldlab `HAND`).

## Часть 1. Порядок → время, пространство, относительность (1–6 окт., `ARTICLE.md`, `STATE.md`)

- ✓ **Правило одно:** событие несёт k чисел, A раньше B, если раньше по ВСЕМ сразу. Единогласие — единственный порог,
  дающий порядок (петли длины ≥ ⌈k/(k−m)⌉, 18/18) (`majority-doc`, `improbable-doc`).
- ✓ **Весов не существует — теорема:** транзитивны ровно единогласия на подмножествах шкал (8 из 20 при k=3, 16 из 168
  при k=4) (`monotone-doc`).
- ✓ **Числа сами ничего не значат:** симметрия перешкалирования Diff⁺(ℝ)ᵏ, 0 различий из 640 000 (`rescale-doc`).
- ✓ **Конус ≡ шкалы t − u·x:** 0 различий из 1 440 000; k — не размерность, а разрешение конуса (`correlated-scales-doc`).
- ✓ **Сколько граней у конуса:** нужно ~√N граней (k = 10/14/20 при N = 200/400/800); конечным числом шкал 4D
  Минковского не получить — теорема (dim ≤ k) (`star-doc`, `orthant-doc`, `cone21-doc`).
- ✓ **Время выходит само:** число событий в интервале — часы, корреляция с собственным временем +0.958 (`particles-doc`).
- ✓ **Пространства в порядке нет — теорема:** буст меняет поперечник в 5 раз при точном совпадении всех порядковых
  величин. «Порядок — совершенные часы и слепая линейка» (`locality-doc`, `frames-howto`).
- ✓ **Пространство наводит наблюдатель:** радар по одной цепи — время и расстояние с корреляцией 0.9998 / 0.9997 (`radar-doc`).
- ✓ **Лоренц из двух цепей:** A = γ² с промахом 0.04–0.49 %, координат в выводе нет (`radar-doc`).
- ✓ **Четыре цепи → метрика Минковского (GPS):** невязка 0.008ℓ, коэффициент 0.0759 против 0.0760 (`gps-doc`, `gpsrule-doc`).
- ✓ **Кинематика выведена:** порядковая площадь ⟨F_k⟩ = a·Γ(k+½)/Γ(k+1) (`kinematics-doc`); поперечник
  восстанавливается порядково W = 2λr (`partial-doc`).
- ✓ **Гипероднородность ромба:** показатель 0.3743 против (d−1)/(2d) = 0.375 — 0.0σ (`hyperuniform-doc`).
- ✓ **Связи через горизонт — по площади** (r_s^2.29, от объёма 12σ) и **сильная субаддитивность** выполнена (11σ)
  (`horizon-cone-doc`, `holography-doc`).
- ✓ **Корона ловит «орту»:** минимальная ловушка — 6 элементов (корона S₃), у засева 1+1 ровно 0 корон (`crown-doc`).
- ✓ **Фейсконтроль:** доля связанных ВНУТРИ интервала (0.10 при d=4, 0.50 в 1+1) ловит слоистого врага двумя
  локальными числами (`facecontrol-doc`, `localcheck-doc`).
- ✓ **В 1+1 кинематика решена:** засев = случайная пара перестановок, ограничение достаточно, вес не нужен (`kin11-doc`).
- ✓ **Шум искажает, а не заменяет:** турнир большинства несёт единогласный порядок (подъём ×18–19) (`noise-doc`).
- ✓ **Связи можно обрезать до ~ln N** без изменений (1+1); стена шума — от множителя ρ, не от хвоста (`trunc-doc`).
- ↺ Размерности до 4 октября — ошибка оценщика Мирхейма–Мейера (знаменатель 2, не 4): 4D читалось как 7D (`locality-doc`).

## Часть 2. Киральность — образцовый случай (`00-ИНВЕНТАРЬ` §7, архив `chirality-doc`)

- ✓ **Замер чистый:** левое и правое различаются, нарушение чётности максимальное — 0 левых против 64 485 правых;
  зеркало даёт 126 645 различий, поворот ровно 0; «бесплатна» — транзитивность остаётся 1.000.
- ↺→◐ **Ранг понижен:** перешкалирование шкал переворачивает киральность у ~половины пар (0.49 / 0.47 / 0.53), значит
  это свойство калибровочной части конструкции, а не мира (`connection-doc`).
- ✓ **Что уцелело:** киральность интерферирует — когерентность 0.961 против 2.000 у порядковых версий (`sorkin-doc`).
- ✓ Позже (13 окт.) лево/право вернулось уже как свойство кванта: «лево/право звена» на кристалле, монета [[1,i],[i,1]]
  (`noise-shadow-doc`), а 15 окт. — как ориентация светового уголка у спина (Часть 13).

## Часть 3. Вещество, кривизна, уравнение состояния (5–9 окт., `00-СВОД.md`, `ARTICLE.md`)

- ✓ **Вещество = разрежение:** обе половины тяготения с верными знаками даёт «дырка», а не сгущение (4.5σ / 5.0σ) (`ARTICLE`).
- ✓ **Уравнение состояния из чистого порядка:** w = +0.3339 ± 0.0157 (излучение, истина 1/3, 0.04σ); +0.97 ± 0.14
  (жёсткое); плоское отвергнуто. Это «термометр», а не открытие этапов вселенной (`weos-doc`, `exact-doc`).
- ✓ **Прибор стал точным:** формулы для конформно-плоских метрик при любом τ, 90 сравнений, медиана 0.75σ (`exact-doc`).
- ✓ **Действие Бенинкасы–Доукера проверено:** −0.49871 против −1/2; −0.20312 против −1/(2√6); наклон на кривом
  +0.42 ± 0.10 против +0.5 (`00-СВОД`).
- ✓ **Двухточечный интеграл точно:** ⟨N_m⟩ при любом N без сприклинга; тождество Σ w_m Γ(m+½)/m! = 0 — почему ⟨S⟩ не
  растёт; предсказание при N = 10⁴ сошлось до 0.3 % (`nm-doc`).
- ✓ **Закон разброса действия без параметров:** σ(S) = k₄√(Σw_m²N_m)·√(1−q), слоистые 0.709 против 0.7071 (`sigma-doc`).
- ◐ **Закон дефицита:** −1.062 ± 0.060 — замер в своём окне стоит, но степенного закона нет (показатель течёт −0.81…−1.77);
  «ньютоновский 1/r выведен» — ↺; профиль предсказуем из геометрии ромба (бьёт Ньютона в 3–5 раз) (`00-ИНВЕНТАРЬ` §0а, `theory-doc`).
- ↺ **Вся компонентная серия** (R_xx, R_ηη, возраст Вселенной 13.6 планковских времён и т.д.): допущение X₂ ~ R_uu
  опровергнуто точным интегралом, рабочая точка вне разложения (`design-doc`, `exact-doc`).
- ↺ Отклик холономии 17.3σ — тавтология (Симпсон); сглаженное действие; загиб к полю (мир с полем не причинное
  множество); «+7.25 заряд подействовал» — был с силой, заданной руками (`00-ИНВЕНТАРЬ` §6, 14 окт.).

## Часть 4. Отбор и рост — все двери закрыты, и известно чем (6–11 окт.)

Главный вывод дуги: **враг (слоистые порядки) — трёхпараметрическое семейство, замкнутое относительно всего, что с ним
делали**; поэтому правило обязано быть не функцией конфигурации, а условием на РОСТ, и геометрия нужна правилу как
состояние (координаты).

- ✗ **Рост Райдаута–Соркина:** L − H = 1 тождественно при любой последовательности → не достигает d ≥ 4; порядки
  семейства на 96 % транзитивны (`growth-doc`, `csg-doc`, `pflow-doc`).
- ✗ **Фазовое погашение:** слоистый сектор растёт как e^{+0.117N²} при всех ℏ (781 точка), закрыто точной суммой; свобода
  весов (1734 точки) и размазка (14 точек) не помогают (`cancel5-doc`, `wscan-doc`, `smear-doc`).
- ✗ **Мера роста:** окно закрывается при N ≈ 180–220; различитель — СВЯЗИ: правильная динамика не может взвешивать по
  связям (`growthsel-doc`, `measure-doc`).
- ✗ **Существует ли действие вообще:** объёмного нет (сертификат Фаркаша); БД отбора не даёт; разделяет только граничный
  счёт; размерность не выводится (`actionexist-doc`, `census-doc`).
- ✗ **Запреты (легальность):** при d ≥ 3 запрещать нечего — все порядки до 7 элементов реализуемы; конечного списка
  запретов нет даже в 1+1 (0, 3, 21 минимальных препятствий) (`forbidden-doc`, `compose-doc`).
- ✗ **Самоподобие как условие:** лазейки при каждом N — почти полный порядок проходит любое «часть похожа на целое»
  (`selfsim-doc`, `fractal-doc`).
- ✗ **Квантовый слой из независимой расстановки:** действие гауссово; «смесь нужна кванту и запрещена отбору» (`qscales-doc`, `qcond-doc`).
- ✗ **Знак от инварианта формы:** ковариантность запрещает ровно фермионный механизм — носитель знака должна быть
  МАТЕРИЯ на множестве, а не само множество (`sign-doc`). (Именно туда проект и пришёл 15 окт.)
- ✗ **Огрубление как поток:** прореживание переводит врага в него же (`coarse.py`); **материя на порядке** — стена шума
  статистическая, путь только аналитический (`matter-doc`, `noisewall-doc`).
- ◐ **Критичность:** архивное опровержение недействительно (гистограмма — гребёнка); пик теплоёмкости растёт ~N^1.2; в
  переходе доля связанных = двумерная; но ни одна геометрия не подходит по всем наблюдаемым (`crit-doc`, `crit-geom-doc`).
- ✓ **Три независимых расчёта дают одну границу N ≈ 100…350** (переход, мера роста, дефицит энтропии) — явление без имени (`census-doc`).
- ✓ **Склейка:** правило локально не в порядке, а в координатах; «нести координаты» и есть геометрия (`compose-doc`).
- ✓ **Предел на исходящие связи ~ln N** работает в 1+1 (`cap-doc`); **размерность течёт** у роста с фиксированным
  числом родителей (1 → 2 → 3) — первая такая конструкция (`dimflow-doc`).
- ✓ **Доля, а не среднее:** вектор отношений обилий N_m/N₀ разделяет засев и врага по конфигурациям (45/50 против 0/40) (`prostoe-doc`).

## Часть 5. Носитель квантовой фазы (10 окт.)

- ✓ **Фаза живёт в часах:** разброс собственного времени s ∝ N^−0.53; бюджет фазы e^{imτ} растёт как N^0.53 — в 450
  раз больше фазы гравитационного действия (`qclock-doc`).
- ✓ **Квантовая механика на фиксированном порядке (Джонстон):** в 1+1 шум пропагатора ∝ N^−0.556 = дробовой шум часов
  (0.7σ); в 3+1 флуктуация не убывает — нужен ансамбль (`johnston-doc`).
- ✓ **Закон лестницы:** показатель = половина размерностной доли носителя (объём 1/2, поверхность 3/8 → замер 0.388,
  линия 1/8 → 0.125) (`qruler2-doc`, `carrier-doc`).

## Часть 6. Золотой кристалл (11–12 окт., `golden-doc.md`)

- ✓ **Формула мира в две строки:** событие есть ⟺ его тень (сопряжение Галуа a+bτ → a−b/τ) в шаре; A раньше B ⟺ B − A
  в световом конусе. Без случайности (`golden-doc`, `formula-doc`).
- ✓ **Точный буст:** 1+1 — 40 ± 0.7 точек в ромбе при ЛЮБОМ бусте (Пуассон ±6.3, квадратная решётка 89 % пустых);
  3+1 — η₀ = ln(τ+√τ) = 1.0613, 3751/3751 образов; бусты до ×8000 без пустых ромбов (`lattice-doc`, `gold4-doc`, `predict-doc`).
- ✓ **Почему именно τ:** самый мелкий буст ниже 2 — только τ (Кронекер) (`finest-doc`); буст вращает тень только при
  θ² = θ + 1 — «точнее или грубее» τ взять нельзя (τ 0.99; серебро 0.59; дроби 0.01) (`golden-doc`, опыт `whytau`, 15 окт.).
- ✓ **Самоподобие и де Ситтер:** мир с тенью ×τ⁻ᵏ = мир ×τᵏ; рост вглубь = экспоненциальное расширение (`desitter-doc`, `fixgold-doc`).
- ✓ **Петля «порядок → радар → круглый конус»** сходится из любого старта за 2–4 шага (`fixloop-doc`).
- ✓ **Отпечаток кристалла:** размеры интервалов — гребёнка (никогда 3, 5, 6, 11…); шаги времени 1 : τ : τ² (0.300 /
  0.486 / 0.786) (`lattice-doc`, goldlab `core.py`).
- ✓ **Дисперсии света нет по симметрии** (LHAASO пройден) (`worldtest-doc`); **виляния частиц нет** (`swerve-doc`).
- ✓ **Сбой расходится как 1/R по связям** (Ньютон в Нордстрёме) (`defect-doc`); **задержка Шапиро одним порядком**
  0.257/0.219/0.192/0.133 против ОТО 0.273/0.218/0.173/0.132 — коэффициент 2 руками (`tilt-doc`).
- ✓ **Горизонт возникает сам;** «двойка = вакуум»: правило «малые ромбы плоские вне вещества» выбирает γ* = 1.34 ± 0.30,
  Нордстрём отвергнут на 7.8σ (`horizon-two-doc`, `oneformula-doc`).
- ✓ **Небесная механика из порядка:** самая длинная цепочка идёт по орбите, Кеплер T ∝ R^1.50; петля света; тень дыры
  5.19M (5.196); восьмёрка трёх тел 400/400 периодов на кристалле (`sky-doc`).
- ✓ **Волны с массой:** Джонстон звенит как J₁(mτ); на золоте точнее посыпки (`waves-doc`, `mass-doc`).
- ✓ **Тень = компактный двойник Лоренца:** буст η₀ ↔ поворот тени 128.17° (cos = −1/τ), группа покоя — куб (`shadow-doc`).
- ◐ **Λ:** одна Λ на весь прошлый конус наблюдателя — w = −1 точно, CMB-проблема исчезает; DESI-намёк 2.4σ против (угроза);
  α ≈ 1 из молекул горизонта при антропном отборе (`frozen-doc`, `alpha-doc`, `lineage-doc`, `fuzzy-doc`, `cosmo-doc`).
- ✓ **Шум = незнание = тень:** восемь видов шума живут в тени; лестница ×τ гасит теневое (`noise-shadow-doc` §1–5).

## Часть 7. Гравитация и поле как изгиб среза (12–13 окт., 14 окт. ночь)

- ✓ **Изогнутый срез вместо лоскутов:** след даёт объемлющее пространство с одним временем (R^{1,3} / R^{1,7}); dS2 — число
  событий в ромбе = точная площадь при любой кривизне (`bentcut-doc`).
- ✓ **Чёрная дыра изогнутым срезом:** Шварцшильд вложен в R^{1,6} точно; анизотропия как у засева; орбиты — наклон трубки
  4.09 ± 0.62 из 4.12 (`bentcut-doc`).
- ✓ **Калибровочное поле из закрутки окна:** Гаусс — гравитация = ΣK_aK_a; Риччи — поле = [K_a, K_b]; однородное поле
  F = −2κ²; 80–91 % силы Лоренца (`gauge-doc`).
- ✓ **Уравнения среза = гравитация вложения (Редже–Тейтельбойм):** Шварцшильд сохраняется; материя вложения — давление,
  p_t/p_r → 1/4, M_доп ∝ r^{3/2}; в R^{1,7} — ровно Эйнштейн, тёмной материи вложения нет (`slice-doc` §1–6).
- ✓ **Тень идёт четвёрками** (4, 8, 12 направлений; 6 невозможно); кубический кристалл θ = 2cos(2π/7) с точным бустом,
  SO(8) ⊃ SU(4) ⊃ SU(3) (`slice-doc` §7).
- ✓ **Порядок по полному следу** — окно становится малыми измерениями (размерность 4.3 → 2.3 с масштабом) (`gauge-doc`).
- ✓ **Симулятор вселенной** `universe.py` и «Обсерватория винтовой дыры» (885 648 событий) (`universe-doc`).

## Часть 14. Двигатель эволюции: развёртка по слоям (15 окт., `dirac-doc` §15; `fermions.pair_ladder`)

**Что это.** Способ считать, как живёт система двух взаимодействующих частиц, — не пересчётом всей задачи разом, а
шаг за шагом по слоям времени кристалла, как настоящая эволюция.

**Почему это работает (простыми словами).** Амплитуда пары в событиях (y₁, y₂) зависит только от того, что было раньше:
от пар событий, лежащих в прошлом. У кристалла время дискретно — слои с точными значениями t (шаги 1 : τ : τ²). Значит
можно идти снизу вверх: на каждом слое берём уже готовое прошлое, протягиваем его на один слой вперёд и добавляем
взаимодействие в этом слое. Каждая строка считается один раз и больше не трогается. Прежний способ (GMRES) решал всю
систему сразу и «угадывал» ответ итерациями — на мире 24 он застывал и не сходился.

**Формула.** A = Kᵀ(F + W∘A)K, где K — пропагатор одной частицы (сумма по цепочкам), F — источник, W — вершина
взаимодействия. Слой за слоем: A[слой] = K[:, слой]ᵀ·H; G[слой] = F[слой] + W[слой]∘A[слой]; H[слой] = G[слой]·K.

**Что даёт.**
- Все порядки взаимодействия сразу (не только первый), без итераций и без застревания.
- Цена ~2n³: мир 28 (6300 событий) — 1–2 минуты на прогон; ограничение — память (n² чисел), не время.
- Это прямой аналог «эволюции во времени» в квантовой механике, но без выделенной системы отсчёта внутри: слои —
  это слои самого кристалла, а K между ними — сумма по всем цепочкам порядка.
- Тот же приём подходит для любой задачи «две частицы + вершина»: атом без ядра (позитроний), рассеяние, аннигиляция,
  трёхчастичные (литий) — память растёт как n^k, поэтому для трёх частиц нужен другой ход (например, среднее поле + пара).

## Часть 15. Статистический взгляд: что мы считаем из порядка и чем это оказывается

Всё в проекте — счёт по одному причинному множеству разными способами. Таблица показывает, какие счёты уже стали
физикой, — и подсказывает, как связать между собой те, которые пока живут отдельно (это ключ к нормировке вершины).

| что считаем по порядку | чем оказалось | где |
|---|---|---|
| число событий в интервале | собственное время (часы) | `particles-doc`, `qclock-doc` |
| длиннейшая цепочка | собственное время, свободное падение | `sky-doc` |
| радар по цепи-наблюдателю | расстояние и время; две цепи — Лоренц | `radar-doc` |
| доля связанных пар внутри интервала | размерность (0.10 / 0.50) | `facecontrol-doc` |
| профиль размеров интервалов N_m | кривизна (БД), уравнение состояния | `weos-doc`, `nm-doc` |
| число связей через поверхность | закон площади / объёма | `horizon-cone-doc` |
| сумма по цепочкам (½ на шаг, −m²/ρ на остановку) | пропагатор частицы с массой (Джонстон) | `johnston-doc`, `mass-doc` |
| ½ за событие источника в прошлом конусе | потенциал заряда (Кулон 3+1, линейный в 1+1) | `maxwell-doc`, `dirac-doc` §7 |
| то же с весом плотности облака | поле электронного облака (Хартри) | `dirac-doc` §14 |
| спектр i(K − K†) | частицы и античастицы, бозоны/фермионы | `maxwell-doc` §23, `dirac-doc` |
| пары несравнимых событий двух историй | взаимодействие пары (вершина) | `maxwell-doc` §26, `dirac-doc` §15 |
| события между двумя историями (площадь) | «струна» поля в 1+1 — точная электродинамика [кандидат] | ☐ |
| ориентация уголка (какой луч первый) | спин / киральность | `dirac-doc` §12 |

**Что из этого следует для нормировки (проверено 16 окт., `dirac-doc` §16: наклоны пары предсказаны на 0.92–0.98, «гелий» до 1–2 %).** Сила взаимодействия пары уже
задана другим счётом — «½ за событие в прошлом конусе» (одночастичное поле, абсолютная нормировка известна и проверена
в атоме). Значит вершину пары не нужно угадывать: её вес λ обязан быть таким, чтобы в пределе «один партнёр — неподвижное
облако» двухчастичная эволюция совпала с одночастичной в поле этого облака. «Вес» каждой частицы (во сколько раз
вставка сдвигает её уровень) можно ИЗМЕРИТЬ на кристалле той же вставкой — без теории. Тогда λ = (сила поля) /
(произведение весов двух частиц), и физический «гелий» считается целиком, со всеми порядками. Это проверка двух разных
счётов одного и того же — то есть статистическая сшивка, а не подгонка.

**Чего ещё не считали, а можно:** число событий между историями (площадь — кандидат на точный закон поля в 1+1);
связи, пересекающие историю частицы (кандидат на «ширину» частицы / собственную энергию); корреляции счётов в соседних
ромбах (кандидат на флуктуации поля — фотоны в 3+1); число цепочек заданной длины между событиями (уже есть у
Джонстона — кандидат на нормировку пропагатора в 3+1, где флуктуации не гаснут).

### Уровень 0–1 (основание, кванты)
- ◐ Форма среза (гравитация, поле) задана руками — нужен закон среза из уравнений.
- ◐ Λ: одна на конус, w = −1 — ждёт данных (DESI против на 2.4σ).
- ☐ Однородное поле и синглет слияния у Боба одновременно.

### Уровень 2 (частица)
- ☐ Толщина среза: что задаёт разрешение по времени (число мод SJ зависит от толщины).
- ☐ Дирак: привязка спина к направлению движения (спиральность).
- ☐ Массовое правило: связаны ли допустимые массы с масштабом кристалла и τ (неподвижная точка укрупнения?).
- ☐ Заряд: недобор 8–9 % при m = 2, 3; отклонения вне оси; величина элементарного заряда (Калуца–Клейн, окно).

### Уровень 3 (взаимодействия)
- ◐ Уравнения изгиба среза: ☐ решающий опыт на кристалле — закон (А) Эйнштейн или (Б) Редже–Тейтельбойм;
  ☐ тёмная материя вложения только при тени ≥ 6 направлений.
- ◐ Уравнения закрутки: ☐ вывести □A = J из закона трубки; ☐ заряд как намотка e^{imθ} на квантах.
- ◐ Сила между квантами: ☐ 3+1; ☐ источник — сам квант, а не полоса.
- ◐ Связанные состояния: ☐ 2s водорода (окно больше); ☐ чётный канал пары; ☐ вывести вершину из кристалла при большей плотности.
- ☐ Правила пересечений: контакт λ на общем событии; спин–статистика зигзага.
- ☐ Рассеяние частица–частица.
- ☐ Частица + античастица: аннигиляция (в 1+1 связанная пара не может уйти «в свет», как в модели Швингера; в 3+1 — в два кванта).

### Уровень 4 (3+1, цвет)
- ☐ Белл / Renou в 3+1.
- ☐ Почему U(1) внутри SU(2)×SU(2) окна.
- ☐ Сильное взаимодействие: самодействие поля (Янг–Миллс), SU(3) ⊂ SO(8) в 3+1 (кубический кристалл), конфайнмент — «струна»
  поля между цветными зарядами.

### Уровень 5 (проверяемое)
- ☐ w = −1 против данных; ☐ нет дисперсии света; ☐ комплексность ↔ поле; ☐ ёмкость каналов по узкому сечению.

### Уровень 6 (симулятор, «финальный босс»)
- ◐ Песочница 1+1 v0.3 (две щели, Алиса и Боб, атом): ☐ делители-события вместо идеального поворота; ☐ распад на два кванта;
  ☐ атом из двух подвижных частиц.
- ◐ goldlab: ☐ форма среза из уравнений; ☐ масса — ?; ☐ 3+1-вид мира в пульте; ☐ перенести вкладки песочницы в опыты.
- ☐ 2+1 с картинкой; ☐ 3+1 (спин, поле, гравитация); ☐ самосогласованный мир (объекты сами изгибают срез).

### Старые открытые вопросы основания (6–11 окт.)
- ☐ Динамики (закона роста) нет — ни здесь, ни в программе Соркина; известны четыре запрета на её форму.
- ☐ Задача меры не решена (однородная мера на помеченных порядках принята, а не выведена).
- ☐ Граница N ≈ 100…350 — одно явление в трёх расчётах, без имени.
- ☐ Критичность: какая фаза живёт в точке перехода (нужны N = 28…32, в 3–5 раз больше развёрток).
- ☐ ẇ: прибор откалиброван, нужен охват по времени в разы шире; плечо w = −1/3.

### Параллельно (применения)
- ☐ Заметка «Лоренц-инвариантная дискретизация полей на золотом кристалле» (Джонстон на золоте точнее посыпки).
- ☐ Принципы фотонного квазикристаллического чипа (делители, синглет по симметрии, слияние).
- ☐ Прототип «причинного» языка (программа = причинное множество).
