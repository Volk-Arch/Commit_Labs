# Два порядка на одних событиях

### Дополнение к `ORDER-final.md`

Идея: вместо добавления метки (заряда) — добавить **второй порядок**. У события $k+1$ шкал;
порядок $A$ строится по шкалам $0..k-1$, порядок $B$ — по $1..k$. Они делят события, но
различаются.

Взаимодействие могло бы возникнуть из их сопоставления, а не из вложенной величины.

---

## ⭐ Порядки совместимы

$N$=800, $k$=5:

| | значение |
|---|---|
| согласны (оба говорят «раньше») | 18796 |
| только $A$ | 25605 |
| только $B$ | 17305 |
| **противоречат** ($A$: $i$ позже $j$, $B$: наоборот) | **0** |

**Противоречий нет** — порядки совместимы. Доля согласия 42%.

---

## ⊗ Пересечение — тождество

| порядок | доля пар | размерность | спектр |
|---|---|---|---|
| $A$ (шкалы 0–3) | 0.1313 | 3.68 | −0.0063 |
| $B$ (шкалы 1–4) | 0.1367 | 3.63 | −0.0087 |
| **пересечение** | **0.0700** | **4.42** | **−0.0037** |
| **порядок по всем 5 шкалам** | **0.0700** | **4.42** | **−0.0037** |

**Совпадают до знака.** Пересечение условий и есть условие по всем шкалам — тождество, а
не новая структура.

---

## ⊗ Объединение почти сводится к порядку меньшей размерности

| порядок | доля пар | размерность | нарушений транзитивности |
|---|---|---|---|
| объединение | 0.1980 | 3.18 | **14607** |
| объединение замкнутое | 0.2449 | 2.91 | 0 |

Объединение **не транзитивно** — приходится замыкать.

### Сравнение со всеми наборами шкал

| | значение |
|---|---|
| ближайший набор | шкалы **(1, 2, 3)** |
| **совпадение** | **0.9898** |
| различий | 5020 из 490000 |

### И различия односторонние

| | значение |
|---|---|
| есть в порядке (1,2,3), нет в объединении | **4925** |
| есть в объединении, нет в (1,2,3) | **0** |

**Объединение — подмножество** порядка по трём шкалам, слегка прорежённое. Различающиеся
пары отличаются по шкалам 0 и 4 (0.39 против среднего 0.34) — тем, что входят лишь в один
из порядков.

---

## Итог

⊗ **Новой структуры не возникает.** Пересечение двух порядков есть порядок по объединённому
набору шкал (тождество); объединение — тот же порядок меньшей размерности, прорежённый на
1%.

> **«Добавить ещё одну проекцию» не даёт нового качества** — получается тот же тип
> объекта с другим числом шкал.

⚠ Проверена одна схема (перекрывающиеся наборы шкал). Другие способы задать два порядка —
например, независимые случайные — не пробовались.

*Реализация: `twoorders.py`.*
