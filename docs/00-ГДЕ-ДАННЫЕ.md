# Данные набора — спасены из сессионной папки 8 октября 2026

Набор лежал в `/tmp/claude-0/-home-claude/<НОМЕР-СЕССИИ>/scratchpad`,
путь которой содержит номер сессии. Новая сессия — другой путь, и всё
пропало бы. Скопировано сюда, в `/home/claude/data`.

**В коде путь задан константой `SCRATCH` в `pencil.py`.** В новой сессии
её надо переставить на `/home/claude/data`, иначе скрипты не найдут
данные и начнут набирать заново.

## Что здесь

- `pencil.pkl` — основной набор: плечи `lin`, `quad`, `flat`, по 104
  засева, 43680 строк каждое. Это то, на чём стоят все компонентные
  результаты.
- `expfam_{0,30,60}.pkl`, `rootfam_{0,30}.pkl` — плечи `exp` (90
  засевов) и `root` (60).
- `expfam_{1000..}.pkl`, `linfam_{1000..}.pkl` — ночной набор 8 октября
  при `per = 120` (доля независимости 0.71 против 0.33 при 420).
- `linfam_{500,530}.pkl`, `expfam_500.pkl` — три чанка при `per = 420`,
  до перестройки дизайна.
- `curve.pkl`, `c4.pkl`, `frw.pkl`, `jacob.pkl` — наборы прежних этапов.
- `bigfall_*.pkl` — чанки закона дефицита.

## ВАЖНО про компонентные данные

Строки в них — это `(C_1, X_2, X_3, v², mid)`, и они в порядке. Но
ПОДГОНКА, которой они обрабатывались до 8 октября, неверна: план стоял
на допущении `X_2 ~ R_uu`, опровергнутом точным интегралом. Правильный
план — в `pwfix.py`, профили в `design-doc.md`. Данные переделывать не
надо, надо переподгонять.
