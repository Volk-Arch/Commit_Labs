# Исправление основного прибора: `X_2` не измеряет `R_uu`

## Что было неверно

Весь конвейер измерения кривизны стоял на допущении

    X_2 = V2CAL * R_uu * tau²,    R_uu = (R_etaeta + R_xx v²)/(1 - v²)

то есть что малый интервал видит ТОЛЬКО компоненту Риччи вдоль своей
оси, а при покое — только `R_etaeta`. Допущение **опровергнуто точным
интегралом**.

Решающее плечо — экспоненциальное. У `a = e^{k eta}` величина
`R_etaeta = 3(a'²/a² − a''/a) = 0` **точно**, поэтому старый план обязан
предсказать `X_2 = 0` при покое. Точный интеграл даёт
`+0.00246 ± 0.00026` — промах **9.5 сигмы**.

Линейное плечо к этой ошибке **слепо**: у него `a'' = 0`, и смесь даёт
−0.0567 против модельных −0.0603, расхождение 6% — ровно внутри
калибровочной погрешности 14%. Я валидировал модель на единственном
плече, которое не может её опровергнуть.

## Как получено верное выражение

Без сприклинга вообще. Для конформно-плоских метрик `a(eta)² eta_{mu nu}`
причинность **точно плоская** (причинность конформно-инвариантна, и код
это уже использует: отбор идёт по плоскому условию `dt² > |dx|²`).
Значит кривизна входит единственным образом — через плотность точек:
физическая плотность постоянна, объёмный элемент `a⁴ d⁴x`, координатный
вес `w = a⁴`.

Нормировка `X_2 = C_2/(c_2 a(a−1)) − 1` берётся при НАБЛЮДЁННОМ `a`,
значит при заданном числе точек они независимы с плотностью `~ w`, и
второй факториальный момент даёт точно

    1 + X_2 = [ ∫∫_{x≺y} w w ] / [ c_2 (∫w)² ]

Разложение `w` у середины (`phi = 4 ln a`, `delta = eta − eta_m`) даёт
первый порядок нулём по симметрии отражения времени, и остаются три
чистых геометрических момента ромба:

    S = <delta²>                 по ромбу
    Q = <delta_x² + delta_y²>    по упорядоченным парам
    P = <delta_x delta_y>        по упорядоченным парам

`P` не нуль, хотя каждый сомножитель в среднем нуль: у упорядоченной
пары `x` сидит в ранней половине, `y` в поздней, и корреляция порядка
остаётся. Именно её я сначала потерял — и первая версия вывода из-за
этого не сходилась.

С `u = a''/a`, `vv = a'²/a²`, подставляя
`u = (R_xx − R_etaeta/3)/2`, `vv = (R_xx + R_etaeta/3)/2` в
`16 vv P + (2u + 6vv)(Q − 2S)`:

    X_2 = [ A(v²) R_etaeta + B(v²) R_xx ] tau²
    A = 8P/3 + (2/3)(Q − 2S),    B = 8P + 4(Q − 2S)

Истинное отношение **меняет знак** около `v² ≈ 0.5`; полагаемое росло

обращается в нуль: там интервал мерит чистую `R_etaeta`, без подгонки.

Отсюда главный вывод о вырождении, с которым я бился весь день:
**оно было в значительной мере артефактом неверной модели.** Отношение
`g_2/g_1 = v²` — свойство допущения, а не геометрии.

## Что это значит для прежних записей

Все компонентные результаты проекта получены старым планом и означают
не то, что написано: «`R_etaeta`» в них — смесь компонент. Пересмотра
требуют раздел про разведение компонент и записанные
`R_xx = +0.00169 ± 0.00044`, `R_etaeta = +0.00228 ± 0.00042`. Устоять
должны отношения и нули (закон дефицита −1.062 ± 0.060, нулевые
контроли), потому что они не опираются на разложение по компонентам.
`X_3` требует СВОЕГО вывода: у него трёхточечные моменты, профили
другие.

## Пойманные ошибки

1. **Валидация на плече, слепом к ошибке.** Линейное семейство имеет
   `a'' = 0`, поэтому не различает верную модель от неверной (6% при
   калибровочной погрешности 14%). Правило: **проверять модель на
   плече, где её предсказание ТОЧНЫЙ НУЛЬ** — у `exp` это
   `R_etaeta = 0`, и там промах вышел 9.5 сигмы вместо незаметных 6%.
2. **Потерянная корреляция порядка.** В первом варианте вывода я счёл,
   что первый порядок уходит целиком по симметрии, и упустил
   `<delta_x delta_y>` по упорядоченным парам: каждый сомножитель в
   среднем нуль, а произведение нет, потому что порядок коррелирует
   положения. Из-за этого вывод не сходился.
3. **Бракованный контроль.** Два «независимых определения» `lambda`
   независимыми не были: второе я получил подстановкой первого, и их
   «совпадение» ничего не проверяло. Признак: контроль, который нельзя
   провалить, — не контроль.
4. **Три недели статистики по направлению, где она не нужна.** Хорошее
   направление упёрлось в систематику калибровки, а калибровка была
   замерена вместо вывода. Вывод дал на тех же данных втрое по `R_etaeta`
   и в 120 раз по обусловленности — больше, чем дал бы семикратный
   набор.
