# Симулятор вселенной: один прогон — паспорт мира

Дата: 13 октября 2026. Код: `code/universe.py`. Паспорта: `docs/runs/*.md`, данные:
`data/universe/*.json`.

## Зачем

Раньше на каждый вопрос писался свой скрипт и строился свой мир. Теперь мир строится
один раз, а потом по нему проходят все модули замеров и выдают паспорт: значение,
ошибка, эталон, отклонение в σ и комментарий. Новый замер — новая функция в списке
`MODULES`. Новый мир — новая строка в `PRESETS`.

## Как запускать

    python3 code/universe.py gold-flat                    # один мир, паспорт
    python3 code/universe.py gold-flat 3                  # зерно 3 (другой кусок кристалла)
    python3 code/universe.py gold-flat --vs poisson-flat  # два мира рядом, две колонки
    python3 code/universe.py gold-ds --quick              # быстро (меньше ромбов)

Миры 1+1 с плотностью 4 считаются за 1–6 секунд.

## Пресеты

| имя | мир |
|---|---|
| `gold-flat` | золотой кристалл 1+1, плоский срез, «раньше» по срезу |
| `poisson-flat` | засев Пуассона 1+1 |
| `gold-trace` | золотой кристалл, «раньше» по полному следу (с тенью) |
| `poisson-trace` | засев + случайное место в окне, «раньше» по следу |
| `gold-ds` | изогнутый срез: де Ситтер 1+1, ℓ = 12 |
| `poisson-ds` | засев на том же де Ситтере |
| `gold-twist` | плоский кристалл + геометрия закрученного среза (κ = 0.05) |

## Модули

| модуль | что меряет |
|---|---|
| густота | событий на собственный объём против заказанной |
| размерность | размерность Майрхейма–Мейера по порядку на трёх масштабах |
| ромбы и бусты | счёт в ромбе на 40 событий при бустах до η = 1.5: среднее, разброс, отношение к засеву, пустые ромбы |
| гипероднородность | рост дисперсии счёта с объёмом, Var ∝ V^α |
| связи | непосредственных связей на событие |
| часы | длина самой длинной цепочки / √(ρV) (у засева → 2) и её зависимость от скорости |
| дно интервала | наименьший τ² среди связанных пар |
| окно и намотка | шаг длинной цепочки по окну и связь намотки её половин (заряд) |
| кривизна | для де Ситтера: счёт в ромбах против точной площади |
| калибровочное поле | для закрученного среза: поле F и кривизна R |

**Кристалл против засева, плоский мир:**

| величина | кристалл | засев |

| шум ромба / шум засева | **0.29** | 1.11 |

| гипероднородность α | **0.50** | 1.04 |

**Де Ситтер (ℓ = 12), счёт в ромбе против точной площади, два зерна:**

| 4 | −0.0046 | −0.0025 / −0.0042 | +0.0034 / −0.0030 |

## Что надо помнить

* **Ошибки одного мира занижены.** Ромбы перекрываются и берут одни и те же события.
  Например, у засева отношение дисперсии к среднему от мира к миру гуляет 0.89–1.11.
  Для окончательных чисел нужны несколько зёрен (сдвигов фазона). Следующее улучшение:
  ключ `--worlds K` с честной ошибкой по мирам.
* Эталоны — либо теория (размерность 2, точная площадь dS, −2κ²), либо засев.
  Константа «часов» 2 достигается только при N → ∞, поэтому сравнивать надо с засевом
  того же размера.
* Пока только 1+1. Чёрная дыра 3+1 (`blackcut.py`) и орбиты 2+1 (`bentorbit.py`) — свои
  скрипты, считаются минутами и часами. Их стоит подключить как «тяжёлые» модули.
* Первая версия засева в ромбе давала половинную густоту (ошибка области); поймано
  по модулю густоты и исправлено.

## Живой прогон: обсерватория чёрной дыры (`code/livehole.py`, 13 окт., 16:39–17:26)

Мир строится слоями по времени (Δt = 1.5M), после каждого слоя пишется кадр
`data/live/<имя>/frame_NNNN.json`, в конце — `orbit.json`. Кадры заливаются в базу
страницы «Обсерватория винтовой дыры» (артефакт с `db`), и она показывает их по мере
счёта: вид сверху на плоскость (события, свет трёх вспышек, орбиты, сферы 3M/6M/8M),
окраска по месту в окне или по часам, тень (x′, y′) с поворотом ωt, графики густоты,
часов и освещённости. Заливка: `livepush.py ИМЯ` (список кадров), `livemark.py ИМЯ N`.

Прогон `hole1`: 2+1, M = 1, винтовой срез ω = 0.12, плотность 10, r от 2.8M до 14M,
t до 150M; 885 648 событий, 100 кадров, 47 минут, связей на событие 6.8.

* **Густота** по радиусу ровная за весь прогон: 0.999–1.001, кроме внутреннего кольца
  2.8–4.2M (0.986 ± 0.003) — край у дыры.
* **Свет**: половина слоя освещена вспышкой у r = 6 к t ≈ 22M, у r = 11 к 26M, у
  фотонной сферы r = 3 к 28M — свет оттуда выбирается медленнее всего. К концу каждая
  вспышка освещает 98.5 % слоя.
* **Часы** (самая длинная цепочка от начала мира, делённая на t): в начале у дыры
  заметно медленнее (1.71 у 3.5M против 2.25 у 13M при t ≈ 8). К концу профиль почти
  ровный (2.61–2.68): самые длинные цепочки к поздним событиям приходят издалека, где
  часы идут быстрее, и падают к дыре в самом конце. Пунктир √(1−2M/r) — только
  ориентир для неподвижных часов.
* **Орбиты** из r = 8 за полоборота (одиночные цепочки, не трубки): радиус в середине
  дуги 6.26 / 7.14 / 7.14 при времени 0.85 / 1.00 / 1.15 от кеплеровского. Видны и
  сдвиг внутрь, и залипание двух цепочек в одной колее, как в `bentcut-doc`.
