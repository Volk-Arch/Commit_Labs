# Меняем связь «дрожь → Λ»: одна Λ на весь прошлый конус

Дата: 12 октября 2026. Код: `code/frozen.py`.

## Что меняем

Модель 1 Соркина: Λ(t) — бегущее среднее дрожи по прошлому конусу момента t.
Отсюда Λ ~ H² во все эпохи, и CMB против (`cosmo-doc`). Монетка, родословная,
подстановка и хаос эту беду не лечат: она в самой связи.

Новая связь (блочное прочтение). У нас мир задан целиком («событие есть ⟺ тень
в шаре»), роста нет. Λ — одно число на весь прошлый конус наблюдателя:

    Λ·V_набл = 8πα·ξ·√V_набл,      ξ ~ N(0,1)

Внутри конуса Λ постоянна (w = −1), а величина ~1/√V_набл ~ H0². Это, по сути,
исходная оценка Соркина (Λ ~ 1/√V «до сих пор»), прочитанная буквально, без
бегущего среднего. Она ложится на унимодулярную гравитацию: там Λ сопряжена
4-объёму, а 4-объём играет роль времени. Λ при этом — константа движения,
разброс которой задан тем, сколько «времени-объёма» прошло.

Самосогласование: V_набл зависит от Λ. Решаем Λ = 8παξ/√V(Λ). Наблюдатель
находится при a = 1 (фотоны остыли до 2.7 K). Физическая плотность вещества
фиксирована, ω_m = 0.142 (по CMB). Свободен один α; ξ — «зерно мира».

| 0.020 | 2.4 % | 4.7 % | 11 % | 1.22–1.51 |
| 0.025 | 2.6 % | 5.2 % | 14 % | 0.98–1.21 |
| 0.030 | 2.6 % | 5.3 % | 15 % | 0.82–1.01 |
| 0.035 | 2.5 % | 5.0 % | 14 % | 0.70–0.86 |

Для сравнения, с теми же условиями: модель 1 (монетка на шаг) — 0 из 3000;
уровни — 0.07 %; родословная — до 0.3 %. Здесь ~5 %, при одном параметре
вместо двух (Ω_m не подбирается).

* **CMB:** Λ постоянна, поэтому Ω_Λ при z = 1100 порядка 10⁻⁹. Проблема
  рекомбинации исчезает сама.
* **Величина:** α ≈ 0.02–0.04, того же порядка, что в модели 1. Наш мир —
  флуктуация ξ ≈ 1, то есть обычная, одна сигма.
* У хороших миров Ω_Λ = 0.63–0.70 и H0 = 62–69 (при фиксированном ω_m).

## Цена

* **Λ относительна наблюдателю.** Наблюдатель в эпоху рекомбинации со своим
  прошлым конусом получил бы свою Λ ~ H_rec². В одном классическом блоке это
  противоречие. Снимается квантово, как в унимодулярной картине: Λ и
  объём-время сопряжены, а история с постоянной Λ — ветвь, заданная тем,
  сколько объёма в прошлом. Это интерпретационный шаг, не выведенный из
  кристалла.
* **«Почему сейчас»** решается так: любой наблюдатель видит Ω_Λ ~ O(1), но не
  на всей своей истории.

## Предсказание

w = −1 точно, Λ не эволюционирует. Если намёк DESI на эволюцию тёмной энергии
(w0 > −1, wa < 0) подтвердится, связь отвергнута. Модель 1, наоборот,
эволюцию допускает, но не проходит CMB.

Не проверено: BAO, полный CMB (кроме тривиального Ω_Λ(рек) ≈ 0).
Распределение ξ гауссово по допущению; у кристалла с размытым краем и у хаоса
(`chaos-doc`) оно гауссово по замеру.

## Дополнение: BAO (DESI DR2, 13 точек, полная ковариация; код `code/frozenbao.py`)

Ранняя вселенная здесь стандартная, поэтому r_d = 147.5 Мпк (ω_m = 0.142, ω_b = 0.0222).

* ΛCDM с тем же ω_m: лучший χ²_BAO = 10.5 на 13 точек (H0 = 68.7, Ω_m = 0.301);
  совместно с SN: 10.6 + 1405.7 (по SN на 2.8 хуже его собственного минимума — известное
  расхождение Ω_m между DESI и Pantheon+).
* Одна Λ на конус: Δχ²_BAO < 4 у ~1 % миров, Δχ²(BAO+SN) < 4 у 0.7–0.9 % (α = 0.02–0.04);
  у α = 0.03 хорошие миры — ξ = 0.98–1.01.

BAO точнее сверхновых, окно по Ω_Λ уже (±0.01), поэтому доля меньше; это не изъян, а
точность данных. Внутри окна модель — это ΛCDM, и подходит так же. Наследует и слабость
ΛCDM: намёк DESI+CMB+SN на эволюцию тёмной энергии (w0wa, 2.8–4.2σ) она объяснить не может.

## Дополнение: w = −1 против меняющейся тёмной энергии (`code/w0wa.py`)

Pantheon+ + DESI DR2 BAO + сжатый реликт (100θ* = 1.04110 ± 0.00031, ω_m = 0.1430 ± 0.0011):

* ΛCDM (наше w = −1): χ² = 1421.8 (h = 0.682, Ω_m = 0.303);
* w0wa: χ² = 1413.6 при w0 = −0.85, wa = −0.54;
* Δχ² = 8.2 за 2 параметра ⇒ p = 0.017, **≈ 2.4σ** в пользу меняющейся.

Совпадает с DESI (2.8σ для DESI+CMB+Pantheon+). Предсказание живо, но под умеренным
давлением. С другими каталогами сверхновых (DES-Y5, Union3) DESI получает 3.8–4.2σ. Если
перевес дойдёт до 5σ, связь «одна Λ на конус» отвергнута.
