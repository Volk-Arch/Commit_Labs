# Компоненты Риччи порознь: два семейства с тождественным нулём

8 октября 2026, после полудня. Запуск: `python3 code/expfam.py --fam exp`
и `--fam root` (набор кусками), `python3 code/comp.py` (подгонка),
`python3 code/compctl.py` (контроль конвейера).

## Задача, которая не лечилась статистикой

Компоненты `R_ηη` и `R_xx` порознь не разводились. Причина — не шум, а
план: его столбцы связаны **тождеством**

    g₁ − g₂ = √C₁ · [1/(1−v²) − v²/(1−v²)] = √C₁

Число обусловленности 3.7·10⁸, и отношение `R_xx/R_ηη` у линейного
семейства выходило **−0.299 ± 0.247 против истины +1/3**, то есть с
НЕВЕРНЫМ ЗНАКОМ. Вчетверо больший набор это не исправил (ошибка №2 из
`pencil-doc.md`): вырождение плана статистикой не лечится.

## Решение: искать семейства, где компонента ЗАНУЛЯЕТСЯ

Для конформно-плоской метрики `ds² = a²(−dη² + dx²)`, при `u = a″/a` и
`v = a′²/a²`:

    R_ηη = 3(v − u),    R_xx = u + v,    отношение = (u+v)/(3(v−u))

Оба наших семейства давали одинаковый по модулю рычаг: линейное `u = 0`
даёт ровно `+1/3`, квадратичное `v = 0` в центре даёт ровно `−1/3`.
Поэтому нужны семейства, где одна компонента равна нулю **тождественно**,
и условия решаются точно:

| условие | решение | что зануляется |
|---|---|---|
| `u = v`, то есть `a″a = a′²` | **`a = e^{kη}`** | `R_ηη ≡ 0`, `R_xx = 2k²` |
| `u = −v`, то есть `(a²)″ = 0` | **`a = √(1 + c(η−η₀))`** | `R_xx ≡ 0`, `R_ηη = 3c²/2` |

**Сверено символьно от метрики** (символы Кристоффеля → Риманa → Риччи),
расхождение ровно 0, включая общие формулы проекта. У корневого
семейства вдобавок `R = −3c²/2` — **отрицательный** скаляр, чего не было
ни у одного прежнего.

## Почему это ломает вырождение ПО ПОСТРОЕНИЮ

Отклик `R_uu = [R_ηη + R_xx v²] / (a²(1−v²))`, значит:

| семейство | форма отклика | при `v = 0` |
|---|---|---|
| экспонента | `∝ v²/(1−v²)` | **нуль** |
| корень | `∝ 1/(1−v²)` | **максимум** |

Формы противоположны, и у каждого плеча остаётся ОДИН параметр — внутри
плеча вырождаться нечему. Это не подбор и не регуляризация.

## Результат

Параметры: `k = 0.03` (экспонента, `R_xx = 0.0018`) и `c = 0.035`
(корень, `R_ηη = 0.00184`); оба внутри окна первого порядка
(`T²R_uu ≤ 0.66` на внешней полосе). Набор 90 и 60 миров кусками.

| | из счёта | истина | σ |
|---|---|---|---|
| `R_xx` из экспоненты, `X₂` | **+0.00169 ± 0.00044** | +0.00180 | **0.2** |
| `R_xx` из экспоненты, `X₃` | +0.00168 ± 0.00045 | +0.00180 | 0.3 |
| `R_ηη` из корня, `X₂` | **+0.00228 ± 0.00042** | +0.00184 | **1.1** |
| `R_ηη` из корня, `X₃` | +0.00217 ± 0.00039 | +0.00184 | 0.8 |
| отношение `R_xx/R_ηη` из ДВУХ плеч | **+0.742 ± 0.155** | +0.980 | 1.5 |

**Обе компоненты тензора Риччи измерены независимо, каждая по 25 %, и
отношение из двух разных плеч имеет верный знак.** Было: −0.299 ± 0.247
против +1/3.

Отдельная проверка экспоненты без всякой подгонки (парное вычитание
помехи, предсказание из символьно выведенного `R_xx` и калибровки `v₂`
из ДРУГОГО прогона): `χ²` = 4.2 на шесть полос без свободных числе,
амплитуда против предсказания **0.89 ± 0.31**, то есть 0.3 σ.

## Контроль конвейера, без которого числа силы не имеют

Половина плоского плеча объявляется семейством (деление ПО МИPАМ, не по
строкам), и параметр обязан выйти нулём:

| что объявлено | `X₂` | `X₃` |
|---|---|---|
| половина плоского как «экспонента» | +0.00014 ± 0.00061 (**0.2 σ**) | +0.00050 ± 0.00072 (0.7 σ) |
| половина плоского как «корень» | +0.00027 ± 0.00047 (0.6 σ) | +0.00040 ± 0.00055 (0.7 σ) |

Все четыре строки ниже 1 σ. Конвейер чист.

## Что это даёт

Разницу между «проверить одно уравнение» и «проверить уравнение поля».
Светоподобная свёртка `R_μν k^μk^ν` измеряется хорошо (11 %) именно
потому, что в ней след ВЫПАДАЕТ (`g_μν k^μk^ν = 0`) — это левая часть
ВАКУУМНОГО уравнения. Полное уравнение есть `R_μν − (R/2)g_μν`, и чтобы
выйти за вакуум, нужен след ОТДЕЛЬНО от направленной части. Теперь он
есть:

- полный тензор Риччи в конформно-плоском классе — из счёта;
- уравнения Фридмана как ДВА независимых уравнения, а не одна
  комбинация (положительный контроль `frw.py` проверял только `R_uu`);
- условия энергии помимо светоподобного — слабое и сильное требуют и
  направленной части, и следа.

## Чего это НЕ даёт

Линейное и квадратичное плечи остались плохи (2.1…2.7 σ, у линейного
`R_xx` с неверным знаком): внутри них вырождение `α`/`β` никуда не
делось, обусловленность полного плана по-прежнему 1.9·10⁸. Но они больше
и не нужны для замера — становятся **проверками**. Замер идёт по двум
выделенным плечам, где каждое даёт одну компоненту и ничего не
смешивает.

## Пойманные ошибки

1. **Повторил свою же ошибку №3.** Сначала вычитал помеху ПОЯЧЕЕЧНО, и
   `R_ηη` линейного уехал на 3.0 σ вверх (с гладкой помехой — 1.1).
   Средние ячеек плоского сами шумны (±0.002…0.004) и сравнимы с
   сигналом в полосах МАЛОГО наклона, а именно они определяют `α`.
   Признак был прямо в данных: экспонента при поячеечном дала 0.00088,
   при гладком 0.00194.
2. **Заплата без счётчика вставилась в ДВА места.** `s.replace("if fam
   == 'exp':", ...)` без `count=1` вставило ветку и в `a_of`, и в
   `truth`, и `truth` стала возвращать `np.sqrt` от неопределённого `e`.
   Прогоны упали сразу (ошибка №32).
3. **`pkill -f <образец>` убивает собственный шелл**, если образец есть
   в своей же команде. Случилось ДВАЖДЕ за день. Искать процессы
   текстовым образцом из той же строки нельзя (ошибка №33).
