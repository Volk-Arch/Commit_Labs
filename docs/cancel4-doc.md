# Пункт 4: погашение разреженного сектора — форма верна, коэффициент мал

## Что проверялось

Самое опасное место для архитектуры 8 октября. Критерий гласил:
погашение убивает сектора, чьё действие аффинно по немногим
целочисленным счётчикам. Разреженный слоистый сектор побивает
многообразный ПО СЧЁТУ с `N ~ 1700`, а гасится ли он — не мерено ни
разу. Архитектура обязывала его гаситься.

Мерить надо аналитически: 8 октября установлено, что выборочное среднее
оценивает `<exp(i S/hbar)>` с ошибкой `1/sqrt(n)`, поэтому подавление
ниже этого пола невидимо для сэмплирования ни при каком терпении.

## Как сумма взята точно

Сектор — три слоя; отношения 1-2 и 2-3 произвольны (матрицы `M12`,
`M23`), а 1-3 определяются замыканием. Отношения между СОСЕДНИМИ слоями
имеют пустой интервал (между ними нет элементов), поэтому каждое даёт
вклад `w(0) = -1`; отношения 1-3 имеют `n_ik = |s_i ∩ T_k|` элементов
между, где `s_i` — носитель строки `M12`, `T_k` — носитель столбца
`M23`. Отсюда

    S/k_4 = n - (|M12| + |M23|) + sum_{(i,k): n_ik >= 1} w(n_ik)
    w(1) = 9,  w(2) = -16,  w(3) = 8,  w(m >= 4) = 0

**Ключ:** при фиксированном `M12` сумма по `M23` распадается в
ПРОИЗВЕДЕНИЕ по столбцам, потому что столбцы независимы, а зависимость
действия от столбца идёт только через `T_k`:

    Z = sum_{M12} exp(i k_4 (n - |M12|)/hbar) * G(M12)^{a_3}
    G(M12) = sum_{T} exp(i k_4 (-|T| + sum_i w(|s_i ∩ T|))/hbar)

Третий слой входит ТОЛЬКО показателем, поэтому подавление на его элемент
равно точно `q = |G|/2^{a_2}`, при любом размере слоя.

**КОНТРОЛЬ**: факторизация против прямого перечисления всех `M12, M23`
на трёх конфигурациях — совпадение до `1e-14`.

## Результат

| | |
|---|---|
| форма подавления | `e^{-s a_2 a_3}`, то есть **квадратично по `N`** |
| `max q` при `hbar = 0.55`, `a_2` = 2…7 | 0.957, 0.907, 0.864, 0.798, 0.696, 0.569 |
| лучшее нерезонансное `s = -ln(max q)/a_2` | **0.0717** при `hbar = 0.56` |
| нужно для гибели (`ln 2`) | **0.6931** |
| не хватает множителя | **9.7** |
| но `s` растёт с `a_2`, наклон | +0.0053, до `ln 2` при `a_2 ~ 121` |

**Форма подтвердилась**, и это не было предрешено: подавление могло
выйти линейным по `N`, и тогда маршрут закрылся бы сразу. Оно
квадратично — того же порядка, что преимущество сектора по счёту.

**Коэффициент на доступных размерах в десять раз мал.** Сектор гибнет
только если `s >= ln 2 = 0.693` (его счёт растёт как
`2^{a_2 a_3} = e^{0.693 a_2 a_3}`), а наблюдается 0.0717.

**Спасает рост `s` с размером слоя.** Линейная экстраполяция дотягивает
до порога при `a_2 ~ 121`, тогда как преимущество по счёту начинает
играть при `a_2 ~ 570`. По экстраполяции сектор гибнет задолго до того,
как успевает победить.

**Но это экстраполяция в пятнадцать раз** от данных при `a_2 <= 8`, и
результатом её называть нельзя. Вдобавок `s` в данных немонотонно
(0.0895, 0.0526, 0.0695, 0.0717, 0.0863, 0.1060), так что линейная
подгонка груба.

## Итог

Единственный живой маршрут отбора **не закрыт и не подтверждён**. У него
теперь есть конкретная проверяемая цель: дотянуть `s(a_2)` до больших
`a_2`. Способ понятен — найти максимизирующую `M12` СТРУКТУРНО, а не
перебором, и тогда `a_2` перестанет ограничиваться `2^{a_1 a_2}`
конфигурациями.

## Пойманная ошибка

**Резонансы приняты за выживание.** Первый прогон выдал «ВЫЖИВАЕТ,
архитектура неверна» при `hbar` = 0.39 и 0.78 — и это артефакт: там
`k_4/hbar` близко к `4pi/3` и `2pi/3`, целочисленная фаза принимает
всего ТРИ значения, и часть конфигураций выравнивается. Хуже: 0.39 и
0.78 — края прежнего окна, которое выводилось из `|2cos(k_d/2 hbar)|`,
то есть края по построению И ЕСТЬ резонансы знаменателя. Правило: при
целочисленной фазе помечать `hbar`, у которых `k/hbar` кратно `2pi/m`
для малого `m`, и выводы на них не строить.
