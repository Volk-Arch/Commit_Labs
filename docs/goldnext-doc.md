# Квазикристалл: своё действие и приливная кривизна

Дата: 11 октября 2026, вечер. Код: `code/goldnext.py`. Продолжение
`gold3-doc.md`.

## 1. Размазанное действие гасит отпечаток

Размазанное БД (прореживание с плотностью ε, `smear-doc`) берёт все
размеры интервалов с гладкими весами. Плоский ромб, N≈2000, 4 положения
ромба против 6 засевов:

| ε | квазикристалл | засев | отличие |
|---|---|---|---|
| 1 (резкое) | −5.63 ± 6.10 | −1.16 ± 2.24 | −2.0σ |
| 0.5 | −5.24 ± 0.83 | +0.12 ± 0.38 | −14σ |
| 0.2 | −1.09 ± 0.09 | +0.22 ± 0.10 | −14σ |
| **0.1** | **+0.234 ± 0.019** | +0.305 ± 0.055 | −1.3σ |
| **0.05** | **+0.402 ± 0.032** | +0.384 ± 0.024 | +0.7σ |

При ε ≤ 0.1 квазикристалл неотличим от засева, а при ε = 0.1 его разброс
втрое меньше. Комки малых интервалов усредняются. **Своё действие для
кристалла — размазанное БД с ε ≲ 0.1.**

## Отклик на кривизну: при N≈2000 не виден ни у кого

Фридман с веществом `a = η²` (η от 2 до 3) минус плоский:

| ε | Δ квазикристалл | Δ засев |
|---|---|---|
| 1 | +32.1 ± 2.6 | −0.9 ± 1.0 |
| 0.5 | +0.88 ± 0.22 | −0.22 ± 0.13 |
| 0.2 | +0.18 ± 0.05 | −0.01 ± 0.04 |
| 0.1 | −0.010 ± 0.014 | +0.015 ± 0.018 |
| 0.05 | +0.008 ± 0.006 | +0.009 ± 0.009 |

При ε ≥ 0.2 у квазикристалла **ложный** отклик: комки взаимодействуют
с градиентом плотности. При ε ≤ 0.1 оба отклика совместимы с нулём и
между собой. Кривизна при таком N слишком мала для этого прибора. Вывод
только один: размазанное действие у квазикристалла ведёт себя как у
засева и в плоском, и в кривом случае. **Что оно видит кривизну — не
проверено.**

## 2. Форма тени приливов не даёт

Эллипсоид вместо шара (вытянут вдвое по времени тени или по оси x тени),
та же плотность. Счёт в ромбе объёма 30 при η = 0 и 3 по осям x, y и
случайному направлению: везде 28–31 ± 3–8, ни одной аномалии. Форма тени
на счёт не влияет, выделенной системы не видно.

И по теореме приливов не будет: причинный порядок задаёт конформную
геометрию (Малament; Хокинг–Кинг–Маккарти), а здесь «раньше» считается
по одному глобальному плоскому конусу при любой тени. Тень меняет
только **какие** события есть, то есть плотность — конформный множитель.
Кривизна Вейля (волны, поле снаружи звезды) требует, чтобы менялись
**сами конусы**: квадратичная форма должна зависеть от места, а «раньше»
между далёкими событиями — получаться замыканием местных отношений.
