# Монетка из хаоса по родословной

Дата: 12 октября 2026. Код: `code/catcoin.py`; массивы: `data/catcoin_*.npy`.

## Модель

Дерево событий по золотому правилу a→acd, b→cd, c→abc, d→ab (рост τ² за
поколение). У события есть скрытая фаза θ на торе. Ребёнок номер j получает
T(θ + j·ω), где ω = (1/τ, 1/τ²) и T — «кошка Арнольда»
(x, y) → (2x + y + p, x + y + p), p = ε/2π·sin 2πx (её числа τ², 1/τ²).
Монетка события равна [θ₁ < 1/2]. Случайности нет: всё определяет фаза
корня. Для каждого поколения считаем e_k = отклонение/√(n_k/4).
Прогон: 200 корней, 13 поколений.

## Результат

| вариант | var(e_k) ~ V^… (0 ⇔ h = 1/2) | корреляция соседних поколений | эксцесс |
|---|---|---|---|
| настоящая монетка | −0.02 | +0.05 | 2.80 |
| линейная кошка (ε = 0) | **+0.99** | 0.00 | 1.93 |
| ε = 0.02 | +0.01 | −0.02 | 2.84 |
| ε = 0.1 | +0.01 | −0.03 | 2.94 |
| ε = 0.3 | −0.01 | −0.03 | 2.82 |
| ε = 0.6 | 0.00 | 0.00 | 3.29 |
| поворот без хаоса | +0.84 | +0.99 | 1.57 |

* **При любой нелинейности (уже ε = 0.02) получается в точности монетка
  Соркина:** h = 1/2, распределение гауссово, памяти между поколениями нет.
  Амплитуда в 1–3 раза меньше, но её поглощает α. Значит, случайность не
  нужна: её заменяет детерминированный золотой хаос.
* **Линейная кошка даёт h ≈ 1:** отклонение пропорционально числу событий,
  то есть Λ ~ const. Фазы поколения линейны по фазе корня, и все монетки
  сдвигаются вместе. Величина Λ при этом порядка единицы в планковских
  единицах — старая проблема 120 порядков.
* Промежуточного режима (h ≈ 0.6 или память, как у родословной) нет.
  Переход резкий: даже малая нелинейность за несколько поколений
  раздувается в полную.

## Космология

Нелинейный хаос статистически совпадает с монетками по уровням при q = 0.
Поэтому для него в силе результаты `cosmo-doc`: по сверхновым подходит
~0.07 % миров, а Ω_Λ при рекомбинации 0.2. Хаос убирает монетку, но новой
физики не добавляет.

## Две крайности

* нелинейный хаос: Λ ~ H². Величина объяснена, CMB против;
* линейный: Λ = const. CMB доволен, величина не объяснена.

Нужное лежит между ними: Λ почти постоянна в поздние эпохи, а её величина
~1/√V_сегодня. Ни монетка, ни родословная, ни подстановка, ни хаос этого
пока не дают.
