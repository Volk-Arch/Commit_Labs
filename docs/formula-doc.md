# Основная формула: что осталось от «раньше по всем шкалам»

Дата: 11 октября 2026, вечер. Сводка по записям, новых замеров нет.
Источники: `PICTURE.md` §1, §2, §5д, §5е; `majority-doc`, `monotone-doc`,
`correlated-scales-doc`, `input-memory-doc`, `gps-doc`, `cone21-doc`,
`gpsrule-doc`, `lattice-doc`, `gold4-doc`, `gold3-doc`.

## Что было записано (по порядку)

1. **Правило проекта** (`PICTURE` §1): событие несёт `k` чисел, A раньше B,
   если раньше по всем.
2. **Единогласие вынуждено** (`majority-doc`, `monotone-doc`): «m из k»
   даёт циклы, начиная с `N_крит`; из всех монотонных правил на битах
   «раньше на шкале» транзитивно только единогласие. Оговорка теоремы:
   доступны **только биты**, потому что правило симметрично к
   перешкалированию каждой шкалы.
3. **Шкалы должны быть видами одной точки** (`correlated-scales-doc`):
   при `sᵤ = t − u·x` то же правило даёт Минковского; `k` — разрешение,
   а не размерность.
4. **Числа читаются из самого порядка** (`PICTURE` §2, `gps-doc`):
   собственные времена до опор — «входа нет», петля «порядок → числа →
   порядок» замкнута.
5. **Но монотонная петля вырождается** (`PICTURE` §5д): неподвижная точка —
   цепь. Длины цепей растут только вперёд, а конусу нужны шкалы, меняющие
   знак по направлениям.
6. **Двух чисел хватает на конформную часть** (`input-memory-doc`): порядок
   помнит `t` и `|x|`; масштаб даёт счёт событий.
7. Сегодня: монотонному правилу нужно `~N^{(d−2)/2}` шкал (`cone21`); те
   же 5 чисел при **квадратичном** сравнении дают Минковского
   (`gpsrule`); золотые числа дают мир без случайности (`lattice`,
   `gold4`); рост в целых числах, порядок рождения не важен (`gold3`).

## Формула

Все пункты укладываются в одну строку:

    A раньше B   ⟺   B − A ∈ C

`C` — **конус положительных разностей**: если `d₁, d₂ ∈ C`, то
`d₁ + d₂ ∈ C`. Из этого одного свойства **транзитивность следует сама**:
`C − A = (C − B) + (B − A)`. Антисимметрия — из того, что `C` не содержит
противоположных направлений.

Что объясняется этой строкой:

| запись | в языке конуса |
|---|---|
| единогласие по `k` шкалам | `C` = ортант: «все координаты разности положительны» |
| большинство «m из k» даёт циклы | множество «m из k положительны» **не замкнуто по сложению**: две разности из него в сумме выходят наружу; при малом `N` такие суммы не реализуются, отсюда `N_крит` |
| теорема о монотонных правилах | если видны только знаки по шкалам, замкнутые по сложению конусы — только грани ортанта |
| шкалы `t − u·x` | гранёный конус: пересечение `k` полупространств |
| Минковский | **круглый** конус `Δt > |Δx|`: пересечение бесконечного числа полупространств, или одно квадратичное условие |
| 1+1 особая | круглый конус на плоскости имеет ровно две грани, то есть это ортант в световых координатах |
| GPS-правило | тот же круглый конус, разность считается из собственных времён до опор |

## Вторая часть формулы

Строка выше говорит, **кто раньше**. Вторая говорит, **кто есть**:

    мир = { x : x' в шаре }     (x — четвёрка чисел a + bτ, x' — тень)

Для 3+1 в золотых числах обе строки:

    событие x существует  ⟺  0.618·t'² + |x'|² ≤ r²
    x раньше y            ⟺  Δt > 0  и  τΔt² − |Δx|² > 0,   Δ = y − x

Обе бинарные, обе на одну строку; вторая считается в целых числах.

## Чем стали шкалы

Шкалы — это **грани** конуса. Для ортанта их `k`, для гранёного — по числу
граней, для круглого их нет вовсе: вместо перечня граней одна
квадратичная форма. Поэтому записи «шкалы не обязательны» и «единогласие
вынуждено» не противоречат друг другу. Единогласие есть частный случай
«разность в конусе», когда конус — ортант.

И оговорка теоремы о монотонных правилах (доступны только биты) — это
ровно та дверь, через которую выходит круглый конус: квадратичное
условие использует величины, а не только знаки. Его симметрия —
не перешкалирование каждой шкалы, а повороты и бусты.

## В 1+1 золотая решётка — буквально единогласие

`u = a + bτ`, `v = a + bτ'`. «Раньше на обеих шкалах» — и вторая шкала
есть тень первой (то же число с заменой `τ → τ'`). Исходное правило
проекта в точности, только шкалы — **число и его тень**.

## Что из записей прямо указывает на следующий шаг

Петля «порядок → числа → порядок» вырождалась в цепь при **монотонном**
сравнении (`PICTURE` §5д). С **квадратичным** сравнением (GPS) петлю не
запускали ни разу. Если у неё есть неподвижная точка, похожая на
Минковского, это и есть «порядок, порождающий сам себя».
