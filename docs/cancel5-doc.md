# Пересчёт пункта 4: действие было неверно, и сектор НЕ гибнет

Отменяет числа `cancel4-doc.md` целиком и ослабляет утверждение
`phase-doc.md` о гибели плотных слоистых. Вечерняя архитектура
8 октября этим **опровергнута**.

## Пойманная ошибка: контроль, который нельзя провалить

Вчерашняя фаза столбца считалась как

    ph(T) = -|T| + sum_i w(|s_i ∩ T|),   w(0) = -1

и проверялась «факторизация против прямого перечисления» — совпадение
до `1e-14`. Но перечисление считало по ТОЙ ЖЕ формуле. Общая ошибка
формулы такой проверкой не ловится.

`bdcontrol.py` считает действие Бенинказы–Доукера **от самого порядка**:
строит матрицу отношений, для каждой СВЯЗАННОЙ пары берёт
`|I(x,y)| = #{z: x<z<y}`, собирает `N_0..N_3`.

| | |
|---|---|
| конфигураций проверено | 240 |
| формула с `w(0) = -1` расходится с порядком | **203** |
| формула с `w(0) = 0` расходится | **0** |

Вес `-1` начислялся парам (слой1, слой3) с пустым пересечением — то есть
**несвязанным** парам, которых в сумме по связанным парам нет вовсе.
Сдвиг не постоянный, а зависит от конфигурации, поэтому гасил не то.

## С верным действием сумма берётся в замкнутом виде

Ключ: `w(m) = 0` при `m >= 4`, поэтому `phi(m) = e^{i th w(m)}`
отличается от единицы только при `m = 1,2,3`. Раскрытие
`prod_i phi(m_i) = sum_{S} prod_{i in S} psi(m_i)` оставляет в каждом
члене лишь КОНЕЧНЫЙ перебор малых пересечений, а остальные классы
второго слоя суммируются по Вандермонду. Перебор `2^{a1 a2}` матриц
больше не нужен — отсюда и `a_2` в сотнях вместо семи.

Для структуры «второй слой разбит на блоки по `m`, каждый блок
обслуживают `d` строк» сумма ТОЧНО факторизуется по блокам:

    G = g_d(m)^{a_2/m},
    g_d(m) = sum_{t=0..m} C(m,t) u^t phi(t)^d
           = (1+u)^m + sum_{t=1..3} C(m,t) u^t (phi(t)^d - 1),  u = e^{-i th}

**Контроли (все прошли):**

| контроль | результат |
|---|---|
| замкнутая форма против суммы по `2^{a_2}` | 2e-12 |
| полное `Z` против перечисления ВСЕХ порядков (действие от матрицы) | 3e-15 |
| `Z` по классам против перечисления всех `2^{3a_2}` матриц `M12` | 5e-15 |
| `g_d(m)` против прямой суммы с явными строками | 9e-15 |
| пустая `M12`: `q = |cos(th/2)|^{a_2}` | совпало |
| `hbar -> oo`: `q -> 1` | 0.9986 при 500 |

## Первое следствие: «не хватает 9.7» было артефактом дважды

При `a1 = 2` точное `s(a_2) = -ln(max q)/a_2` теперь берётся до
`a_2 = 300`, и аргмаксимум устойчиво садится на `(0, a_2/2, a_2/2, 0)`
— **две строки делят второй слой на две непересекающиеся половины**.
Асимптотика выводится аналитически и совпадает с точным счётом в
четвёртом знаке:

    s(a_2) = ln 2 - (6 ln(a_2/2) + ln(|psi_3|²/36))/a_2

| `a_2` | 7 | 30 | 80 | 200 | 300 | 10⁴ |
|---|---|---|---|---|---|---|
| `s` точно | 0.081 | 0.274 | 0.458 | 0.571 | 0.603 | — |
| асимптотика | — | — | 0.457 | 0.571 | 0.603 | 0.688 |

Вчера `s` = 0.0717 и «линейный рост +0.0053 до порога при `a_2 ~ 121`».
Оба числа неверны: значение — из-за действия, рост — потому что
**подход логарифмический, а не линейный**. `s` стремится к `ln 2`
СНИЗУ и порога не пересекает никогда. При `a1 = 2` сектор ровно
маргинален, и «множитель 9.7» вырождается в 1.0.

## Главное следствие: форма `a_1` свободна, и на ней сектор выживает

`a_1` — параметр ФОРМЫ, а не константа, и максимум по структурам стоит
не при `a_1 = 2`. Энтропийные члены (число матриц в структурном классе)
дают лишь `O(N ln N)`, поэтому весь вклад порядка `N²` сидит в
`a_3 ln|G|`, а оптимум по форме при `a_1 = (d/m) a_2` берётся
аналитически (`beta* = 1/(2(1+d/m))`, `gamma* = 1/2`):

> **`ln|Z| ~ c N²`, где `c(m,d) = ln|g_d(m)| / (4(m+d))`**

Вердикт сводится к ОДНОМУ неравенству: сектор гибнет тогда и только
тогда, когда `|g_d(m)| <= 1` для всех `m, d`.

**Нижняя оценка законна.** Внутри структурного класса все `M12` дают
одно и то же `|G|`, одно и то же `|M12|` и один и тот же `arg G`
(перестановка метрк второго слоя не меняет `G`), поэтому складываются
КОГЕРЕНТНО. Проверено при `a1 = 3`, `a_2 = 9` против точного `|Z|`:

| `a_3` | 5 | 10 | 20 | 40 |
|---|---|---|---|---|
| `ln|Z|` точно − оценка | 4.42 | 0.43 | 0.81 | 0.15 |

## Результат скана

781 точка по полосе `hbar` ∈ [0.390, 0.780] с шагом 0.0005,
`m, d` до 40 (минимум не сдвигается и при потолке 120):

| | |
|---|---|
| точек, где сектор гибнет (`c <= 0`) | **0 из 781** |
| минимум `c` по всей полосе | 0.0874 при `hbar` = 0.414 — но **это резонанс** (`k₄/ℏ / 2π ≈ 5/8`) |
| **минимум `c` по НЕРЕЗОНАНСНЫМ `hbar`** | **0.1167** при `hbar` = 0.5485, `(m,d)` = (7,1) |
| максимум `c` | 0.1377 при `hbar` = 0.7495, `(m,d)` = (5,1) |
| счёт сектора без подавления | 0.1733 `N²` |

Резонансы помечены по правилу, выведенному 8 октября (`k₄/ℏ` кратно
`2π/m` при малом `m`), и лучшая для архитектуры точка стоит ровно на
резонансе — то есть в месте, где выводы запрещены самим этим правилом.
По нерезонансным `hbar` погашение снимает лишь **треть** показателя:
остаётся 67 % от 0.1733.

Переход против пространства-времени сдвигается ВНИЗ:

| против | было | стало (нерезонансный минимум) |
|---|---|---|
| пола многообразных `2 N lnN` | — | `N ~ 74` |
| счёта по Милнору–Тому `4 N lnN` | `N ~ 1700` | `N ~ 178` |

## Что именно опровергнуто

**Критерий «действие аффинно по немногим целым счётам ⇒ гасится»
неверен как сформулирован.** Фаза столбца этого сектора есть

    th * (-t + 9k_1 - 16k_2 + 8k_3)

где `t = |T|`, а `k_j` — число строк с пересечением ровно `j`. Это
аффинная функция ЧЕТЫРЁХ целых чисел — «немногих» по любому счёту. И
сектор не гибнет. Значит дело не в ЧИСЛЕ счётчиков, а в том,
насколько сосредоточен вес по их значениям; четырёх хватает, чтобы
`|g| > 1`.

**Утверждение `phase-doc.md` «плотные слоистые гасятся точно до
`e^{-cN²}`» верно только для подсемейства**, где все интервалы
слой1-слой3 содержат `>= 4` элемента и действие сводится к
`S = k_4(N - N_0)`, аффинному по ОДНОМУ числу. Выжившие структуры
живут ровно в поправках `w(1), w(2), w(3)`, которые там отброшены.

## Код

`bdcontrol.py` (действие от порядка), `cancelclosed.py` (замкнутая форма
+ контроль против перечисления порядков), `cancelfast.py` (явная формула

функцией, скан), `gcrit2.py` (проверка нижней оценки при `a1=3`, тонкий
скан).

## Оговорки

1. Нижняя оценка опирается на когерентность внутри класса — проверена,
   но против полного `|Z|` только при `a1 <= 3`.
2. Однородное семейство `(m,d)` НЕ исчерпывает структуры: точный
   максимум при `a1 = 3` стоит на покрытии кратности 2 блоками РАЗНЫХ
   размеров по трём парам строк, вне семейства. Для вердикта это
   работает в нужную сторону (истинное `c` ещё больше), но число 0.0874
   — нижняя граница, а не значение.
3. Пол float64 измерен, а не принят: при малых `a_3` сокращение
   достигает `1e14`, и те строки отброшены как шум. Выводы взяты при
   `a_3 >= 20`, где сокращение порядка единицы.
