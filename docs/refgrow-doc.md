# Рост по опорным событиям: шесть пунктов критерия из восьми

**Драйвер:** `code/refgrow.py` · **Повод:** «а что если есть формула,
которая даёт нужное семейство, или собрать самим по нужным параметрам»

---

## Почему все прежние правила промахивались

`step-phase-doc.md` закончился измеренным запретом: все перебранные
семейства предложений имеют по **одной** эффективной степени свободы, а
цель живёт в пяти измерениях (плотность, высота, связи, спектр,
перекрытие прошлых). Диагностика достижимости показала это прямо: `|D|`
и перекрытие `J` лежат на одномерной кривой, а цель — вне неё.

Формула, дающая нужное семейство, известна: конус `s_u = t − u·x`, и у
него ровно четыре параметра на событие. Но ему нужны координаты, а вся
затея с ростом — попытка обойтись без них.

## Конструкция: k порядковых шкал вместо координат

Опорные события `r_1 … r_k`. Для каждого события `b`:

```
    v_i(b) = длина самой длинной цепи от r_i до b     (0, если недостижимо)
```

Новое событие задаётся целью `w ∈ ℤ^k`, и его прошлое есть

```
    D = { b : v(b) ≤ w покомпонентно }
```

**Два свойства достаются бесплатно.**

*Замкнутость вниз.* Если `b' ≺ b`, любая цепь от `r_i` до `b'`
продолжается через `b`, значит `v(b') ≤ v(b)`. Тогда из `v(b) ≤ w`
следует `v(b') ≤ w`. Значит `D` — всегда корректное прошлое, и
**транзитивность цела по построению** (измерено: 0 нарушений везде).

*Коррелированность шкал.* Все `k` чисел выведены из **одного** порядка,
как `s_u = t − u·x` выведены из одного 4-вектора. Именно
коррелированность стоила `+0.04` по спектру при совпадающей плотности, и
именно её не давали ни популярность, ни высота.

> И это буквально исходное правило проекта — «событие несёт k чисел, A
> раньше B если раньше по всем k» — только числа берутся **из порядка**, а
> не задаются извне.

### Что пройдено — перепроверено на 16 засевах

Первые числа считались на 5–6 засевах. Спектру, как выяснилось раньше,
нужно 12–16, поэтому прогон повторён:

  ящик                           -0.0076   0.0017
  конус                          +0.0145   0.0026

| пункт | цель | получено |
|---|---|---|
| нарушений транзитивности | 0 | **0**, по построению |
| доля пар | 0.098, устойчиво | **0.091–0.095**, устойчиво |
| размерность | 4.03, устойчиво | **4.07–4.11**, устойчиво |
| воспроизводимость | с.к.о. ~0.002 | **0.0020 при N=1600** |
| самоусреднение | разброс падает с N | **0.0034 → 0.0020 → 0.0007** |
| перекрытие прошлых | 0.169 | **0.1746 при N=1600** |
| показатель высоты | 0.279 | **0.287** |

⚠ **Пункт «спектр положителен» снят.** На 16 засевах он
`+0.0026 ± 0.0020`, то есть **1.3σ — согласуется с нулём**. Значимо выше
ящика (3.9σ) и значимо ниже конуса (3.6σ): величина **промежуточная**, а
не положительная. Было «шесть из восьми», стало **пять из восьми**.

**Самоусреднение — главное приобретение.** Все прежние правила либо не
самоусреднялись (разброс стоял на 0.02 при любом N), либо были
воспроизводимы и давали спектр уровня перколяции. Здесь разброс падает
быстрее эталонного, то есть это **один мир, а не семейство**.

### Что не пройдено

```
  спектр, величина   +0.002 плоско        конус растёт 0.0069 -> 0.0145 -> 0.0213
  показатель связей  0.949               цель 0.75 (связей 68.4 против 30.9)
  высота, амплитуда  9.2 при N=2400      конус 12.5 (показатель верен, число низко)
```

Спектр положителен и воспроизводим, но **не растёт с размером мира**, а у
конуса он растёт втрое от N=400 до N=1600. При N=1600 расхождение
`+0.0016 ± 0.0017` против `+0.0213 ± 0.0016` — двенадцать сигм.

⚠ Это поправка к моему же критерию: я записал «спектр должен быть
положительным и воспроизводимым», и по этой формулировке конструкция
проходит. Но калиброванные значения эталона (`+0.0145` при N=800,
`+0.0213` при N=1600) она не даёт. Критерий требует **величины**, а не
только знака и устойчивости.

Рычаги проверены и не помогают: `spread` от 0.6 до 1.8 и `jitter` от 0 до
0.35 меняют долю, высоту и связи, но спектр остаётся в
`+0.002 … +0.007` при любом сочетании, то есть на порядок ниже нужного.

### Гипотеза о связи двух промахов

Связей вдвое больше нужного при показателе 0.95 вместо 0.75, то есть
связей приходится постоянная **доля** мира, а не `N^0.75`. Прошлое
задаётся «ящиком» `{v ≤ w}` в пространстве шкал, и его максимальные
элементы — ступенчатая граница этого ящика. Возможно, избыток связей и
подавленный спектр — одно и то же: и то и другое про тонкую структуру
графа сравнимости. Это **гипотеза**, не измерение.

## Физическое объяснение: это GPS-координаты

**Драйвер:** `code/gps.py`

Длиннейшая цепь между событиями засева плотности `ρ` приближает
собственное время, `L ≈ m_d · ρ^(1/d) · τ`. Значит `v_i(b)` — это
**собственное время от опоры `r_i` до `b`**, а набор из `k` таких чисел —
положение события, заданное собственными временами до нескольких
наблюдателей.

Это известная конструкция: реляционные координаты излучения, в ОТО
«GPS observables» (Ровелли), и буквально принцип спутниковой навигации.
В 4d нужно четыре опоры, пятая снимает квадратичную неоднозначность — и
скан нашёл верную долю пар как раз при `k = 5…6`.

> Конструкция оказалась не произвольным правилом, а **реляционными
> координатами, выведенными из самого порядка**.

### Вывод формулы интервала

`R_1` — начало, `e_i = R_i − R_1`, `y = x − R_1`, `z = b − R_1`:

```
  τ_i(x)² = (y − e_i)²  ⟹  y·e_i = (τ_1(x)² + e_i² − τ_i(x)²)/2 ≡ u_i(x)
  y·z = u(x)ᵀ G⁻¹ u(b),      G_ij = e_i·e_j
  (x − b)² = τ_1(x)² + τ_1(b)² − 2 · u(x)ᵀ G⁻¹ u(b)
```

причём `G_ij = (τ(r_1,r_i)² + τ(r_1,r_j)² − τ(r_i,r_j)²)/2` — тоже только
длины цепей. Константа `m_d ρ^(1/d)` сокращается: все члены квадратичны
по интервалу, а нужен лишь знак.

**Это замкнутая формула интервала между любыми двумя событиями через одни
порядковые величины.** Условие `b ≺ x` есть `(x−b)² ≥ 0` плюс
направление времени — настоящий конус, а не ящик.

### Формула верна, оценщик негоден — и только у нас

Проверка на известном засеве: **ни один из 3000 наборов опор не дал
сигнатуру Грама `1+/3−`**, обязательную для четырёх векторов,
покрывающих 4d Минковский. Причина измерена:

```
    tau    пар     <L>  с.к.о.  отн.разброс  отн.разброс L²
   0.30    138     1.6    0.57        0.359           0.719
   0.91    474     5.9    1.01        0.171           0.343
   2.05   1314    14.9    2.28        0.153           0.306
```

Разброс длины цепи 15–36%, у её квадрата 30–72%. А `G` строится из
**разностей сравнимых по величине квадратов**, то есть с сокращением, и
30-процентная ошибка превращается в произвольную.

Разброс падает как `1/√L`, значит для надёжной сигнатуры нужна длина
цепи порядка 600 против наших 15, то есть `N ~ 10¹¹`.

> **Это предел симуляции, а не физики.** В реальной Вселенной плотность
> планковская, и для одной секунды `L ~ 10⁴³`. GPS-восстановление там
> превосходно; непригодно оно только на наших числах. Различать эти два
> вида провала обязательно.

### Что вывод всё-таки дал: наклонная граница

Условие конуса линейно по **квадратам** собственных времён. Значит
прошлое должно ограничиваться не ящиком `{v ≤ w}`, а наклонными
полупространствами:

```
    D = { b : Σ_i c_i · v_i(b)² ≤ W },   c_i ≥ 0
```

Замкнутость вниз цела (монотонность плюс неотрицательные веса), Грам не
нужен. Результат при `M` таких отсечений:

```
   k   M     N     доля  разм. высота   <спектр>   с.к.о.  связ       J
   6   1   800   0.7237   1.49   23.4    +0.0125   0.0030  26.7  0.5716
   6   2   800   0.5841   1.79   13.0    +0.0113   0.0011  53.1  0.4963
   6   4   800   0.2866   2.72    7.6    +0.0060   0.0039  70.3  0.3568
   6   6   800   0.1610   3.43    7.2    +0.0022   0.0116  48.0  0.3318
 ящик(6)   800   0.0973   4.04    6.8    +0.0005   0.0030  24.8  0.2293
  КОНУС   800   0.098    4.03   ~9.5    +0.0145   0.0026  ~15   0.169
```

**Величина спектра впервые верна:** `+0.0113 ± 0.0011` против конусных
`+0.0145 ± 0.0026`. Этого не давал ни один прежний механизм — все
упирались в `+0.002`.

Но плотность при этом уходит, и размен тот же, только сдвинутый: мало
отсечений — верный спектр и вчетверо высокая доля; много отсечений —
верная доля и подавленный спектр. Ящик есть предельный случай с
осевыми `c`.

⚠ По пути поймана своя ошибка: пороги как **квантили** вместо абсолютных
дают самоподдерживающуюся цепь (высота 1588 при `N = 1600`, связей ровно
1.0), потому что квантиль по монотонной величине вырезает префикс.

### Где это оставляет задачу

```
  ящик       верная доля, верная размерность, спектр подавлен (+0.002)
  наклон     верный спектр (+0.011), доля вчетверо велика
  оба        транзитивность 0, воспроизводимость эталонная
```

Размен «спектр против плотности» воспроизводится в обоих семействах.
Значит не хватает по-прежнему одной степени свободы: нужно отсекать
**часто** (для плотности) и **наклонно** (для спектра) одновременно, а в
нынешней параметризации число отсечений управляет и тем и другим.

## Что проверять дальше

1. **Форму прошлого вместо ящика.** `{v ≤ w}` — это покомпонентное
   условие, то есть ящик в пространстве шкал. У конуса прошлое — конус.
   Естественная замена: условие на **сумму** или на норму,
   `Σ_i c_i v_i(b) ≤ W`, которое тоже сохраняет замкнутость вниз (при
   `c_i ≥ 0`), но даёт не ступенчатую, а наклонную границу. Это должно
   уменьшить число максимальных элементов, то есть связей.
2. **Опоры не в начале, а распределённые.** Сейчас опоры — первые `k`
   событий, то есть все в далёком прошлом. У конуса направления `u`
   покрывают сферу; аналог — опоры, разбросанные по порядку, и, возможно,
   обновляемые по ходу роста.
3. **Проверить показатель связей как первый отсев.** Он считается за
   секунды и сейчас промахивается грубее всего (0.95 против 0.75).
