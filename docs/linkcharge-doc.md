# Заряд как свойство связи

### Дополнение к `ORDER-final.md`

Прежде заряд вешался на **событие** и выводился из его свойств. Здесь он — независимая
величина на **канале** между событиями, антисимметричная по направлению.

Почему это может быть лучше: связей в десятки раз больше, чем событий, и у связи есть
направление — антисимметрия возникает естественно.

---

## ⭐ Сохраняющиеся токи существуют, и их много

Сохранение в узле (приток = оттоку) — это закон Кирхгофа. Ищем заряды на связях с нулевой
дивергенцией.

$N$=300, 2664 связи:

| | значение |
|---|---|
| ранг матрицы инцидентности | 297 |
| **размерность пространства токов** | **2367** |
| формула для циклов графа (связи − узлы + 1) | 2365 |
| дивергенция найденного тока | **$8.9\times10^{-16}$** |

**Совпадает с числом независимых циклов графа.** Токи есть, их 2367.

⚠ Случайный заряд на связях **не сохраняется**: дивергенция 5.33, нулевая лишь у 46 узлов
из 600.

---

## Есть ли среди них выделенный

Проверяем величины, вычисляемые из порядка — какая доля каждой лежит в пространстве токов:

| кандидат | доля в пространстве токов |
|---|---|
| **общие предки минус потомки** (наша калибровочная фаза) | **0.583** |
| единица | 0.283 |
| разность прошлого | **0.000** |

**«Разность прошлого» ровно ноль** — она целиком градиент, что мы уже знали
(телескопирует).

### Устойчиво

| $N$ | доля |
|---|---|
| 250 | 0.6057 ± 0.0025 |
| 300 | 0.6059 ± 0.0077 |
| 400 | 0.6055 ± 0.0151 |

**0.606 при всех размерах**, разброс в третьем знаке.

---

## ⊗ Но это хуже случайного

Случайный вектор в пространстве размерности $M$ имеет долю
$\sqrt{(M-\text{rank})/M} = \sqrt{2367/2664} = \mathbf{0.943}$.

$$0.606 < 0.943$$

> **Наша калибровочная фаза сохраняется ХУЖЕ случайного заряда на связях.**
> Она содержит больше градиентной части, чем случайная величина.

---

## Итог

⭐ **Пространство сохраняющихся токов существует** и точно совпадает с циклами графа
(2367 при формуле 2365).

⭐ **Величина «общие предки минус потомки» устойчиво лежит в нём на 60.6%** —
воспроизводится при трёх размерах с точностью до третьего знака.

⊗ **Но это хуже случайного (0.943).** Выделенного тока, следующего из структуры, не
нашлось: наша величина сохраняется хуже, чем произвольный заряд на связях.

⚠ Проверены три кандидата; систематического перебора величин, вычислимых из порядка, не
было.

*Реализация: `linkcharge.py`.*
