# Заряд как инвертированная шкала: два правила, две разные смерти

**Драйвер:** `code/antimatter.py` · **Проверено:** гипотеза 4 из серии «маловероятных»

## Что спрашивали

Аналог античастицы: событие с перевёрнутой шкалой. Каждое событие несёт
знак `q = ±1`, доля отрицательных — `f`. Правило надо задать, и
осмысленных вариантов ровно два.

**Правило A.** Для пары одного знака обычное правило; для пары разных
знаков сравнение обращено на **всех** шкалах.

**Правило B.** Обращена только **одна** шкала (шкала 0).

Оба антисимметричны, оба при `f = 0` в точности совпадают с нашим
обычным правилом (контроль пройден).

## Правило A: причинность ломается при любой доле

```
  доля анти     3-циклов       ациклично
      0.000          0.0          5 из 5
      0.001         64.6          4 из 5
      0.010       1615.4          0 из 5
      0.100      13942.2          0 из 5
      0.500      42499.2          0 из 5
```

3-цикл виден на бумаге: `i(+) ≺ j(+) ≺ l(−) ≺ i(+)` требует лишь
`x_i < x_l < x_j` — совместимое условие. Поэтому петли появляются сразу,
и их число растёт как `N³f`.

Вывод: заряд, переворачивающий сравнение целиком, несовместим с
причинностью при любой ненулевой доле античастиц. Закрыто.

## Правило B: причинность выживает, геометрия — нет

Ацикличность здесь не наблюдение, а следствие: остальные `k − 1` шкал
никогда не переворачиваются, значит любое отношение влечёт
`x_i < x_j` на них, то есть вкладывается в обычный `(k−1)`-шкальный
порядок, у которого циклов нет. Отношение нетранзитивно, но замыкание
даёт законное причинное множество.

```
  доля анти 0.50: ациклично True, доля пар 0.0607 -> 0.1027 после замыкания
      размерность 3.132, высота 11, сектора: + 3.134 (302), - 3.190 (298)
```

Сектора по отдельности выглядят одинаково (3.134 против 3.190) — как и
должно быть: антивещество внутри себя неотличимо от вещества.

Но дальше три проверки убили конструкцию.

### Знак не восстанавливается из порядка

Парный признак слаб, но не нулевой: размер интервала различает пары
разных знаков с AUC 0.535 при 200 тыс. пар. У каждого события десятки
связей, поэтому слабые признаки могли бы сложиться в метку. Не сложились.

```
     N  доля анти   точность   случайно      контроль (мир без заряда)
   600       0.50      0.510      0.507                  0.513
  1200       0.50      0.505      0.509                  0.506
  2400       0.50      0.506      0.507                  0.505
```

Двухцветная раскраска по ведущему собственному вектору даёт 0.505–0.510
— ровно столько же, сколько на мире, где знаки приписаны случайно и на
порядок не влияли вовсе. Заряд остаётся приписанным сверху.

### Управляет число, а не доля

```
A. ФИКСИРОВАНА ДОЛЯ f=0.05        B. ФИКСИРОВАНО ЧИСЛО = 30
     N  античастиц  размерность        N    доля  размерность
   600          30        3.334      600  0.0500        3.334
  1200          60        3.242     1200  0.0250        3.361
  2400         120        3.156     2400  0.0125        3.354
  4800         240        3.070     4800  0.0063        3.320
```

При фиксированной доле размерность уползает вниз с ростом мира; при
фиксированном числе стоит на месте на восьмикратном диапазоне `N`.
Значит геометрия отвечает на абсолютное число заряженных событий.

### Размерность не имеет предела

```
     N  k       заряженный      обычный k-1
  1000  4    3.054 ± 0.016    2.899 ± 0.018
  2000  4    3.001 ± 0.012    2.889 ± 0.011
  4000  4    2.960 ± 0.012    2.886 ± 0.010
  1000  5    4.064 ± 0.033    3.746 ± 0.023
  2000  5    3.957 ± 0.018    3.738 ± 0.016
  4000  5    3.901 ± 0.011    3.734 ± 0.019
```

Обычный мир держит размерность: 3.746 → 3.738 → 3.734 при учетверении
`N`. Заряженный — нет: он сползает и предела не показывает до `n = 2000`
заряженных событий.

**Это и есть приговор.** Мир без устойчивой размерности — не
пространство-время. Заряженная конструкция тем беднее геометрией, чем
она больше.

## Две гипотезы, которые не прошли проверку размером

По дороге я дважды принял эффект конечного размера за структуру.

**Первая.** «Заряженный мир с `k` шкалами — это обычный мир с `k−1`
шкалами, перевёрнутая шкала перестаёт быть измерением». Красиво и
проверяемо. Отвергнуто: различия 4.6σ–26σ по всем четырём
дискриминаторам сразу (размерность, высота, доля пар, спектр).
Заряженный мир близок к `k−1`, но это другой объект.

**Вторая.** «Заряженный мир даёт **целую** размерность `k−1`». При
`N=1500` вышло `3.013 ± 0.045` и `4.042 ± 0.075` — почти в точку, и
это выглядело решением нашей стоячей проблемы (обычный `k=4` мерится
как 3.75, а не 4.00). При `N=4000` стало 2.960 и 3.901, то есть
3.4σ и 8.7σ мимо. Совпадение на конкретном размере.

## Чему это учит в смысле метода

Третий раз за сессию эффект конечного размера выдал себя за структуру:
ацикличность при `m = k−1` (гипотеза 3), «потеря измерения» и
«целая размерность» (здесь). Во всех трёх случаях число при одном `N`
выглядело содержательным.

> **Правило: в этой конструкции прогон при одном `N` не доказывает
> ничего. Любое число надо брать минимум на трёх размерах мира с
> четырёхкратным разбросом и смотреть на тренд, а не на значение.**

Это стоит дописать в `METHOD.md` к пяти уже записанным способам
измерить тавтологию — как шестой способ обмануться, отдельный от них.

## Итог по гипотезе

Заряд как инвертированная шкала умирает дважды, и причины разные:

| | причинность | геометрия | заряд из порядка |
|---|---|---|---|
| правило A | **ломается** при любом `f>0` | — | — |
| правило B | сохраняется (доказуемо) | **нет устойчивой размерности** | **не восстанавливается** |

Это снова та же стена, что и в прежних заходах: порядок не несёт второй
сущности. Но теперь формулировка точнее, чем раньше. Заряд, вставленный
в само правило сравнения, оставляет след в глобальной геометрии (доля
пар, высота, размерность меняются измеримо) — и при этом не читается
ни по отдельному событию, ни по отдельной паре. След есть, носителя нет.
