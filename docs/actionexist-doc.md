# Существует ли вообще действие, при котором доминирует пространство-время

Вопрос поставлен не «какая мера верна» (однородная, перколяция, фаза —
все провалились), а **есть ли хоть одна**. Вес сектора есть

    ln W(сектор) = S(сектор) + theta · f(сектор)

где `f` — порядковые счёты, `theta` — коэффициенты действия. При
`theta` = 0 это однородная мера, при `theta` на `(N₀, R)` — перколяция,
при `(−1, +9, −16, +8)` на `(N₀,N₁,N₂,N₃)` — действие
Бенинказы–Доукера. Требование доминирования

    theta · (f_4d − f_j) > S_j − S_4d   для всех соперников j

есть **линейное программирование**. Геометрически: пространство-время
обязано быть крайней точкой с опорной гиперплоскостью. У соперников
свободны число слоёв, плотность и размеры слоёв, поэтому они заполняют
континуум — и вопрос содержателен.

**Направления надёжности противоположны:** «действия нет» устойчиво к
добавлению соперников (оболочка только растёт) и доказывается
сертификатом Фаркаша; «действие есть» всегда предварительно.

## Результат

| набор счётов | вердикт |
|---|---|
| `N₀,N₁,N₂,N₃` (БД) | не разделяет |
| `R,N₀` (перколяция) | не разделяет |
| БД + `R` | не разделяет |
| `C₃,C₄` (цепи, то есть размерность) | не разделяет |
| высота | не разделяет |
| **все восемь объёмных**, плюс `N₄…N₈` и `C₅` | **не разделяет** |
| те же **плюс число максимальных и минимальных элементов** | **разделяет** |

> **Никакое действие из объёмных счётов не выделяет
> пространство-время. Добавление одного ГРАНИЧНОГО счёта — числа
> крайних элементов — выделяет.**

Невыполнимость доказана сертификатом Фаркаша: существуют `λ_j ≥ 0` с
`Σλ_j g_j = 0` и `Σλ_j C_j > 0`, то есть счёты засева суть **выпуклая
смесь** счётов соперников, у которых энтропия в среднем выше. Остаток
`|Gᵗλ|` = 10⁻¹⁶, `Σλ·C` = +8211…+9220 при трёх независимых пересевах.
Смесь всегда одного вида: плоский разреженный сектор (`k`=2, малое `q`)
плюс высокий тонкий (`k`~75…150).

Линейное действие не может отличить точку от смеси, которая в неё
усредняется — вот почему объёмные счёты бессильны.

## Действие Бенинказы–Доукера отбора не даёт

Прямая проверка: направление `(N₀,N₁,N₂,N₃) = (−1,+9,−16,+8)` со
свободным общим множителем (это `1/ℏ`), скан по знаку и величине от
10⁻⁴ до 10⁹. Лучший запас:

| `N` | 150 | 300 | 600 |
|---|---|---|---|
| запас | −960 | −7143 | −43231 |

Дефицит растёт как `N²` — не конечно-размерный эффект. Связывает всегда
`слоистый k=2 q=0.5`, то есть сектор Клейтмана–Ротшильда.

Это не противоречит известному: БД обосновано как дискретное действие
Эйнштейна–Гильберта (оно воспроизводит кривизну), а не как принцип
отбора. Но надежда «БД плюс энтропия ⇒ доминирует пространство-время» в
этом классе **не исполняется**.

## Самое разреженное работающее действие

L1-минимум использует **три счёта из девяти**, все с отрицательным
коэффициентом:

| счёт | коэффициент |
|---|---|
| `R` (отношения) | **−0.3735** |
| `N₀` (связи) | **−0.8006** |
| макс+мин (граница) | **−59.77** |

Граничный член на два порядка больше остальных.

**И отсюда видно, чего именно не хватало перколяции.** У неё
`ln Pr = L ln p + (M−R)ln(1−p)`, то есть `θ_{N₀} = ln p < 0` (верный
знак, `−0.80` отвечает `p` = 0.45) и `θ_R = −ln(1−p) > 0` — **знак при
`R` противоположен нужному**. Перколяция НАГРАЖДАЕТ отношения, а
разделяющее действие обязано их наказывать. Граничного члена у неё нет
вовсе.

## Чего это НЕ даёт: размерность не выводится

С граничным счётом разделимой становится **каждая** размерность засева
(`d` = 2…6, все с запасом ∞). Без него разделимы только края `d`=2 и
`d`=6, а `d` = 3, 4, 5 поглощены оболочкой. Значит граничный счёт
выделяет «похожесть на засев», а четвёрка задаётся **коэффициентами**,
а не выводится. Это ограничение честное и важное: класс действий
допускает любую размерность.

## Пойманные ошибки

1. **Искусственная граница `|θ| ≤ 10⁴`** дала «действия нет» при
   `N` = 600. Поймал КОНТРОЛЬ: цель «цепь» вышла невыполнимой, а цепь
   разделима по построению (у неё максимум `R`, `C₃`, `C₄`, высоты).
   Энтропийные зазоры растут как `N²`, нормированные счёты порядка
   единицы — граница связывала. Правильная постановка: `θ` без границ,
   неограниченность задачи = выполнимость.
2. **Знак энтропийного дефицита.** В L1-задаче требование было записано
   как `θ·g ≥ b + 1` при `b = S_цель − S_соперник`, а нужно `≥ −b + 1`.
   Из-за этого вышло «невыполнимо по всем наборам» — результат
   правильный по виду, но полученный из ошибки. Отсюда правило:
   **совпадение вердикта с ожиданием не отменяет проверки знака.**
3. **Редкая сетка соперников** давала «выполнимо с запасом ∞» для
   объёмных счётов. Плотная (426 секторов) даёт невыполнимость. Выводы
   о выполнимости без проверки на плотность не делать.

## Оговорки

1. Невыполнимость доказана **относительно набора счётов**; любой новый
   счёт её может снять — что и произошло с граничным.
2. Выполнимость доказана **относительно набора соперников**; она
   устояла против 125–150 специально построенных подделок с тонкими
   крайними слоями, но это не доказательство.
3. Энтропия засева взята щедро (Милнор–Том `4N lnN`) и ОДНА для всех
   `d` — то есть размерностная часть теста слепа к тому, что счёт
   многообразных порядков зависит от `d`.
4. «Действие» здесь — линейное по экстенсивным порядковым счётам. Это
   включает однородную меру, перколяцию и БД, но не исчерпывает
   семейство Райдаута–Соркина.
5. Счёты секторов меряны по 1–2 выборкам; устойчивость проверена
   пересевом (три зерна).

## Итог

Четвёртое ограничение на форму правила, и самое содержательное:

> **действие обязано содержать ГРАНИЧНЫЙ член и обязано НАКАЗЫВАТЬ
> отношения.** Объёмного действия, выделяющего пространство-время, не
> существует — доказано сертификатом.

Рядом с этим стоит измеренное ранее: граница несёт не больше
информации, чем случайный экран того же размера (0.5850 против
0.5891). Противоречия нет — там речь об информационном содержании, здесь
об одном экстенсивном числе, — но пара любопытная: граница
информативно пуста и при этом необходима для отбора.
