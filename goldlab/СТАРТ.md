# goldlab — с чего начать

**Что это.** Единый каркас проекта «физика из причинного порядка». Мир — золотой кристалл Z[τ]ⁿ: событие есть ⟺ его
«тень» (сопряжение Галуа) лежит в шаре. Всё, что было разбросано по сотне скриптов в `code/`, собрано в один пакет:
**ядро** (мир, связи, пропагаторы, поля, наблюдаемые), **реестр опытов** (каждый с эталоном из документа и допуском),
**хранилище прогонов**, **самопроверка** и **пульт** (страница в браузере: выбрал опыт → задал параметры или выделил
область мира мышью → «Посчитать» → числа с эталонами, графики, раскраска мира, история прогонов).

Новой сессии не нужно собирать проект заново по документам: запустить самопроверку, открыть пульт — и видно, что
воспроизводится, что нет и почему.

## Запуск

```bash
pip install numpy scipy            # больше ничего не нужно (сервер — стандартная библиотека Python)
cd goldlab
python -m goldlab.selftest         # воспроизвести ключевые числа (пресет «как в документе»; ~15–50 мин с парой)
python -m goldlab.selftest --quick # быстро (~6 мин; у спектров на коротких окнах ≈/✗ ожидаемы)
python -m goldlab.selftest --only bell,hydrogen11
python -m goldlab.server           # пульт: http://localhost:8765
python -m goldlab.server --export viewer.html   # статический просмотрщик с готовыми прогонами (можно показать другим)
```

Из Python:
```python
from goldlab import experiments as E, store
r = E.run('hydrogen11', {'L': 56})          # результат: numbers / series / overlay / notes
store.save(r, 'моя-метка')
```

## Ядро: одна формула (`core.py`)

```
τ = (1 + √5)/2,  τ′ = −1/τ          координаты — числа a + bτ, «тень» — те же числа с τ → τ′
событие есть   ⟺  тень в шаре       (crystal: одно правило для 1+1 и 3+1; радиус шара задаёт только плотность)
i раньше j     ⟺  j − i в конусе    (precedes)
```

Итератора у мира нет — правило задаёт всё пространство-время сразу. Но время кристалла дискретно, и мир честно
перечисляется слоями (`layers`). Шаги между слоями принимают **ровно три значения в отношении 1 : τ : τ²**
(0.300 / 0.486 / 0.786 при ρ = 4) и чередуются квазипериодически — «тиканье» кристалла золотое.

Всё остальное — либо выведено из ядра, либо **взято руками**. У каждого опыта есть список `hand` (в пульте — пунктирные
плашки «взято руками»): масса, закон движения (пропагатор Джонстона), потенциал ядра, форма среза, вершина пары… Плотность ρ
и размер области — масштаб и окно обзора, их в список не пишем. Опыт «Мир и его размерность» — целиком из ядра. Цель
роадмапа — сокращать эти списки.

**Опыты v1.**
* *Мир, свет, масса:* размерность мира; закон дисперсии (инерция = масса); часы массивной частицы; свет и масса в 3+1; почему именно τ (буст точен только у золота); световых пар нет (теорема, наименьший интервал).
* *Поле, атом, водород:* Кулон из связей 3+1; сила между зарядами; спектр атома 1+1; водород 1+1; водород 3+1 (↺ точность понижена до ±5 %); атом со спином в 3+1 и предел зерна (`spin31`); ансамбль сдвигов фазона в 3+1 (`ens31`); Паули и «гелий» в 3+1 (`pauli31`); откуда «разгон» в 3+1 (`grow31`); симметрично размытый световой конус (`fuzzy31`); лестница частот кристалла и резонанс по массе (`ladder31`); атом 3+1 без гребёнки (`lightatom31`); потенциал как вставка при энергии E (`energyatom31`); один проход и гармоническая инверсия (`hinvatom31`); свет 3+1 из порядка — две стороны конуса (`ordercone31`); ящик □ из слоёв прошлого — веса Соркина из моментов (`boxorder31`); массивная частица 3+1 без цепочки по массе — только сравнимые пары (`massive31`); заряд из геометрии.
* *Пары и Белл:* квант из точки (полярное событие); Алиса и Боб (синглет, CHSH); пара частица + античастица (Фейнман).
* *Гравитация среза и цвет:* уравнения среза Р–Т; неабелево поле из формы среза; квант с цветом.
* *Фермионы и атомы* (15 окт., `fermions.py`): измеритель на длинном окне; частица со спином на нитях (спин → статистика); поле заряда
  из порядка (1+1); Паули в атоме; «гелий» с отталкиванием из поля зарядов; «литий» самосогласованно (Хартри); одно правило на разных уровнях; спин без нитей — компоненты Дирака из светового уголка; атом Дирака целиком из порядка; «гелий» без нитей (Паули и обмен, всё поле из порядка); обмен как динамика (пара с взаимодействием, все порядки); нормировка вершины сшивкой и «гелий» всеми порядками; одна векторная вершина для всех состояний; «литий» на новой основе; ансамбль сдвигов фазона (точность пары); этапы вселенной (уравнение состояния w = 1/3, 1, −1/3, −1).

**Как добавить опыт.** В `experiments.py`: декоратор `@experiment(id, block, title, what, params, region, presets, ref, cost)`
и функция `(p, region) → {'numbers': [num(...)], 'series': [...], 'overlay': overlay(world, v, label), 'notes': [...]}`.
Список ручных входов — в словарь `HAND` (обязательно). `num(key, label, value, expected, tol, rel)` сам ставит статус: ✓ в допуске, ≈ до трёх допусков, ✗ дальше. Пульт подхватит
опыт без правок страницы. `region` — `'interval'` (причинный интервал по выделению) или `'point'` (центр выделения).

## Соглашения (важно, легко перепутать)

* `K[i, j]` — амплитуда из i в j; отклик на источник f — `φ = Kᵀf`. Частица вращается как e^{+iEt}; у волны e^{ikx}
  физический импульс −k. Спектр считаем с весом e^{−iωt}.
* 1+1: Φ = ½C; 3+1: Φ = (√ρ / (2π√6))·L по связям, вставка b = −m²/ρ.
* Связь поля в 1+1 — «световой уголок» (точна при любой силе поля): фаза P(x_y) + P(x_x) − 2P(x_c) и вставка
  B = −(m² − iU′)/ρ. В 3+1 — прямая нить Вильсона по связи (связи короткие).
* События золотого 1+1 лежат на уровнях времени; мера мгновенной вершины — λ = ρ·Δt_уровня, не 2δρ.
* Заряд — целое число оборотов фазы вокруг окна; поле — связность нормалей среза.

## Принципы

* **Не читерить.** Ничего не выбрасываем ради красивого числа (нашли античастицу — она остаётся, аннигиляция — вопрос
  к теории, а не к фильтру). Приближения помечаем прямо в описании опыта (пример: no-pair — приближение, основной
  путь — Фейнман).
* **Честные статусы:** замер / вывод / гипотеза / приближение / отозвано. ✗ в таблице не прячем.
* **Физика, не фичи.** Пульт — инструмент, а не симулятор ради симулятора.
* Эталоны — из документов; если число в документе оказалось неверным, исправляем документ и пишем поправку в инвентарь.

## Поправки, найденные при сборке каркаса (15 окт.)

* *Уровни КГ для U = F|x|* — линейный векторный потенциал не запирает навсегда (парадокс Клейна), уровни
  квазисвязанные; стрелять надо до середины «щели Клейна», как в `spectro1d.py`. Первая версия каркаса стреляла до x = 60
  и давала мусор (1.03 вместо 1.426) — исправлено (`observe.kg_levels_linear`).
* *Уравнения среза (slice-doc §5).* В `rt_far.py` выход писался со сдвигом на шаг (r старый, состояние новое), что
  занижало M_доп на малых r (0.033 вместо 0.045 при r = 20). Правильно: наклон log M_доп / log r = 1.45 на r = 30…160,
  локальный наклон растёт к 3/2 (1.43 → 1.47). Где решение «рвётся» — зависит от шага (161…300+): не физика.
  Вывод (добавка ∝ r^{3/2} асимптотически, плоских кривых нет; q = 1/4) не меняется.

* *Заряд из геометрии (maxwell-doc §22).* Центр пакета — шумный зонд силы: даже во внешнем однородном поле ускорение зависит
  от места старта. Физика — отношение «срез / внешнее поле» при одном старте: 1.00 ± 0.03 на оси (m = 1), 0.92 / 0.91 при m = 2, 3.
* *Пара (maxwell-doc §21, §25).* Множитель c подгонялся по спектру, а K_вперёд = −i(W₊ − W₋) — тождество. С точным c: 0.389 против
  0.425 (мера «полоса»), приведённая масса 1.064 против 1.066. Прежние 0.422 и 0.568 несли ошибку c.
* *Долгие счёты:* не запускать два тяжёлых параллельно (память 8 ГБ), печатать прогресс, ставить предел итераций (`CAP`).

## Открытые вопросы (куда дальше)

* Нормировка вершины пары: мера «полоса» даёт −8.5 %, мера «уровень» дрейфует с размером; чётный канал завышен (+26–36 %, до пересчёта с точным c).
* Заряд из геометрии: недобор 8–9 % при m = 2, 3 и отклонения вне оси.
* Фермионы: спинорное ядро с положительным контактом.
* Аннигиляция (в 1+1 в покое — ноль по сохранению тока; вывод, не замер).
* Самодействие неабелева поля (Янг–Миллс), SU(3) ⊂ SO(8); величина элементарного заряда.
* Дальше по мечте: сильное взаимодействие → химия (см. `docs/00-РОАДМАП.md`).

**Двигатель эволюции пары (15 окт., `fermions.pair_ladder`, `dirac-doc` §15).** Двухчастичная амплитуда A = Kᵀ(F + W∘A)K
считается не итерациями, а прямой развёрткой по слоям времени кристалла: строка A[y₁] зависит только от более ранних
событий, поэтому каждая считается один раз (A[слой] = K[:, слой]ᵀH, H[слой] = (F + W∘A)[слой]·K). Все порядки
взаимодействия, цена ~2n³ (мир 28 — минуты), упор — в память n². Это эволюция, а не пересчёт всей системы.
