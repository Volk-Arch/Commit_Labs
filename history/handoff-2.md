# Хэндофф: порядок, шкалы, случайность

Четыре дня работы по каузальным множествам. Всё ниже проверено счётом, каждое число
воспроизводится. Восемнадцать гипотез снято собственными проверками — они перечислены
отдельно, чтобы не повторять.

Инструмент: `order.py` (четыре преобразования от порядка до физики) и быстрый
инкрементальный движок Монте-Карло.

---

## 1. ФОРМУЛА

Правило, порождающее причинную структуру, тривиально и не содержит параметров:

```
e_i ≺ e_j   ⟺   ∀m ∈ {1..k}:  u_m(i) < u_m(j)
```

Событие `i` предшествует `j`, если раньше по **каждой** из `k` шкал.
Шкала `u_m` — полный порядок на событиях, то есть очередь. Ни расстояний, ни
вещественных чисел: только ранг.

**Вход:** множество из N событий и k независимых шкал.
**Выход:** частичный порядок, из которого достаётся вся кинематика.

### Что достаётся из одного порядка

| величина | как | проверка |
|---|---|---|
| размерность | доля связанных пар → Майрхейм–Мейер | 1.99 / 3.00 / 4.00 при истинных 2/3/4 |
| собственное время | длина максимальной цепи | цепь/T постоянна: 103.3, 107.8, 103.3 |
| волновое уравнение | знакопеременный подсчёт цепей | совпало с ½·J₀(mτ) до третьего знака |
| различимость | перекрытие прошлых у несравнимых | 0.77 / 0.59 / 0.48 / 0.36 при d=2..5 |
| кривизна | действие через обилия интервалов | см. §3 |

Различимость устойчива по размеру (0.773, 0.797, 0.765 при N=2500..10000) и **не зависит
от кривизны**: конформное искажение плотности в 8000 раз её не двигает.

## 2. ГЛАВНОЕ ОГРАНИЧЕНИЕ ФОРМУЛЫ (найдено в самом конце)

**k шкал воспроизводят Минковский ТОЛЬКО при k=2.**

Причина известна и опубликована: размерность порядка Душника–Миллера для пространства
Минковского при размерности многообразия больше двух равна **счётной бесконечности**
(Müller, arXiv:2303.11237). Для всех прочих известных порядковых размерностей оценка
снизу тоже бесконечна. Именно поэтому Мюллер вводит новое понятие размерности,
дающее правильное n+1.

Двумерие — исключение, там размерность порядка ровно 2 (теорема о светоконусных
координатах), и наше совпадение точное.

### Проверено прямо: разрыв не сходится с размером

| N | k=2 против d=2 | k=4 против d=4 |
|---|---|---|
| 800 | 1.99/0.756 vs 2.00/0.788 | 3.85/0.400 vs 4.00/0.455 |
| 2000 | 2.01/0.772 vs 1.98/0.750 | 3.72/0.440 vs 3.98/0.484 |
| 5000 | 2.01/0.773 vs 1.99/0.765 | 3.73/0.357 vs 3.98/0.452 |
| 10000 | 1.99/0.765 vs 1.98/0.778 | 3.71/0.399 vs 4.00/0.483 |

Двумерие идеально на всех размерах. Четырёхмерие расходится, разрыв 0.15 → 0.29 и
стабилизируется на четверти. Это не конечно-размерный эффект.

**Вывод:** формула из §1 — точная модель двумерия и лишь приближение выше. Для
четырёхмерия нужно либо бесконечно много шкал, либо другое понятие размерности.

## 3. ПРО СЛУЧАЙНОСТЬ: КУДА ЕЁ ПОДАВАТЬ

Центральный результат по этой линии.

### Независимость шкал обязательна (измерено с контролями)

Вторая шкала как функция первой ломает всё, каждый раз по-своему:

| вторая шкала | доля пар | размерность | различимость | действие S/N |
|---|---|---|---|---|
| **независимая (эталон)** | 0.488 | 2.03 | 0.752 | **+1.0 ± 1.8** |
| первая + сильный шум | 0.751 | 1.44 | 0.927 | +2.2 ± 1.1 |
| перестановка разрядов | 0.516 | 1.96 | 0.654 | **−14.3 ± 0.0** |
| квадрат первой (монотонная) | 1.000 | 1.00 | — | цепь |
| первая со сдвигом | 0.556 | 1.86 | **0.000** | вырождение |
| обратная первой | 0.000 | — | — | пустой порядок |

Строка «перестановка разрядов» — важнейшая: она подделала **три наблюдаемых из трёх**
(доля пар, размерность, различимость почти как у эталона) и провалилась по действию
с разрывом в 14 сигм. Это ровно та ловушка, в которую мы попадали 17 раз.

Даже частичная зависимость губительна: первая шкала плюс шум даёт различимость 0.927
вместо 0.752, то есть треть корреляции уже выталкивает к вырождению.

### Слот случайности: перебор

Систематический перебор того, что можно подать, чтобы «вернулся ответ» (мишень —
предсказание непосредственного соседства, засев d=3, 4 реализации):

| что подаём | AUC | прирост |
|---|---|---|
| ничего | 0.559 | — |
| шум (контроль) | 0.548 | −0.011 |
| число родителей | 0.586 | +0.027 |
| разброс глубин родителей | 0.584 | +0.025 |
| теснота родителей | 0.589 | +0.030 |
| глубина | 0.627 | +0.068 |
| размер прошлого | 0.634 | +0.075 |
| **указатель на одного соседа** | **0.734** | **+0.175** |

Три группы: шум даёт ноль; «сколько родителей и как устроены» +0.03; «как далеко вдоль»
+0.07 (три независимые записи одного слота дают одинаково — слот исчерпан); «рядом с кем»
+0.175.

**Из чего состоит указатель** (разложение):

| подаём | прирост |
|---|---|
| числа про якорь, но не кто он | +0.023 |
| один бит на кандидата: связан ли с якорем | +0.042 |
| перекрытие прошлых с якорем | +0.080 |
| весь указатель | +0.160 |

Объёмом указатель не работает. Работает именно **отношение** к нему.

### Асимметрия «да» и «нет»

Протокол «потерявшийся ребёнок»: сколько подтверждений нужно.

| подсказка | AUC (d=3) |
|---|---|
| ничего | 0.577 |
| 1 раз НЕТ | 0.555 |
| 5 раз НЕТ | 0.560 |
| 25 раз НЕТ | 0.551 |
| **150 раз НЕТ** | **0.552** |
| **1 раз ДА** | **0.735** |
| 2 раза ДА | 0.831 |
| 4 раза ДА | 0.869 |

Сто пятьдесят отрицаний дают ноль (даже ниже базовой линии). Одно подтверждение даёт всё.
Причина: связей меньше процента, поэтому редкий ответ информативен. Зеркально фильтру
Блума, где редко именно «нет».

## 4. ДЕЙСТВИЕ КАК ЕДИНСТВЕННЫЙ НАДЁЖНЫЙ РАЗЛИЧИТЕЛЬ

Формула (Бенинказа–Доукер, d=4), выверена по источнику:

```
S/ħ = N − N₁ + 9N₂ − 16N₃ + 8N₄        (N_k — число пар с ровно k элементами между)
```

Двумерный оператор:  `B⁽¹⁺¹⁾φ = (2/ℓ²)[ −φ + 2(ΣL₁ − 2ΣL₂ + ΣL₃) ]`

### Проверка на готовых множествах (N=2500, 3 реализации)

| | доля пар | размерность | S/N |
|---|---|---|---|
| засев d=2 | 0.500 | 2.00 | **+1.4 ± 0.5** |
| засев d=3 | 0.230 | 2.99 | **+2.7 ± 1.8** |
| засев d=4 | 0.089 | 4.13 | **−0.1 ± 1.1** |
| перколяция p=0.002 | 0.019 | 5.91 | −5.9 ± 0.8 |
| **перколяция p=0.007** | **0.474** | **2.07** | **−15.6 ± 1.5** |
| перколяция p=0.02 | 0.832 | 1.29 | −16.9 ± 1.2 |
| перколяция p=0.06 | 0.959 | 1.07 | −5.4 ± 0.5 |

У всех засевов действие около нуля — правильно, Минковский плоский, а действие в пределе
даёт скалярную кривизну. Величина строится из чисел порядка N², и после подстановки
остаётся единица на элемент: сокращение на шесть порядков.

Строка `p=0.007` решающая: она четыре дня прикидывалась двумерием по доле пар (0.474
против 0.500) и по размерности (2.07 против 2.00). Действие даёт −15.6 против +1.4,
разрыв в семнадцать сигм.

**Пересечения шкал лежат вместе с засевами:** k=2 даёт +2.1 ± 0.6, k=3 +2.5 ± 0.9,
k=4 +5.4 ± 1.0, k=5 +2.6 ± 0.9. То есть по действию они многообразны, и различитель
работает в обе стороны.

## 5. КЛЮЧЕВОЙ ЗАМЕР: СТЕНА БЫЛА В ПОСТАНОВКЕ, А НЕ В ПОРЯДКЕ

Четыре дня считалось: «порядок не содержит информации о соседстве» (AUC вперёд 0.565).
Проверка опровергла это.

**Восстановление связей вынутого элемента** (интерполяция вместо экстраполяции):

| | d=2 | d=3 | d=4 |
|---|---|---|---|
| предсказание ВПЕРЁД | ~0.60 | **0.565** | 0.69 |
| восстановление вынутого, ничего о нём не зная | 0.765 | **0.840** | 0.936 |
| то же, зная его будущее | 0.750 | **0.982** | 0.989 |

Информация о соседстве в порядке **есть** и её почти достаточно. Она не работает вперёд,
потому что вперёд нет данных — элемента ещё нет.

**Следствие:** семнадцать провалов правил роста объясняются не невозможностью правила, а
тем, что последовательная постановка даёт только левый контекст, а соседство определяется
двусторонне.

## 6. РАЗВОРАЧИВАНИЕ И НАБЛЮДАТЕЛИ

Два наблюдателя разворачивают один и тот же порядок в разном линейном продолжении.

| развёрнуто | кажущихся связей | из них настоящих | согласие двоих |
|---|---|---|---|
| 20% | 657 | **0.000** | 0.464 |
| 40% | 1733 | 0.000 | **0.177** |
| 60% | 3901 | 0.026 | 0.297 |
| 80% | 5900 | 0.062 | 0.447 |
| 95% | 8218 | 0.136 | 0.645 |
| 100% | **4811** | 1.000 | **1.000** |

При 20% ни одна кажущаяся связь не настоящая. Два наблюдателя при 40% согласны на 0.177 —
и это на парах, которые оба уже видят.

**Слияние УБИРАЕТ связи:** 8218 кажущихся против 4811 настоящих. Ветка всегда видит больше
близости, чем есть.

На малой системе (12 событий, 150 множеств × 12 пар наблюдателей, планки ±0.01):

| непроявлено | согласие | прирост |
|---|---|---|
| 4 | 0.706 | +0.016 |
| 3 | 0.702 | −0.004 |
| 2 | 0.724 | +0.022 |
| 1 | 0.784 | +0.060 |
| **0** | **1.000** | **+0.216** |

Скачок на последнем элементе. Один непроявленный элемент портит пятую часть картины —
он лежит МЕЖДУ какими-то двумя, и без него они кажутся соседями.

**Схождение конусов при этом плавное** (доля общего будущего от объединённого по слоям):
d=4 даёт 0.013, 0.044, 0.096, 0.173, 0.287, 0.427, 0.599, 0.748 — никакого момента встречи.
Разрывность живёт в исчерпании непроявленного, не в геометрии пересечения.

## 7. НОВЫЕ НАБЛЮДАЕМЫЕ (родились из аналогии с git)

**Доля верхушки общего прошлого** — максимальные элементы среди общих предков двух
несравнимых событий. В теории порядков это множество максимальных нижних граней;
отдельного имени в литературе по каузальным множествам не нашли.

| | доля верхушки | размер общего прошлого |
|---|---|---|
| засев d=2 | 0.042 ± 0.005 | 464 |
| засев d=3 | 0.246 ± 0.012 | 188 |
| засев d=4 | 0.533 ± 0.011 | 95 |
| перколяция p=0.007 | 0.053 ± 0.002 | 1264 |

Единственный общий предок практически не встречается: 0.7% в двумерии, ноль в трёх и
четырёх. Криcc-кросс мердж — норма, а не исключение.

**Конфликтность** = размер верхушки / (что каждый нажил своего сверх общего):
0.26 ± 0.05, 1.80 ± 0.27, 3.46 ± 0.43 при d = 2, 3, 4. Перколяция даёт 2.84 и 2.89 при
доле связанных пар 0.607 и 0.877 — то есть по паре величин не совпадает ни с одним засевом.

**Показатель роста числа связей по размеру:** 0.153 / 0.431 / 0.660 при d=2/3/4 (R²≈0.999).
В двумерии рост логарифмический (L ≈ 1.0·lnN, R²=0.9988), в трёх и четырёх степенной.

**Скорость схождения конусов:** к восьмому слою общее будущее составляет 13% в двумерии
и 75% в четырёхмерии.

## 8. ЧТО СНЯТО (18 гипотез, не предлагать заново)

1. Число родителей как метка фермион/бозон — расходится с плотностью (6.3 → 42.7).
2. Конусный вес в правиле роста — хуже линейного (0.0043 против 0.0051 при цели 0.0161).
3. Экранирование при приёме зацепов — тождественная операция, порядок не меняется.
4. Отбор по перекрытию прошлых — сокращает связи вместо роста.
5. Ремонт удалением «плохих» элементов — неотличим от случайного контроля.
6. Многообразность как поздний режим роста — с размером хуже (0.91 → 0.97 → 0.99).
7. Избыток симметрии как диагноз — опровергнут замером автоморфизмов (у роста |Aut|=1.06,
   у засева 3.00, то есть наоборот).
8. Критичность — три захода, все отрицательные. Огибающая τ^(−1/2) есть просто континуальный
   предел; порог по массе существует у всех, разница лишь в тридцать раз.
9. Произведение перекрытие×d = 1.79 на трёх знаках — рассыпалось при контроле по размеру.
10. Потолок связей 1.8 — артефакт узкого окна по N (на самом деле 1.7 → 3.9 → 5.0).
11. «Объединение прошлых гасит различие» — неверно, при радиусе 1 гаснет так же.
12. Транзитивность как причина — та же, спад 1151x при радиусе 1 против 652x при полном.
13. Фиксированное число родителей — проезжает мимо цели (1.81 → 2.01 → 2.17 → 2.26).
14. Постоянный список знакомых (граф знакомств) — тоже проезжает.
15. Кластеризация знакомств помогает — наоборот, чем меньше треугольников, тем ближе к цели.
16. Смысловая близость как источник различимости — убивает её (перекрытие 0.984 против
    0.500 у случайных связей): сходство транзитивно, независимость нет.
17. Парные признаки поднимут предсказание соседства — ухудшают (0.518 против 0.568).
18. **k шкал дают k-мерный Минковский** — только при k=2; при d≥3 порядковая размерность
    Минковского бесконечна (§2).

Плюс закрыто перебором: в классе последовательного роста динамики нет. Полный перебор
всех 32768 историй на шести элементах, всё пятипараметрическое семейство — расстояние по
вариации до двумерия 0.31, до четырёхмерия 0.93. Пять параметров лучше одного на 5%.

## 9. ЧЕТЫРЕ ФОРМУЛЫ, ВСПОМНЕННЫЕ НЕВЕРНО И ПОЙМАННЫЕ ПРОВЕРКОЙ

Записано как предупреждение: по памяти ошибка примерно в каждой второй формуле.

1. Множитель в формуле Майрхейма–Мейера (был вдвое меньше; точный ответ для d=2 равен 0.5,
   формула давала 0.25).
2. Сопряжение в хеббовской матрице: нужно `W = Σ z z†`, то есть `Z.T @ Z.conj()`.
   Обратный порядок даёт поле, тянущее к сопряжённому паттерну, узнавание падает до шума.
3. Коэффициенты оператора Бенинказы–Доукера в 2D (был префактор 4 вместо 2 и 1/ℓ² вместо 2/ℓ²).
4. Длина ряда в действии: четыре слоя обилий, а не два.

Плюс дефект в `order.py`, найденный второй сессией: `proper_time` шла по возрастанию
индекса и молча требовала топологической сортировки. Разброс `distinctness` по
перенумерациям достигал 0.11 при сигнале 0.18. Исправлено, провалидировано (размах по
перенумерациям 0.040 против размаха повторов на одной матрице 0.055).

## 10. ГДЕ СТОИТ ОБЛАСТЬ

Не только мы. Уилер шёл от геометрии — не вышли фермионы (из чистой геометрии не получаются
спиноры). Вэнь идёт от запутанности — не выходят киральные (Нильсен–Ниномия). Соркин своё
единственное удачное предсказание (величина тёмной энергии, угадана за десять лет до
открытия, из пуассоновой флуктуации числа элементов) построил на допущении «дальше работает
какая-то неизвестная динамика», и так и написал: неизвестная.

Работающий подход в области — не рост, а Монте-Карло по действию: там найден фазовый
переход между многообразной и слоистой фазой для двумерных орденов (обзор arXiv:2306.09904).
Мы его не воспроизвели: наш скан не показывает перехода ни при одном размере (150–1000),
ни при одном ходе, ни в пяти порядках по константе связи. Разброс действия падает с
размером (0.63 → 0.31), а у перехода первого рода обязан расти. Причины: нормировка
действия у нас своя (общий множитель выброшен, масштаб β неизвестен) и приёмка за
пределами узкой области падает до 0.007 — цепь замерзает. Нужен параллельный отжиг или
кластерные ходы.

## 11. ОТКРЫТОЕ

**Главный вопрос после §2:** формула из §1 точна только для двумерия. Чем заменить её выше?
Мюллер вводит новое понятие размерности, дающее правильное n+1 — стоит прочитать
arXiv:2303.11237 целиком и попробовать померить эту величину нашим инструментом.

**Второй:** откуда независимость шкал. Измерено, что она обязательна (§3), но не выведено.

**Третий:** воспроизвести фазовый переход. Упор алгоритмический, не концептуальный.

**Не проверено и висит:** предсказание, что у названных концептов перекрытие прошлых ниже,
чем у безымянных. Сделано до замера из двух независимых источников. Требует графа со
сведением узлов по содержанию — в имеющемся `lived_graph.json` 174 узла и **ноль** узлов
с двумя родителями, то есть схождений нет вовсе, и величина не определена по построению.

## 12. СЧЁТ

По критерию «убрали ли хоть один параметр, который приходится брать у природы» — **ноль**.
У всей области тоже ноль.

Что сделано: инструмент из четырёх проверенных преобразований, быстрый движок
(ускорение ~3000×, время шага не зависит от размера, сверка с лобовым счётом точная),
пять наблюдаемых вместо двух, восемнадцать закрытых дверей с числами.

Почти всё, что получено, уже опубликовано, включая работу трёхмесячной давности,
повторяющую наш замер с кривизной, и работу 2024 года о причинном перекрытии, которое
оказалось более аккуратной версией нашей `distinctness`.

При восемнадцати снятых гипотезах совпадение с литературой — не поражение, а признак,
что прибор мерил настоящее.
