## Что уже убито (не предлагать заново)

Восемь гипотез, каждая снята собственной проверкой предыдущей сессии:

1. Число родителей как метка фермион/бозон — расходится с плотностью (6.3 → 42.7), не метка.
2. Конусный вес в правиле роста — сделал хуже (0.0043 против 0.0051 при цели 0.0161).
3. Экранирование при приёме зацепов — тождественная операция, множество не меняется.
4. Отбор по перекрытию прошлых — сокращает связи вместо роста.
5. Ремонт удалением «плохих» элементов — неотличим от случайного контроля.
6. Многообразность как поздний режим роста — с размером становится хуже (0.91 → 0.97 → 0.99).
7. Избыток симметрии как диагноз — опровергнут замером автоморфизмов (у роста |Aut|=1.06,
   у засева 3.00, то есть наоборот).
8. Критичность — три захода, все отрицательные: огибающая τ^(−1/2) есть просто континуальный
   предел; скорость экспоненты не проходит через ноль по параметру роста; порог по массе
   существует у всех множеств, разница лишь в тридцать раз.

Также закрыто: в классе последовательного роста динамики, дающей многообразие, нет.

расстояние по вариации до двумерия 0.31, до четырёхмерия 0.93. Пять параметров лучше одного

## Правило проверки (важнее всех результатов)

За сессию восемь красивых результатов оказались артефактами. Выжила одна привычка:

> **Подгонять по одной величине, проверять по другой, которую не трогал.**

Все провалы шли по одной схеме: совпадало ровно то, подо что подгоняли. Формула Коиде
совпала до четвёртого знака и оказалась круговой. Перколяция совпала по доле связанных
пар и провалилась по родителям втрое. Произведение перекрытие×d дало 1.794/1.796/1.785 —
три знака — и рассыпалось при контроле по размеру (1.53/1.78/1.94).

Второе правило, тоже оплаченное: **одна реализация на точку — не результат.** Прорыв при
κ=−1.5 (перекрытие 0.62 при цели 0.70) исчез при повторе с другими параметрами.

## Инструмент: `order.py`

Самодостаточный, зависимости — numpy и scipy. Запуск демонстрации:

```bash
python3 order.py
```

Печатает пять блоков с ожидаемыми числами (см. таблицу выше). Если они не совпали —
сломано окружение, а не физика.

### Интерфейс

Все четыре функции принимают одну матрицу отношений:

```python
K[j, i] == 1   ⟺   i предшествует j
```

Матрица float32, размер N×N, **транзитивно замкнутая**, без циклов.

```python
from order import dimension, proper_time, propagate, distinctness

dimension(K)          # → float, размерность по Майрхейму–Мейеру
proper_time(K, src=0) # → массив длин максимальных цепей от src
distinctness(K)       # → float, медиана перекрытия прошлых; 0.77=2D, 1.0=вырождение
propagate(K, src, mass, rho)  # → поле от точечного источника
```

Память: плотная матрица, N² float32. N=10000 это 400 МБ, N=20000 — 1.6 ГБ плюс копии.
При 32 ГБ практический потолок около N=25000.

## Задача 1 (главная): померить граф `belief_core`

`belief_core.py` держит реляционную память: узлы плюс рёбра `caused_by` / `followed_by`.
Это ориентированный граф отношений — ровно тот объект, который читают четыре преобразования.

### Шаги

1. Вынуть из `belief_core` ориентированный граф причинных рёбер.
2. **Проверить ацикличность.** Каузальное множество обязано быть строгим частичным
   порядком. Граф убеждений вполне может иметь циклы, и тогда задача умирает на первом
   шаге — это законный отрицательный результат, о нём надо сказать прямо, а не чинить
   выбрасыванием рёбер молча.
3. Взять транзитивное замыкание, собрать `K` в указанной ориентации.
4. Прогнать `dimension`, `distinctness`, и отклик через `propagate`.

### Как читать ответ

| результат | что значит |
|---|---|
| размерность 2–4, перекрытие 0.5–0.8 | граф ведёт себя как многообразие. Неожиданно и интересно: значит у пространства убеждений есть устойчивое число независимых направлений |
| перекрытие ≈ 1.0 | состояния неразличимы по своей истории. Это режим «один глобальный бассейн», он же эпилепсия из статьи про когерентность: максимум согласованности при нулевой различимости |
| размерность >6 или нестабильна | граф слишком разрежен, ведёт себя как случайный порядок |
| `nan` | не хватило элементов. `distinctness` требует ≥40 валидных пар в слое; на графах меньше ~300 узлов будет молчать |

**Главный риск, назвать его сразу:** переносимость понятий не гарантирована. Размерность
и собственное время определены для порядков, возникших из пространства-времени. Что они
означают на графе убеждений — открытый вопрос, и возможен ответ «ничего». Численный
результат надо предъявить вместе с этой оговоркой, а не вместо неё.

## Задача 1б: предсказание про имена (главная проверка на невподогнанном)

Из `abstraction-spiral_ru.md`: аттрактор без имени — это **аттрактор без рёбер**. Поле его
держит, но он не участвует в мысли, потому что не включён в связность. По утверждению
автора, это самая повторяющаяся находка проекта — десяток сессий подряд не названное
не ложилось и не узнавалось.

Функция `distinctness` меряет ровно это: насколько различаются прошлые у элементов,
между которыми нет отношения. Названный концепт имеет рёбра, значит различённое прошлое;
безымянный аттрактор — нет.

**Предсказание:** у названных концептов перекрытие прошлых заметно ниже, чем у безымянных.

Замер: разбить узлы на названные и безымянные, посчитать `distinctness` отдельно по каждой
группе (при достаточном размере обеих). Разница в ожидаемую сторону — сильное свидетельство,
потому что обе стороны предсказания установлены независимо и **до** замера: одна на
каузальных множествах, другая на когнитивном субстрате.

Отсутствие разницы тоже информативно: значит либо перенос понятия не работает, либо имя
даёт не связность, а что-то другое. Оба варианта надо назвать прямо.

⚠ Не подгонять порог разбиения на группы под получение разницы. Разбиение фиксируется
до замера по признаку «есть слово / нет слова», и больше не трогается.

## Задача 2 (дешёвая, независимая): порог ёмкости

Померено на фазовом Хопфилде, 200 осцилляторов, механика та же, что в `_settle`:

| P/N | узнавание | взаимное перекрытие settled-состояний |
|---|---|---|
| 0.03 | 0.99 | 0.16 |
| 0.10 | 0.54 | 0.46 |
| **0.14** | **0.39** | **0.64** |
| 0.30 | 0.34 | 0.48 |

Обвал на классической ёмкости Хопфилда ≈ 0.138. За порогом разные входы сходятся в одно
место. В `belief_core` это измеримо напрямую: взять settled-состояния от разных входов и
считать их взаимное перекрытие как функцию числа посаженных убеждений.

Это даёт машинерии забывания (`rem_downscale`, `_chunk_aged`, `consolidate_wave_resident`)
количественный критерий вместо эвристики: она обязана удерживать систему ниже порога.
Узнавание при этом обманывает — оно падает плавно, а слияние бассейнов происходит резко.

Осторожно с хеббовской матрицей: `W = Σ z z†`, то есть `Z.T @ Z.conj()`. Обратный порядок
сопряжения даёт поле, тянущее к сопряжённому паттерну, и узнавание падает до шума. Эта
ошибка была допущена и поймана отладкой с нулевым шумом — стоит начинать с неё.

## Что хочу получить обратно

По убыванию ценности:

1. **Числа с оговоркой.** Размерность, различимость и отклик графа `belief_core`, вместе
   с честной оценкой, значат ли они что-нибудь. Отрицательный ответ («граф циклический»,
   «слишком мал», «величины нестабильны») — полноценный результат, его надо дать прямо.

2. **Кривая ёмкости для реального поля.** Взаимное перекрытие settled-состояний против
   числа убеждений, и где обвал. Одно число, которого сейчас нет.

3. **Проверка на невподогнанном.** Что бы ни вышло — предъявить величину, под которую
   не подгоняли. Без этого шага результат не считается.

Чего не нужно: продолжать искать динамику роста каузальных множеств. Это направление
закрыто перебором, а работающие подходы (двумерные ордена, CDT) обходят вопрос тем, что
кладут структуру в представление, а не выводят её.
