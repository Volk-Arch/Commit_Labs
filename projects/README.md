## Активные проекты (GitHub)

### [Cognit](https://github.com/Volk-Arch/Cognit)

Локальный ИИ-ассистент для кодовых баз на модели Qwen2.5-Coder-7B. Всё работает in-process, без API-ключей.

- **Язык:** Python
- **Коммиты:** 29
- **Статус:** MVP

---

### [Baddle](https://github.com/Volk-Arch/Baddle)

Интерактивный инструмент для экспериментов с генерацией текста нейросетью. Пошаговая визуализация процесса «мышления» модели. Граф мыслей с дивергентным (Think/Expand) и конвергентным (Collapse) режимами, heatmap энтропии по токенам, compare mode.

- **Языки:** Python, HTML
- **Коммиты:** 53
- **Статус:** Рабочий прототип
- **Статья:** [Что думает нейросеть о Baddle](../articles/baddle-ai-view.md)

---

### [dev-graph](https://github.com/Volk-Arch/dev-graph)

Визуальный инструмент управления проектами: иерархическая декомпозиция задач, визуализация графа зависимостей, интеграция с Яндекс.Трекером. Рабочий проект — сделан за вечер+утро.

- **Языки:** HTML, Python, JavaScript
- **Статус:** Рабочий инструмент

---

### [PaPaPhone](https://github.com/Volk-Arch/PaPaPhone) ← текущий фокус

Телефон с голосовым управлением на Orange Pi + 4G-модем (SIM7600 HAT). Для людей, которые не могут пользоваться смартфонами — потеря зрения, слуха, моторики. Готовых аналогов на рынке нет. Делается для дедушки.

- **Язык:** Python
- **Статус:** Прототип → доведение до рабочего состояния
