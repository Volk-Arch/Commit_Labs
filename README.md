# Порядок — что следует из одного отношения «раньше»

Восемь дней работы. Всё проверено счётом, каждое число воспроизводится.

**Это не теория мира.** Игрушечная модель, на которой видно, сколько физики следует из
одного правила — и где оно кончается. Ни одна измеренная величина природы здесь не
воспроизведена.

## Правило

> Событию даны $k$ чисел. Событие $A$ раньше $B$, если $A$ раньше по **всем** $k$ числам.

```bash
python3 code/twobody.py            # взаимодействие двух тел
python3 code/threebody.py          # складываются ли влияния

```

**`ORDER-final.md`** — весь путь: правило, следствия с числами, границы, снятые гипотезы.

## Что выходит из правила

**Устройство пространства-времени.** Размерность равна числу шкал; собственное время —
длина максимальной цепи; световой конус и предельная скорость — граница, а не постулат;
замедление времени.

**Свойства материи.** Волновое распространение с интерференцией (двущелевой опыт,
видность 0.405); статистика частиц из топологии пространства фаз (в слое одного момента
времени: энионы при k = 3, два класса с k = 4, тот же порог, что у спина); киральность; заряд как
разброс шкал; **спин ½ при k ≥ 4**: поворот на π (двойная транспозиция шкал), применённый
дважды, возвращает мир и даёт −1 на спиноре при любом подъёме; при k = 3 вынужденных знаков
нет. ⚠ «Оборот даёт −1» из ранних частей мерил зацепление с осями таких поворотов, а не
оборот (`docs/spin-doc.md`, §15–16).

**Стрела времени** — из объёма макросостояния, без дополнительных постулатов.

**Динамика.** Рождение и гибель событий по квантовому правилу дают устойчивый мир с
аттрактором по размерности; правило гибели управляет крупномасштабной структурой
(показатель −0.98 при наблюдаемом во Вселенной −0.90).

**Гравитация — частично.** Метрика возникает из плотности событий; геодезические
загибаются к искривлённым областям; **два тела взаимодействуют через поле между ними**, и
эффект убывает до нуля с расстоянием; **влияния трёх тел складываются в слабом поле**
(совпадение до третьего знака).

## Чего НЕ выходит

**Квантовости нет и быть не может:** у события определённые значения фаз, теорема Белла
запрещает такой модели нарушить неравенство (замер 1.453 при пределе 2).

**Уравнения поля нет:** есть искривление и взаимодействие, нет закона, связывающего
материю с геометрией. Причина измерена: у величин на событиях сохранение и влияние
**антикоррелированы** (−0.83).

**Материя не отделяется от геометрии:** всё, что можно посчитать, оказывается описанием
самого пространства.

**Число шкал не выводится:** почему их четыре — не объяснено, проверено пять способов.

## Запуск

```bash
python3 code/simulate.py            # КУСОК ПРОСТРАНСТВА-ВРЕМЕНИ целиком
python3 code/simulate.py --k 3      # двумерное пространство
python3 code/order8.py              # главный: 13 разделов
python3 code/double_slit.py         # двущелевой опыт, два случая
python3 code/double_slit.py --n 20000 --plot out.png
```

`double_slit.py` — наглядная демонстрация: интерференция есть на уровне амплитуд,
но наблюдатель, живущий в порядке, её не видит (относительные фазы теряются при
переводе фаз в порядок). Работает на numpy + sklearn; для больших N замените
numpy на cupy в верхних функциях.

### Зависимости и окружение

- `python -m pip install -r requirements.txt` ставит numpy, scipy, scikit-learn и matplotlib.
- numpy и scipy обязательны. Без scipy `simulate.py` предупредит и оценит размерность как
  1 − log₂ f вместо формулы Майрхейма–Мейера; `order8.py` без scipy не запустится.
- `double_slit.py` дополнительно требует scikit-learn, а с `--plot` ещё matplotlib.
- Windows: консоль в cp1251 не печатает юникод. Задайте `PYTHONUTF8=1` (или один раз
  `setx PYTHONUTF8 1`). Точки входа из этого списка переключают вывод в UTF-8 сами.
- Скрипты, собранные в песочнице через `exec(open(...))`, ищут соседей в своей папке,
  запускать можно из любого места: `python code/charge_weight.py`.
